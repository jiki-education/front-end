# Fun-rating emoji

These five PNGs are JoyPixels emoji (128px), used for the "Rate the fun factor" control
in the exercise-completion modal (`lib/modal/modals/steps/DifficultyRatingStep.tsx`).

| File                 | Emoji | Codepoint |
| -------------------- | ----- | --------- |
| frustrated.png       | 😫    | U+1F62B   |
| neutral.png          | 😐    | U+1F610   |
| slightly-smiling.png | 🙂    | U+1F642   |
| smiling.png          | 😊    | U+1F60A   |
| grinning.png         | 😄    | U+1F604   |
