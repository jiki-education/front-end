कल्पना कीजिए कि आपके पास मेरा नाम, Jeremy, है और आप उसमें से मेरा पहला अक्षर J निकालना चाहते हैं। हम यह कैसे करेंगे?

देखिए, आप स्ट्रिंग को अक्षरों की एक श्रृंखला की तरह समझ सकते हैं। तो `"Jeremy"` में छह अक्षर हैं: J-E-R-E-M-Y, और हर एक की एक स्थिति है। `"J"` पहली स्थिति पर है, `"y"` आखिरी स्थिति पर है।

अब, JavaScript और ज़्यादातर प्रोग्रामिंग भाषाओं में, ये स्थितियाँ शून्य से शुरू होती हैं। तो पहला अक्षर `"J"` स्थिति 0 पर है, फिर अगला `"e"` स्थिति 1 पर है, `"r"` 2 पर, `"e"` 3 पर, `"m"` 4 पर, और `"y"` 5 पर।

अब, शून्य से शुरू करने वाली यह बात थोड़ी अजीब है, और सच कहूँ तो, अगर हम सामान्य दुनिया की तरह एक से गिनती शुरू करते तो ज़िंदगी आसान होती। लेकिन हम ऐसा नहीं करते। ज़्यादातर प्रोग्रामिंग भाषाओं में हम शून्य से गिनती शुरू करते हैं, तो बस आपको यह सीखना है।

तो अगर हमें किसी खास स्थिति पर मौजूद अक्षर चाहिए, तो हम अंदर संख्या लिखकर चौकोर ब्रैकेट का इस्तेमाल कर सकते हैं।

तो अगर हम `"Jeremy"[0]` लिखते हैं, तो हम कह रहे हैं कि मुझे `"Jeremy"` शब्द का पहला अक्षर दो।

अगर हम `"Jeremy"[1]` लिखते हैं, तो हम कह रहे हैं कि मुझे दूसरा अक्षर दो।

```javascript
"Jeremy"[0] // "J"
"Jeremy"[1] // "e"
```

और हम यह वेरिएबल के साथ भी कर सकते हैं। तो अगर हम एक वेरिएबल बनाएँ जिसका नाम `name` (नाम) है और उसकी वैल्यू `"Jeremy"` स्ट्रिंग सेट करें, तो हम `name[0]` कर सकते हैं और हमें फिर से `"J"` मिलेगा।

```javascript
let name = "Jeremy"
name[0] // "J"
```

एक बात साफ़ कर लें: `name[0]` से आपको जो मिलता है, वह बस एक और स्ट्रिंग है। यह एक और कागज़ है जिस पर J लिखा है। इसमें कोई खास बात नहीं है। यह ठीक वैसी ही स्ट्रिंग है जैसे `"Jeremy"` एक स्ट्रिंग है।

बस इतना है कि इस पर छह के बजाय एक ही अक्षर है।

और ऐसा करने से मूल स्ट्रिंग पर कोई फ़र्क नहीं पड़ता। हम J को फाड़कर अलग नहीं कर रहे हैं या ऐसा कुछ नहीं। हम बस यह ढूँढ रहे हैं कि हमें कौन-सा अक्षर चाहिए, और फिर उसे लेकर एक नई स्ट्रिंग बना रहे हैं।
