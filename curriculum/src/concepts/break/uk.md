Ключове слово `break` можна використати будь-де в тілі будь-якого циклу.

Усе, що міститься між фігурними дужками, і є тілом циклу. І щойно Jiki побачить це слово, він негайно вийде з циклу й перейде до коду, який розташований нижче.

Отже, якщо в нас є обмеження, що цикл має виконатися 50 разів, але ми хочемо зупинитися, коли користувач вистрілить пʼять разів, ми можемо створити цикл `for`, який рахує до 50.

А посередині циклу ми можемо додати умову, яка перевіряє, чи вистрілив користувач пʼять разів, і якщо так, то використовуємо `break` (перервати), щоб зупинити цикл.

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // вийти з циклу
  }
}
```
