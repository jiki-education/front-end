Η λέξη-κλειδί `break` μπορεί να χρησιμοποιηθεί οπουδήποτε μέσα στο σώμα οποιουδήποτε βρόχου.

Το κομμάτι ανάμεσα στα άγκιστρα, αυτό είναι το σώμα. Και όταν ο Jiki το δει, θα βγει από τον βρόχο αμέσως και θα προχωρήσει σε ό,τι κώδικα υπάρχει κάτω από τον βρόχο.

Έτσι, αν έχουμε έναν περιορισμό που λέει να τρέξουμε αυτόν τον βρόχο 50 φορές, αλλά θέλουμε να σταματήσουμε αν ο χρήστης πυροβολήσει πέντε φορές, θα μπορούσαμε να έχουμε έναν βρόχο `for` στο πάνω μέρος που μετράει προς το 50.

Αλλά στη συνέχεια, θα μπορούσαμε να έχουμε μια συνθήκη στη μέση του βρόχου που ελέγχει αν ο χρήστης έχει πυροβολήσει πέντε φορές, και αν έχει, κάνουμε `break` για να σταματήσουμε τον βρόχο.

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // βγες από τον βρόχο
  }
}
```
