کلیدواژه‌ی `break` را می‌توانید در هر جایی از بدنه‌ی هر حلقه‌ای استفاده کنید.

آن بخش بین آکولادها، همان بدنه است. و وقتی جیکی آن را می‌بیند، بلافاصله از حلقه خارج می‌شود و به سراغ هر کدی می‌رود که پایین حلقه قرار دارد.

بنابراین اگر محدودیتی داریم که می‌گوید این حلقه را ۵۰ بار اجرا کن، اما می‌خواهیم اگر کاربر ۵ بار شلیک کرد متوقف شویم، می‌توانیم یک حلقه‌ی `for` در بالا داشته باشیم که تا ۵۰ می‌شمارد.

اما بعد می‌توانیم یک شرط در وسط حلقه داشته باشیم که بررسی می‌کند آیا کاربر ۵ بار شلیک کرده است یا نه، و اگر این‌طور بود، برای متوقف کردن حلقه از `` `break` (توقف) `` استفاده می‌کنیم.

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // خروج از حلقه
  }
}
```
