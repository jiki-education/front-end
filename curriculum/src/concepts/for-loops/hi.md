आपको शायद याद होगा कि `repeat` लूप वास्तव में JavaScript में नहीं होता। यह सिर्फ एक अतिरिक्त चीज़ है, जो शुरुआत में आपकी ज़िंदगी थोड़ी आसान बनाने के लिए जोड़ी गई है।

तो इसकी जगह हम क्या इस्तेमाल करते हैं? हम एक सामान्य `for` लूप का इस्तेमाल करते हैं, और वह कुछ इस तरह दिखता है।

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

आप समझ सकते हैं कि पहले दिन यह देखकर आपको थोड़ा डर लगा होगा।

लेकिन अब आपके पास उतना ज्ञान आ गया है कि आप इसको आराम से समझ सकते हैं। तो चलिए, इसे भागों में तोड़कर समझते हैं।

एक `for` लूप में तीन हिस्से होते हैं: एक इनिशियलाइज़र (_initializer_), एक शर्त, और एक इंक्रीमेंट (_increment_)।

इनिशियलाइज़र, यानी `let i = 0` वाला हिस्सा, पूरे लूप की शुरुआत में चलता है। यह सिर्फ एक बार चलता है, और यहाँ यह `i` (एक वेरिएबल) नाम का डिब्बा बनाकर उसमें शून्य रखता है। `i` बस एक अक्षर है जिसका इस्तेमाल लूप के दौरान एक वैल्यू को ट्रैक करने के लिए किया जाता है, और परंपरा से इसके लिए `i` या `x` का इस्तेमाल होता है।

फिर शर्त की जाँच होती है, जो हर इटरेशन से पहले की जाती है।

अगर शर्त सही हो, तो हम लूप दोबारा चलाते हैं।

अगर शर्त सही नहीं है, तो लूप नहीं चलता।

और अंत में इंक्रीमेंट आता है, यानी `i++`।

`i++` का मतलब बस `i = i + 1` के बराबर ही है। यह एक संक्षिप्त तरीका है, `i` को हर बार एक से बढ़ाने का।

तो इस उदाहरण में, हम `i` को शून्य पर सेट करते हैं। हम जाँचते हैं कि क्या `i` दो से छोटा है, जो कि हाँ है, तो हम लूप चलाते हैं।

और फिर अंत में, हम `i` को एक से बढ़ाते हैं, तो `i` एक हो जाता है। शून्य जमा एक बराबर एक।

और फिर हम दोबारा जाँचते हैं। हम जाँचते हैं कि क्या एक दो से छोटा है। हाँ है, तो लूप चलाते हैं। और फिर अंत में, हम `i` को फिर से बढ़ाते हैं। तो अब यह दो है, एक जमा एक बराबर दो।

```javascript
i = 0
i < 2 // सही - लूप चलाएँ
...   // इटरेशन करें
i = i + 1 // 1

i < 2 // सही - लूप चलाएँ
...   // इटरेशन करें
i = i + 1 // 2

i < 2 // गलत - लूप से बाहर निकलें
```

और फिर हम तीसरी बार जाते हैं। इस बार हम जाँचते हैं कि क्या दो, दो से छोटा है, और यह सही नहीं है, इसलिए लूप नहीं चलता, और हम लूप से बाहर आ जाते हैं। हम बस नीचे के कोड पर चले जाते हैं। तो हमने लूप दो बार चलाया, और यह जानने लायक बात है। जब तक हम शून्य से शुरू करते हैं और शर्त `i < n` है, तो संख्या `n` बताती है कि लूप कितनी बार चलेगा।

तो यह `repeat 2` कहने के बराबर है।

तो यह कठिन नहीं है, लेकिन सीधे `repeat 2` लिखने की तुलना में कहीं ज़्यादा पेचीदा ज़रूर है। `for` लूप का फ़ायदा यह है कि उन तीनों हिस्सों में आप कुछ भी कर सकते हैं। आप किसी और संख्या से शुरू कर सकते हैं, एक से ज़्यादा से बढ़ा सकते हैं, घटा सकते हैं, या ऐसी शर्त लगा सकते हैं जो किसी साधारण काउंटर के बजाय किसी और चीज़ पर निर्भर करती है। यही लचीलापन `for` लूप को JavaScript का सबसे भरोसेमंद और काम का लूप बनाता है।
