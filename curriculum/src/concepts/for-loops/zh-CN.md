你也许记得，`repeat` 循环在 JavaScript 中并不真的存在。它只是为了在入门阶段给你行个方便而加入的。

那我们用什么呢？嗯，我们使用普通的 `for` 循环，看起来像这样。

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

你看，这就是为什么第一天这对你来说可能有点吓人。

但现在，你已经掌握了所有需要熟悉它的知识。所以，让我们来分解一下。

一个 for 循环由三部分组成：初始化（英语：_initializer_）、条件和自增（英语：_increment_）。

初始化部分，也就是 `let i = 0` 这一段，会在整个循环开始时运行。它只运行一次，这里它创建了一个名为 `i` 的盒子（`i` 是循环中用来跟踪数值的变量），并设置为 0。`i` 只是一个字母，用于在循环过程中跟踪一个值，传统上常使用 `i` 或 `x` 来表示。

在条件之前的下一部分，会在每次循环迭代之前运行。

如果条件为 true，我们就再次运行循环。

如果不是，就不运行。

最后是自增部分，也就是 `i++`。

`i++` 的意思就和 `i = i + 1` 一样。这只是一个简写，一种每次将 `i` 增加 1 的方式。

所以在这个例子中，我们将 `i` 设置为 0。我们检查 `i` 是否小于 2，是的，于是运行循环。

然后在末尾，我们把 `i` 增加 1，所以 `i` 变成 1。0 加 1 等于 1。

然后我们再来一次。检查 1 是否小于 2。

是的，所以运行循环。然后在末尾，再次增加 `i`。所以现在它是 2，1 加 1 等于 2。

```javascript
i = 0
i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 1

i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 2

i < 2 // false - exit the loop
```

然后我们进行第三次。这次我们检查 2 是否小于 2，不是，所以不运行循环，实际上循环就结束了。我们就继续执行下面的任何代码。所以循环运行了两次，知道这一点很有用。只要我们从 0 开始，并且条件是 `i < n`，那么数字 `n` 就是循环将运行的次数。

所以这跟说 repeat 2 是一样的。

所以这并不难，但它比直接写 repeat 2 要复杂得多。for 循环的优点在于，你可以在那三个槽位里做任何事情。你可以从不同的数字开始，以大于 1 的幅度向上计数，向下计数，或者使用依赖于简单计数器之外其他东西的条件。这种灵活性使得 for 循环成为 JavaScript 的主力。
