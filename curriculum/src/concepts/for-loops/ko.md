JavaScript에는 repeat 루프라는 것이 실제로는 없어요. 처음 시작할 때 조금 더 쉽게 하기 위해 추가한 것일 뿐이에요.

그럼 대신 무엇을 사용할까요? 바로 일반적인 `for`문을 사용해요. 이런 모습이에요.

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

처음 접하면 조금 부담스러울 수 있어요. 하지만 이제는 이걸 편하게 이해할 수 있는 지식을 모두 갖췄어요. 그러니 하나씩 살펴볼게요.

`for`문은 세 가지 구성 요소로 이루어져 있어요. 초기화식(영어: _initializer_), 조건, 그리고 증감식(영어: _increment_)이에요.

초기화식, 즉 `let i = 0` 부분은 전체 루프의 시작에서 딱 한 번 실행돼요. 여기서는 `i`(반복 변수)라는 상자를 만들고 0으로 설정해요. `i`는 단지 반복할 때 값을 추적하는 데 사용하는 문자예요. 전통적으로는 `i`나 `x`가 이 용도로 사용돼요.

그다음 부분인 조건은 매 반복을 시작하기 전에 매번 검사해요.

조건이 참이면 루프를 다시 실행해요. 그렇지 않으면 실행하지 않아요.

마지막으로 증감식인 `i++`이 와요.

`i++`은 `i = i + 1`과 같은 뜻이에요. `i`를 매번 1씩 증가시키는 간단한 표기법이에요.

그럼 이 예제에서는 `i`를 0으로 설정해요. `i`가 2보다 작은지 검사하는데, 작으니까 루프를 실행해요.

그리고 마지막에 `i`를 1 증가시켜서 `i`가 1이 돼요. 0 더하기 1은 1이니까요.

다시 돌아와서, 1이 2보다 작은지 검사해요. 작으니까 루프를 실행하고, 마지막에 `i`를 다시 1 증가시켜요. 그러면 이제 2가 돼요. 1 더하기 1은 2니까요.

```javascript
i = 0
i < 2 // 참 - 루프 실행
...   // 반복 수행
i = i + 1 // 1

i < 2 // 참 - 루프 실행
...   // 반복 수행
i = i + 1 // 2

i < 2 // 거짓 - 루프 종료
```

그리고 세 번째로 돌아가요. 이번에는 2가 2보다 작은지 검사하는데, 작지 않으니까 루프를 실행하지 않아요. 사실 이제 루프는 끝이에요. 그 아래에 있는 다른 코드로 넘어가면 돼요. 결국 루프는 두 번 실행됐어요. 이건 알아두면 도움이 되는 사실이에요. 0부터 시작하고 조건이 `i < n`이면, 숫자 `n`이 바로 루프가 실행되는 횟수가 돼요.

그러니까 이건 repeat 2라고 말하는 것과 같아요.

어렵지는 않지만, 단순히 repeat 2라고 적는 것보다 훨씬 복잡해 보여요. `for`문의 장점은 저 세 자리에 무엇이든 넣을 수 있다는 거예요. 다른 숫자에서 시작할 수도 있고, 1보다 크게 증가시킬 수도 있고, 거꾸로 감소시킬 수도 있고, 단순한 카운터가 아닌 다른 조건을 사용할 수도 있어요. 이런 유연함 덕분에 `for`문은 JavaScript의 핵심 도구가 돼요.
