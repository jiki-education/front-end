شاید یادتان باشد که حلقه‌ی Repeat در واقع در جاوااسکریپت وجود ندارد. حلقه‌ی Repeat را فقط برای آسان‌شدن کار اضافه کردیم تا راه بیفتیم.

پس به جایش از چه استفاده می‌کنیم؟ خب، از یک حلقه‌ی عادی `for` استفاده می‌کنیم که به این شکل است.

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

می‌بینید که چرا ممکن است این قضیه در روز اول برای شما کمی ترسناک بوده باشد.

اما برعکس روز اول، الان کلی چیز بلدیم که به ما کمک می‌کند تا راحت‌تر این حلقه را یادبگیریم. پس بیایید آن را گام‌به‌گام بررسی کنیم.

یک حلقه‌ی `for` سه بخش دارد: یک مقدار اولیه، یک شرط، و یک افزایش.

مقدار اولیه، یعنی همین `let i = 0`، در ابتدای کل حلقه اجرا می‌شود. فقط یک بار اجرا می‌شود و در اینجا جعبه‌ای به نام `i` (شمارنده) می‌سازد که مقدارش صفر است. `i` صرفاً حرفی است که برای دنبال کردن یک مقدار در حین حلقه استفاده می‌شود و به طور سنتی از `i` یا `x` برای این کار استفاده می‌کنند.

بخش بعدی شرط است که هر بار، پیش از هربار تکرارشدن حلقه، بررسی می‌شود.

اگر شرط درست باشد، دوباره حلقه را اجرا می‌کنیم.

اگر نباشد، اجرا نمی‌کنیم.

و در نهایت هم افزایش، یعنی `i++`.

`i++` دقیقاً همان `i = i + 1` معنی می‌دهد. فقط یک خلاصه‌نویسی است، راهی برای این که هر بار `i` را یک واحد افزایش دهیم.

پس در این مثال، `i` را روی صفر تنظیم می‌کنیم. بررسی می‌کنیم که آیا `i` از دو کوچک‌تر است یا نه، که همین‌طور است، بنابراین حلقه را اجرا می‌کنیم.

و سپس در انتها، `i` را یک واحد افزایش می‌دهیم، پس `i` یک می‌شود. صفر به اضافه‌ی یک می‌شود یک.

و بعد دوباره به سراغش می‌رویم. بررسی می‌کنیم که آیا یک از دو کوچک‌تر است.

هست، پس حلقه را اجرا می‌کنیم. و بعد در انتها، دوباره `i` را افزایش می‌دهیم. بنابراین حالا دو شده است، یک به اضافه‌ی یک می‌شود دو.

```javascript
i = 0
i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 1

i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 2

i < 2 // false - exit the loop
```

و بعد برای بار سوم ادامه می‌دهیم. این بار بررسی می‌کنیم که آیا دو از دو کوچک‌تر است، که نیست، پس حلقه را اجرا نمی‌کنیم و در واقع کارمان با حلقه تمام می‌شود. فقط به هر کدی که در ادامه آمده ادامه می‌دهیم. بنابراین حلقه دو بار اجرا شد، به این نکته دقت کنید. تا وقتی از صفر شروع کنیم و شرط `i < n` را داشته باشیم، عدد `n` همان تعداد دفعاتی است که حلقه اجرا می‌شود.

استفاده از حلقه‌ی For در مثالی که گفتیم، عین این است که بگوییم: «دو بار این دستورها را تکرار بکن».

آخر سر این که استفاده از حلقه‌ی For اون‌جوری‌ها هم سخت نیست، اما حتما پیچیده‌تر از وقتی هستش که فقط می‌گوییم: «دوبار تکرار کن». مزیت حلقه‌ی `for` این است که می‌توانید هر کاری را در سه قسمت خط اول حلقه انجام دهید. می‌توانید از عدد دیگری شروع کنید، با گامی بزرگ‌تر از یک بشمارید، شمارش معکوس کنید، یا از شرطی استفاده کنید که به چیزی غیر از یک شمارنده‌ی ساده وابسته است. این انعطاف‌پذیری است که حلقه‌ی `for` را به اسب بارکش جاوااسکریپت تبدیل می‌کند.
