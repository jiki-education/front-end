Можливо, ви памʼятаєте, що циклу repeat насправді не існує в JavaScript. Його просто додали, щоб трохи полегшити нам життя на старті.

То що ж використовувати натомість? Звичайний цикл `for`, і виглядає він ось так.

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

Тепер зрозуміло, чому першого дня він міг би видатися трохи страшним.

Але тепер у нас є всі потрібні знання, щоб із ним освоїтися. Тож розберімо його на частини.

Цикл `for` складається з трьох частин: ініціалізатора (англ. _initializer_), умови та інкременту (англ. _increment_).

Ініціалізатор, оця частина `let i = 0`, виконується тільки раз на початку всього циклу. У цьому прикладі він створює коробку з назвою `i` й кладе в неї нуль. `i` тут просто буква, якою ми відстежуємо значення, поки проходимо цикл; традиційно для цього використовують `i` або `x`.

Наступна частина, умова, виконується щоразу перед кожною ітерацією циклу.

Якщо умова правдива, цикл виконується ще раз.

Якщо ні, то ні.

І нарешті інкремент, оте `i++`.

`i++` означає те саме, що й `i = i + 1`. Це просто скорочення, спосіб збільшувати `i` на одиницю щоразу.

Отже, у цьому прикладі ми присвоюємо `i` нуль. Перевіряємо, чи `i` менше за два. Так, менше, тож запускаємо цикл.

А в кінці збільшуємо `i` на одиницю, тож `i` стає одиницею. Нуль плюс один буде один.

І йдемо далі. Перевіряємо, чи один менше за два.

Так, менше, тож запускаємо цикл. А в кінці знову збільшуємо `i`. Тепер це два: один плюс один буде два.

```javascript
i = 0
i < 2 // правда - запускаємо цикл
...   // Виконуємо ітерацію
i = i + 1 // 1

i < 2 // правда - запускаємо цикл
...   // Виконуємо ітерацію
i = i + 1 // 2

i < 2 // неправда - виходимо з циклу
```

І йдемо втретє. Цього разу перевіряємо, чи два менше за два. Ні, не менше, тож цикл не запускаємо, і на цьому з ним, власне, закінчуємо. Просто переходимо до коду нижче. Отже, цикл виконався двічі, і це корисно знати: якщо ми починаємо з нуля й маємо умову `i < n`, число `n` показує, скільки разів виконається цикл.

Тож це те саме, що написати repeat 2.

Отже, нічого складного тут немає, але це набагато заплутаніше, ніж просто написати repeat 2. Перевага циклу `for` у тому, що в ці три частини можна вписати будь-що. Можна почати з іншого числа, збільшувати лічильник більше ніж на одиницю, рахувати у зворотному напрямку або використати умову, що залежить не від простого лічильника, а від чогось іншого. Саме ця гнучкість робить цикли `for` ключовим інструментом у JavaScript.
