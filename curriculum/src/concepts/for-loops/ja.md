JavaScriptには `repeat` ループというものが実際には存在しないのを覚えているかもしれません。これは、これから進めるにあたって少しでも楽に感じてもらうために用意されたものにすぎません。

では、代わりに何を使うのでしょうか？　普通の `for` ループを使います。そして、それは次のような形をしています。

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

初日からこれを見ると、少し身構えてしまうのも当然ですよね。

でも今なら、これに慣れるのに必要な知識はすべて身についています。では、分解してみましょう。

`for`ループには、初期化部分（英: _initializer_）、条件、増分（英: _increment_）の3つの構成要素があります。

初期化部分、つまりこの `let i = 0` の部分は、ループ全体の最初に一度だけ実行されます。ここでは、`i`（ループ回数を数えるための変数）という名前の箱をゼロに設定しています。`i`は、ループ中に値を追跡するために使われる単なる文字で、伝統的に `i` や `x` が使われます。

次の部分である条件は、ループの各繰り返しの直前に毎回評価されます。

条件が真であれば、ループをもう一度実行します。

そうでなければ、実行しません。

そして最後が増分、`i++` です。

`i++` は `i = i + 1` と同じ意味にすぎません。これは単なる略記法で、`i` の値を毎回 1 ずつ増やす方法です。

では、この例で見てみましょう。まず `i` をゼロに設定します。`i` が 2 より小さいかを調べます。実際に小さいので、ループを実行します。そしてループの終わりに `i` を 1 増やします。すると `i` は 1 になります。0 に 1 を足すと 1 ですね。そしてもう一度繰り返します。1 が 2 より小さいかを調べます。小さいので、ループを実行します。そして再び終了時に `i` を 1 増やします。すると今度は 2 になります。1 足す 1 は 2 です。

```javascript
i = 0
i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 1

i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 2

i < 2 // false - exit the loop
```

そして3回目に入ります。今度は 2 が 2 より小さいかを調べますが、小さくないのでループは実行されません。これで実際にループは終了です。あとは下にあるコードに進むだけです。結局、このループは 2 回実行されたことになります。これは覚えておくと便利です。ゼロから始めて、条件に `i < n` と書けば、数字 `n` がループの実行回数になるのです。

ですから、これは repeat 2 と言っているのと同じことです。

決して難しいわけではありませんが、ただ repeat 2 と書くよりはるかに複雑ですね。`for`ループの利点は、この3つのスロットで何でもできることです。別の数から始めたり、1 より大きな値で増やしたり、減らしたり、単純なカウンター以外の条件を使うこともできます。この柔軟性こそが、`for`ループを JavaScript の主力にしている理由です。
