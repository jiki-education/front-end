Іноді ми хочемо пропустити певну ітерацію циклу, а не повністю з нього виходити. Уявімо, що ми хочемо щось робити лише з непарними числами.

Ми хочемо мати змогу сказати: якщо `i` (індекс) непарний, цього разу цикл виконувати не треба.

Але ми не хочемо повністю виходити з циклу. Нам треба лише пропустити цю одну ітерацію і поглянути на наступну.

І для цього в нас є ще одне ключове слово, яке називається `continue`.

Коли Jiki бачить `continue`, він просто повертається на початок циклу, до наступної ітерації. Тож у циклі `for-of`, побачивши `continue`, він переходить до наступного елемента масиву.

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // Пропускає решту циклу для "something"
  }
  // Решта циклу...
}
```

У циклі `for` він спершу доходить до інкремента `i++`, а тоді починає наступну ітерацію.

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // Пропускає решту циклу для парних чисел
  }
  // Решта циклу...
}
```
