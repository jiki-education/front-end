گاهی ممکن است بخواهیم یک تکرار خاص از حلقه را بدون این که از آن خارج شویم، رد کنیم. فرض کنید فقط می‌خواهیم برای اعداد فرد کاری انجام دهیم.

می‌خواهیم بتوانیم بگوییم اگر `i` (متغیر حلقه) فرد باشد، این بار حلقه را اجرا نکن.

اما نمی‌خواهیم به‌طور کامل از حلقه خارج شویم. فقط می‌خواهیم همین یک تکرار را رد کنیم و بعد به سراغ تکرار بعدی برویم.

و برای این کار، یک کلیدواژه‌ی دیگر داریم به اسم `continue`.

وقتی جیکی `continue` را می‌بیند، فقط به بالای حلقه برای تکرار بعدی برمی‌گردد. بنابراین در یک حلقه‌ی for-of، اگر `continue` را ببیند، به سراغ عنصر بعدی در فهرست می‌رود.

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // برای "something" بقیه‌ی حلقه را رد می‌کند
  }
  // بقیه‌ی حلقه...
}
```

در یک حلقه‌ی for، قسمت افزایش `i++` را اجرا می‌کند و بعد تکرار بعدی را شروع می‌کند.

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // برای اعداد زوج بقیه‌ی حلقه را رد می‌کند
  }
  // بقیه‌ی حلقه...
}
```
