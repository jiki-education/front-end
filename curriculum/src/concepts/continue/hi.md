कई बार हम लूप से बाहर निकलने के बजाय उसके किसी एक खास इटरेशन को छोड़ना चाहते हैं। सोचिए कि हम केवल विषम संख्याओं के लिए ही कुछ करना चाहते हैं।

हम यह कह पाना चाहते हैं कि यदि `i` (इंडेक्स) विषम है, तो इस बार लूप न चलाइए।

लेकिन हम लूप से पूरी तरह बाहर नहीं निकलना चाहते। हम सिर्फ इस एक इटरेशन को छोड़ना चाहते हैं और फिर अगले इटरेशन पर जाना चाहते हैं।

और इसके लिए हमारे पास `continue` नामक एक और कीवर्ड है।

जब Jiki `continue` देखता है, तो वह अगले इटरेशन के लिए सीधे लूप के शीर्ष पर वापस चला जाता है। तो for-of लूप में, अगर वह `continue` देखता है, तो वह ऐरे के अगले आइटम पर चला जाता है।

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // "something" के लिए लूप के बाकी हिस्से को छोड़ देता है
  }
  // लूप का बाकी हिस्सा...
}
```

for लूप में, वह `i++` के इंक्रीमेंट पर पहुंचता है और फिर अगला इटरेशन शुरू करता है।

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // सम संख्याओं के लिए लूप के बाकी हिस्से को छोड़ देता है
  }
  // लूप का बाकी हिस्सा...
}
```
