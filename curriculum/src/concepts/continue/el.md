Υπάρχουν φορές που μπορεί να θέλουμε να παραλείψουμε μια συγκεκριμένη επανάληψη ενός βρόχου αντί να τον διακόψουμε. Φαντάσου ότι θέλουμε να κάνουμε κάτι μόνο για μονούς αριθμούς.

Θέλουμε να μπορούμε να πούμε: αν η `i` (μετρητής) είναι περιττή, μην εκτελέσεις τον βρόχο αυτή τη φορά.

Αλλά δεν θέλουμε να βγούμε εντελώς από τον βρόχο. Θέλουμε απλώς να παραλείψουμε αυτή τη μία επανάληψη και μετά να δούμε την επόμενη.

Και για αυτό, έχουμε μια άλλη λέξη-κλειδί που λέγεται `continue`.

Όταν ο Jiki βλέπει `continue`, απλά επιστρέφει στην αρχή του βρόχου για την επόμενη επανάληψη. Έτσι, σε έναν βρόχο for-of, αν δει `continue`, προχωρά στο επόμενο στοιχείο της λίστας.

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // Παραλείπει το υπόλοιπο του βρόχου για το "something"
  }
  // Το υπόλοιπο του βρόχου...
}
```

Σε έναν βρόχο for, εκτελεί την αύξηση του `i++` και μετά ξεκινά την επόμενη επανάληψη.

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // Παραλείπει το υπόλοιπο του βρόχου για ζυγούς αριθμούς
  }
  // Το υπόλοιπο του βρόχου...
}
```
