誰かに「20歳以上の人が来たらドアを開けてください」と頼まれたら、きっとどうすればいいかわかりますよね。でも、もし20歳以上で、**かつ**正しい服装をしているかどうかを同時に確認しなければならないとしたら？　つまり、二つの異なる条件を一度にチェックする必要があるわけです。どうすればいいでしょうか？

もしかすると、入れ子（英: _nested_）の`if`文を使うこともできます。以前に入れ子のループを学びましたが、それと似たようなものです。つまり、`age`が`20`より大きければ、このコードブロックに入り、さらに`outfit`が`"disco"`と等しければ、また別の中括弧と新しいコードブロックが続く、というふうに書くことができます。

これでも動きますが、かなりごちゃごちゃしてきます。とくに、たくさんの条件を扱いたいときには大変です。

ありがたいことに、もっと簡単な方法があります。それは、条件自体に複数の部分を持たせることです。一つの条件で1つだけチェックするのではなく、2つ、3つ、あるいはもっと多くのことを同時にチェックできます。そのために使うのが、`and`キーワードです。

ところが残念なことに、JavaScriptでは、andキーワードは実際には `and` という単語ではありません。言語によっては `and` と書くものもありますが、JavaScriptでは違います。代わりに、アンパサンド（英: _ampersand_）を2つ、続けて書く必要があります。

これは覚えるしかありません。ちょっと面倒ですが、そういうものだと思ってください。すぐに慣れます。

では、この`&&`を使って、より複雑な条件を作ってみましょう。たとえば、`age`が`20`より大きく、**かつ**`outfit`が`"disco"`であれば先に進む、といった具合です。もし`age`が`20`未満だったり、`outfit`が`"disco"`でなければ、その文全体、条件全体が偽になります。

論理学を学んだことがある人や、電子工作や少し高度な数学に触れたことがある人なら、これはとても自然に感じられるでしょう。経験がなくても、すぐに慣れます。

```javascript
if (age > 20 && outfit === "disco") {
  openDoor()
}
```

ANDとORの両方で、よくつまずくポイントがあります。それは、AND / OR（英: _and/or_）の左右それぞれが、完全な比較になっていなければならないという点です。たとえ同じ変数を両方の辺で比較している場合でも、繰り返して書く必要があります。

`if (age > 13 && < 20)` のような書き方はできません。`if (age > 13 && age < 20)` と書かなければなりません。

```javascript
if (age > 13 && age < 20)
```
