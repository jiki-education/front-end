Μέχρι τώρα, όποτε χρησιμοποιούσες τον βρόχο `repeat`, πάντα έδινες έναν αριθμό που λέει πόσες φορές να επαναλάβεις. Επανάλαβε πέντε φορές, 10 φορές, 40 φορές. Κάποιες φορές χρησιμοποίησες και μια μεταβλητή για να το κάνεις αυτό. Όμως πάντα έλεγες στον Jiki ακριβώς πόσες φορές να επαναλάβει τον βρόχο. Ωστόσο, μερικές φορές δεν ξέρουμε από πριν πόσες φορές θα χρειαστεί να επαναλάβουμε. Σκέψου τον λαβύρινθο. Στην αρχή αυτού του μαθήματος, έλυσες τον λαβύρινθο γράφοντας συγκεκριμένες κινήσεις. Μπορούσες να δεις τον λαβύρινθο, να μετρήσεις τα βήματα και να γράψεις τον σωστό αριθμό κινήσεων.

Άρα χρειάζεσαι έναν τρόπο να πεις απλώς στον Jiki να συνεχίσει. Να ελέγχει συνέχεια προς τα πού μπορεί να πάει, να παίρνει συνέχεια αποφάσεις, να προχωράει συνέχεια μπροστά, ξανά και ξανά μέχρι να τελειώσει.

Και ο τρόπος για να το κάνεις αυτό είναι πραγματικά απλός. Απλώς μη δώσεις αριθμό στη λέξη-κλειδί `repeat`. Άφησε απλώς αυτές τις αγκύλες κενές. Αν το κάνεις αυτό, ο Jiki απλώς θα συνεχίσει μέχρι κάτι άλλο να του πει να σταματήσει. Αργότερα θα δούμε ποια είναι αυτά τα «κάτι άλλα». Για την ώρα όμως, απλώς θα συνεχίσει μέχρι να ολοκληρωθεί η άσκηση, ή μέχρι να αποφασίσει ότι συνεχίζει εδώ και πάρα πολλή ώρα, ότι θέλει ένα διάλειμμα και ότι πλέον του αρκεί.
