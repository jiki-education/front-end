Μέχρι τώρα, όταν έγραφες συναρτήσεις, κάθε μία στεκόταν σχεδόν μόνη της και περιείχε όλη τη λογική που χρειαζόταν για να λειτουργήσει.

Τώρα θα δούμε πώς να σπάμε τις συναρτήσεις ώστε να έχουμε μικρότερες συναρτήσεις που συνεργάζονται, αντί για μεγάλες συναρτήσεις που έχουν πολλά πράγματα ταυτόχρονα.

Ως γενικός κανόνας στον προγραμματισμό, θέλεις κάθε συνάρτηση να κάνει το ελάχιστο δυνατό. Αυτό το ονομάζουμε μια συνάρτηση που έχει αποκλειστική ευθύνη (_single responsibility_ στα αγγλικά). Κάθε συνάρτηση θα πρέπει να κάνει μόνο ένα πράγμα και να χρησιμοποιεί άλλες συναρτήσεις για τα διαφορετικά υπο-κομμάτια του.

Ας δούμε λοιπόν ένα παράδειγμα.

Φαντάσου ότι έχουμε μια συνάρτηση που η δουλειά της είναι να επιστρέφει μια συμβολοσειρά που περιγράφει ένα όνομα.

Μια απλή εκδοχή θα ήταν κάπως έτσι. Έχουμε έναν βρόχο μέτρησης, κάτι που έχεις ήδη γράψει, και μετά ένα πρότυπο συμβολοσειράς που συνθέτει το αποτέλεσμα.

```javascript
function describeName(name) {
  let length = 0
  for (const letter in name) {
    length += 1
  }
  return `This name is ${length} letters long`
}
```

Αυτό λειτουργεί μια χαρά, αλλά κάνει δύο πράγματα. Κάνει ένα αρκετά γενικό πράγμα, το μέτρημα, και ένα άλλο πολύ συγκεκριμένο, το να φτιάχνει αυτή τη συμβολοσειρά σε μια συγκεκριμένη μορφή.

Θα ήταν πολύ ωραιότερο να το σπάσουμε σε δύο συναρτήσεις, μία που είναι υπεύθυνη για το μέτρημα και μία που είναι υπεύθυνη για την περιγραφή ενός ονόματος σε αυτή τη συγκεκριμένη μορφή.

```javascript
// Απλά μετράει γράμματα
function countLetters(str) {
  let count = 0
  for (const letter in str) {
    count += 1
  }
  return count
}

// Απλά μορφοποιεί το κείμενο όμορφα
function describeName(name) {
  const count = countLetters(name)
  return `The name has ${count} letters`
}
```

Και μπορούμε στη συνέχεια να επαναχρησιμοποιήσουμε αυτή τη γενική συνάρτηση μέτρησης σε αυτή τη μορφοποίηση συμβολοσειράς, αλλά και σε οποιοδήποτε άλλο μέρος χρειαζόμαστε. Όποτε χρειάζεται να μετρήσουμε γράμματα σε μια συμβολοσειρά, είναι εντελώς αποσυνδεδεμένη από οτιδήποτε έχει σχέση με την εκτύπωση.

Μπορείς να διαβάσεις και τις δύο συναρτήσεις απομονωμένα και να καταλάβεις αμέσως τι κάνει η καθεμία.

Καθώς οι συναρτήσεις σου γίνονται πιο πολύπλοκες και έχεις περισσότερες από αυτές, αυτή η τεχνική είναι η διαφορά ανάμεσα στο να έχεις τακτοποιημένο, ευανάγνωστο κώδικα και στο απόλυτο χάος και ακαταστασία.

Υπάρχει ένα πράγμα που αξίζει να αναφέρουμε ξανά εδώ, και αυτό είναι ότι οτιδήποτε δημιουργείς μέσα σε μια συνάρτηση δεν μπορεί να προσπελαστεί από άλλες συναρτήσεις εκτός αν το επιστρέψεις σκόπιμα.

Έτσι, αν προσπαθήσεις να αναφερθείς στη μεταβλητή `count` (μετρητής) από μέσα από την `describeName` (περιγραφή ονόματος), δεν μπορείς να το κάνεις, καθώς ανήκει στην άλλη συνάρτηση.

Στη JavaScript, μπορούμε να δημιουργήσουμε μεταβλητές στην κορυφή πάνω από όλα που μοιράζονται μεταξύ των συναρτήσεων, αλλά πραγματικά σου συνιστώ να μην το κάνεις αυτό εκτός αν υπάρχει πολύ καλός λόγος.

Όσο περισσότερο κρατάς κάθε συνάρτηση ανεξάρτητη, και η τεχνική λέξη για αυτό είναι _pure_ (καθαρή), pure συναρτήσεις, τόσο πιο καθαρός θα είναι ο κώδικάς σου και τόσο λιγότερα bugs θα δημιουργείς και θα έχεις.
