Ξέρεις ήδη τι είναι οι συμβολοσειρές. Είναι χαρτάκια με κείμενο πάνω τους.

Μέχρι τώρα, κάθε συμβολοσειρά που έχεις χρησιμοποιήσει είναι κάποια που έχεις πληκτρολογήσει απευθείας. Τι γίνεται αν θέλεις να φτιάξεις μια συμβολοσειρά βασισμένη σε μεταβλητές ή συνθήκες; Πώς το κάνουμε αυτό;

Υπάρχουν δύο τρόποι.

Η πρώτη ονομάζεται _string concatenation_ (συνένωση συμβολοσειρών), που είναι ένας φανταχτερός και λίγο μπερδευτικός τρόπος να πεις πρόσθεση δύο συμβολοσειρών.

Φαντάσου ότι έχεις δύο λέξεις, την `"hello"` (γεια) και την `"world"` (κόσμος), και θέλεις να δημιουργήσεις μια συμβολοσειρά που να περιέχει το `"hello world"`.

Θα μπορούσες απλώς να γράψεις το `"hello world"` ως μία συμβολοσειρά, αλλά θα μπορούσες επίσης να γράψεις `"hello " + "world"`, και αυτό θα σου έδινε την ίδια συμβολοσειρά.

Τώρα, προφανώς, αυτό δεν είναι και τόσο χρήσιμο σε αυτή την περίπτωση. Αλλά τι θα γινόταν αν είχαμε μια μεταβλητή με το όνομα κάποιου μέσα και θέλαμε να του πούμε γεια;

Φαντάσου λοιπόν ότι έχουμε μια μεταβλητή που ονομάζεται `name` (όνομα), και περιέχει το `"Jeremy"` άλλοτε και το `"Jiki"` άλλοτε. Θέλουμε να πούμε `"hello Jeremy"` ή `"hello Jiki"` χρησιμοποιώντας αυτή τη μεταβλητή.

Λοιπόν, μπορούμε να το πετύχουμε αυτό χρησιμοποιώντας αυτή την έννοια της συνένωσης:

```javascript
"hello " + name // "hello Jeremy" or "hello Jiki"
```

Αυτό θα μας δώσει είτε το `"hello Jeremy"` ή το `"hello Jiki"`, ή γεια σε οποιονδήποτε άλλον, ανάλογα με το τι βρίσκεται μέσα στο κουτί `name`.
