Ας πούμε ότι θέλουμε μια σειρά λουλούδια. Μπορούμε να γράψουμε κάτι σαν αυτό. Ορίζουμε μια θέση, φυτεύουμε ένα λουλούδι, αυξάνουμε τη θέση κατά 10, επαναλαμβάνουμε, και καταλήγουμε με μια ωραία τακτοποιημένη σειρά λουλουδιών.

```javascript
let x = 10
repeat(5) {
  plant(x, 50, 10)
  x = x + 10
}
```

Έχουμε έναν βρόχο που σχεδιάζει μια σειρά λουλουδιών. Πώς μπορείς να τον χρησιμοποιήσεις για να σχεδιάσεις τέσσερις σειρές; Ή τι θα μπορούσαμε να κάνουμε για να σχεδιάσουμε τέσσερις σειρές;

Μια επιλογή θα ήταν απλώς να αντιγράψουμε και να επικολλήσουμε αυτόν τον βρόχο τέσσερις φορές και να αλλάξουμε την επάνω θέση για κάθε μία. Και αυτό θα δούλευε. Θα ήταν εντάξει. Αλλά είναι επαναλαμβανόμενο, και υπάρχει καλύτερος τρόπος. Ξέρουμε ότι όταν ο κώδικας είναι επαναλαμβανόμενος, μπορούμε να χρησιμοποιήσουμε έναν βρόχο για να απλοποιήσουμε τα πράγματα.

Έτσι, εδώ μπορούμε να χρησιμοποιήσουμε έναν βρόχο μέσα σε έναν άλλο βρόχο. Έναν βρόχο για τις σειρές και έναν για τα λουλούδια σε αυτήν τη σειρά. Ας ξεκινήσουμε, λοιπόν, προσθέτοντας έναν βρόχο `repeat` γύρω από τον υπάρχοντα κώδικα, για να το καταλάβεις. Και θα το επαναλάβουμε μόνο μία φορά. Λέμε, λοιπόν, στον Jiki να κάνει όλα όσα βρίσκονται μέσα σε αυτά τα εξωτερικά άγκιστρα μία φορά. Άρα αυτό έχει ακριβώς το ίδιο αποτέλεσμα με το να μην έχουμε καθόλου αυτόν τον εξωτερικό βρόχο. Λέμε στον Jiki να επαναλάβει κάτι μία φορά, που είναι το ίδιο με το να του λέμε να το κάνει χωρίς τον `repeat`. Αλλά έτσι λειτουργεί αυτός ο κώδικας. Είναι θεμιτός, έγκυρος κώδικας. Έχουμε έναν βρόχο μέσα σε έναν άλλο βρόχο.

Τώρα, τι γίνεται αν αλλάξουμε αυτόν τον εξωτερικό βρόχο ώστε να επαναλαμβάνει δύο φορές; Έτσι, ο Jiki θα εκτελέσει ολόκληρο το `plant` (φυτεύω) πέντε φορές, δύο φορές. Θα φυτέψει 10 λουλούδια. Αλλά όλα αυτά τα λουλούδια θα βρίσκονται στην ίδια σειρά.

Έτσι, με τον ίδιο τρόπο που χρειαζόμαστε να μετακινήσουμε τη θέση από αριστερά προς τα δεξιά λίγο κάθε φορά, αφού έχουμε σχεδιάσει κάθε πλήρη σειρά, πρέπει επίσης να μετακινήσουμε και την κατακόρυφη θέση. Πώς το κάνουμε αυτό; Λοιπόν, μπορούμε να προσθέσουμε μια εξωτερική μεταβλητή για την επάνω θέση, να τη χρησιμοποιήσουμε στη συνάρτησή μας `plant`, και μετά να την αυξήσουμε κατά 10 μετά από κάθε σειρά.

Σκέψου, λοιπόν, ποια είναι η τιμή κάθε φορά. Η επάνω θέση ξεκινά από το 10. Για τις πρώτες πέντε φορές που φυτεύουμε, παραμένει έτσι. Η αριστερή θέση αυξάνεται. Και μετά προσθέτουμε άλλα 10 σε αυτήν, στην επάνω θέση, και φυτεύουμε πέντε ακόμα λουλούδια λίγο πιο κάτω. Επαναφέρουμε την αριστερή θέση πάλι στο 10, και μετά την αυξάνουμε ξανά κάθε φορά.

Και τώρα μπορούμε να πούμε επανάλαβε αυτό τέσσερις φορές, και θα πάρουμε τέσσερις σειρές των πέντε φυτών.

```javascript
let y = 10
repeat(4) {
  let x = 10
  repeat(5) {
    plant(x, y, 10)
    x = x + 10
  }
  y = y + 10
}
```

Το βασικό που πρέπει να καταλάβεις είναι ότι ο Jiki ολοκληρώνει όλη τη δουλειά στον εσωτερικό βρόχο (_inner loop_ στα αγγλικά) πριν επιστρέψει στον εξωτερικό βρόχο (_outer loop_ στα αγγλικά). Δεν πηγαινοέρχεται μπρος πίσω. Ολοκληρώνει τον εσωτερικό βρόχο και μετά προχωρά στο επόμενο βήμα του εξωτερικού βρόχου.

Σε αυτήν την περίπτωση, μπορείς να σκεφτείς τον εξωτερικό βρόχο ότι ελέγχει τις ομάδες ή τη σειρά, και τον εσωτερικό βρόχο ότι ελέγχει κάθε στοιχείο σε αυτήν την ομάδα ή κάθε στοιχείο σε αυτήν τη σειρά. Έτσι, στο παράδειγμά μας, ο εξωτερικός βρόχος φτιάχνει τέσσερις σειρές και ο εσωτερικός βρόχος βάζει πέντε φυτά, πέντε στοιχεία σε κάθε ομάδα.
