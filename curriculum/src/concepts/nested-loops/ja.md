花を一列に植えたいとしましょう。次のように書けます。まず位置を決めて、花を植え、位置を10ずつ増やし、繰り返します。そうすると、きれいに整った花の列ができあがります。

```javascript
let x = 10
repeat(5) {
  plant(x, 50, 10)
  x = x + 10
}
```

花を1列描くループがすでにあります。これを使って4列描くにはどうすればいいでしょうか？　あるいは、4列描く方法には何があるでしょうか？

ひとつは、そのループを4回コピー＆ペーストして、それぞれの行の縦位置を変える方法です。それでも動きますし、悪くありません。でも、繰り返しが多くて、もっといい方法があります。コードが繰り返しだらけのときは、ループを使ってシンプルにできるのを知っていますよね。

そこで、ループの中にループを入れます。行用のループと、その行の花用のループの2つです。では、まずは既存のコードのまわりにもう1つ`repeat`ループを追加して、イメージをつかみましょう。最初は1回だけ繰り返すようにします。つまり、外側の波括弧の中にあるすべてを1回だけやるようJikiに指示します。これは外側のループをまったく付けないのと同じ効果です。1回繰り返すと言うのは、繰り返しなしでやれと言うのと同じですからね。でも、これがコードの動きです。ちゃんと動く、正しいコードです。ループの中に別のループが入っています。

では、外側のループを2回繰り返すように変えたらどうなるでしょう？　Jikiは`plant`（植える）の5回の処理をまるごと2回実行することになります。花を10本植えます。でも、それらは全部同じ行に植えられてしまいます。

同じように、左から右へと少しずつ位置を動かすのと同様に、1行分を描き終えたら縦位置も動かす必要があります。どうやってでしょう？　縦位置用の外側の変数を用意し、`plant`関数でそれを使い、行が終わるたびに10ずつ増やせばいいのです。

それぞれのタイミングで値がどうなっているか考えてみましょう。縦位置は10から始まります。最初の5回の植え付けの間はそのままです。左位置は増えていきます。その後、縦位置にさらに10を足して、少し下がったところでさらに5本の花を植えます。左位置はまた10にリセットされ、その後は毎回少しずつ増えていきます。

そして、これを4回繰り返すようにすれば、5本ずつの花が4行並んだグリッドができあがります。

```javascript
let y = 10
repeat(4) {
  let x = 10
  repeat(5) {
    plant(x, y, 10)
    x = x + 10
  }
  y = y + 10
}
```

大事なポイントは、Jikiは内側のループ（英: _inner loop_）の作業をすべて終えてから外側のループ（英: _outer loop_）に戻るということです。行ったり来たりするわけではありません。内側のループを完了してから、外側のループの次のステップに進みます。

この場合、外側のループがグループや行を制御し、内側のループがそのグループ内の各要素や行内の各アイテムを制御していると考えることができます。この例では、外側のループが4行を作り、内側のループが各グループに5つの植物（5つのアイテム）を配置しています。
