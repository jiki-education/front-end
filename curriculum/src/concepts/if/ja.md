あるキーワードを使うと、特定の状況でのみ Jiki に指示を出すことができます。たとえば、バーの入り口を守るコードを書いているとしましょう。あなたは門番で、きちんとした服装の人にだけ Jiki がドアを開けるようにしたい。あるいは、レースの最後にチェッカーフラッグを振る役目のコードを書いているとしましょう。でも Jiki は、最終ラップのときだけ旗を振ればいいと知る必要があります。こういうときに使うのが、`if` キーワードです。

`if` キーワードの使い方は、`repeat` キーワードとよく似ています。括弧（`()`）の中に情報を入れます。この場合、その情報はチェックしたい条件（英: _condition_）です。そして、波括弧（`{}`）の中に、その条件が真のときだけ実行するコードブロックを書きます。

```javascript
if (condition) {
}
```

では、条件はどんなふうに書くのでしょうか？　たいていは、何らかの比較（英: _comparison_）です。2 つの数値や文字列を比較し、その結果が真か偽かをチェックします。

これらは、声に出して言える命題（英: _statement_）だと考えてください。「3 は 5 より小さい」。これは真です。「7 は 2 より小さい」。これは偽です。

これらの比較を書くときには、記号を使います。数学でおなじみの記号ばかりです。「より小さい」「より大きい」「以下」「以上」があり、さらに、2 つのものが同じかどうか、等しいかどうかを調べる記号もあります。この最後のものは、少し変わっています。2 つのものが等しいかどうかを調べるのに、イコールを 3 つ続けて書くのです。

こうすることで、変数を作ったり更新したりするときに「この値を箱に入れて」という意味で使うイコール 1 つと混同しなくなります。比較にはイコール 3 つ、と覚えておきましょう。

文字列も比較できます。つまり、`"hello"` は `"hello"` と等しい——これは真です。2 つの文字列が同じということです。ただし、ここは注意が必要です。Jiki は 2 枚の紙に書かれた文字列の、すべての文字（英: _character_）を 1 つずつ比較します。ですから、大文字の `H` で始まる `"Hello"` と、小文字の `h` の `"hello"` は同じではありません。別の文字列です。比較した結果は偽になります。大文字の `H` と小文字の `h` は異なる文字だからです。

ところで、真と偽のことは「真偽値（英: _Boolean_）」と呼ばれます。また専門用語が出てきました。でも、中身はとてもシンプルです。何かが真か偽のどちらかである、ということを正式に言っているだけです。真偽値という言葉が出てきたら、それは単に「真か偽か」という意味だと思ってください。実際の動きを見てみましょう。クラブのロボット門番を作っていると想像してください。門番は、その人が 21 歳以上の場合にだけドアを開ける、というルールにします。まず、誰かの年齢を取得するための `askAge`（年齢を尋ねる）関数があります。この関数の結果を、`age`（年齢）という変数に保存します。そして、もし `age` が 20 より大きければ、ドアを開ける、と書きます。`askAge` が `30` を返せば、ドアが開きます。`12` を返せば、開きません。

```javascript
let age = askAge()
if (age >= 21) {
  openDoor()
}
```
