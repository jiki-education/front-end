如果你用代码做任何视觉相关的事（就算你想成为数据科学家，觉得所有画图的东西有点无聊，但通过视觉传达数据也是一项关键技能），那么有两种不同的表示颜色的方式。你已经在绘图函数中使用过诸如红色或黄色这样带有名称的颜色作为最后的输入，这是快速使用颜色的一种好方法，但它的局限性很大。我们能用的有名称的颜色只有很少的几个。所以现在我们要来看看两种能表示任何你想要的颜色的方法，这两种方法分别叫做 RGB 和 HSL。

RGB 让我们把颜色想象成红色、绿色和蓝色的混合。这就是 RGB 的含义：红色（英语：_red (R)_）、绿色（英语：_green (G)_）、蓝色（英语：_blue (B)_）。如果你还记得在学校里混合颜料，这是一个类似的概念，只不过我们混合的不是颜料，而是光。

在很多练习里，你都会遇到一个叫 `rgb` 的函数，它接收三个数字作为输入，一个代表红色，一个代表绿色，一个代表蓝色，然后它会返回一个颜色。

你可以作为输入的数字范围是 0 到 `255`。0 表示我不想要任何这种颜色，而 `255` 表示尽可能多地加入这种颜色。所以如果我们给 `rgb` 函数传入 `255`、0 和 0 作为输入，我们就是在说，我要全部的红色。记住，`255` 是你能填入的最大数字。但我们不想要任何绿色或蓝色，所以这两个都是 0。这样我们就得到了红色，我们可以把这个红色存到一个变量里，然后像我们之前用有名称的字符串那样，在 `circle` 函数中使用它。那么如果我们用 `rgb` 函数传入 0、`255`、0 呢？现在我们说的是没有红色，全部绿色，没有蓝色。所以我们会得到一个绿色的圆。如果我们要黄色呢？黄色是红色和绿色的混合。所以我们可以说，给我全部的红色，全部的绿色，没有蓝色，这样就会得到黄色。我们还可以用更小的数字。所以如果我们想要一些红色，不要绿色，很多蓝色，我们会得到紫色。很多红色，一点点绿色，再多一点蓝色，就会得到粉色。这就是 RGB。我们混合红色、绿色和蓝色来得到不同的组合。

```javascript
let red = rgb(255, 0, 0)
let green = rgb(0, 255, 0)

```

现在让我们来看看 HSL，它给我们一种完全不同的思考颜色的方式。HSL 代表色相（英语：_hue (H)_）、饱和度（英语：_saturation (S)_）和明度（英语：_lightness (L)_）。和 RGB 类似，你有一个叫 `hsl` 的函数，它接收三个数字，一个代表色相，一个代表饱和度，一个代表明度，然后它会返回一个颜色。我们来分解一下这三个词的含义。

色相是你想要的颜色色调（英语：_shade_），它的范围是从 0 到 360。也许可以想象一道彩虹。我是这样想的：左边是红色，然后是橙色、黄色、绿色、蓝色、紫色，实际上，我们最后还会回到红色。所以如果你说 0，你就从左边开始，那是红色。如果你说 `120`，你就是在要绿色。`230` 是蓝色。你也可以把这想象成一个色轮（英语：_color wheel_），360 实际上就是它的度数，也就是圆圈里的角度。我总是直接查我想要的数字，所以不用太担心要记住这些，但了解其中的原理也挺好。所以这就是色相，也就是色调。接下来，我们有饱和度，它表示颜色的鲜艳程度。它的范围从 0 到 100。为 0 时，你只会得到灰色，没有任何颜色，没有任何色调。为 100 时，你会得到丰满、鲜明、生动的颜色。然后我们还有明度。明度是颜色的明亮程度，它的范围也是从 0 到 100。为 0 时，你会得到黑色。不管你选择了什么色相，你都会得到黑色，里面没有任何光。为 100 时，你会得到白色。不管其他参数如何，它就是充满了光，所以是白色。50 刚好在中间，是正常的颜色。所以你可以把它想象成一个滑块（英语：_slider_），用来让颜色变得明亮或暗淡。

所以，如果我们想要一个正常的红色圆，在 RGB 中我们会写成 255, 0, 0，全部红色，没有绿色，没有蓝色，在这里我们会用 0, 100, 50。0 代表红色色相，100 代表饱和度，全彩，50 代表亮度，这是正常的亮度级别。如果我们想把它变成绿色的圆，我们只要把色相改成 `120`。如果我们想把它变成深绿色，可以把明度降到 `25`。

如果我们想让它变成暗一点的绿色，我们可以去掉一些颜色，降低一些饱和度，比如把它降到 `30`。

如果你想要一个明亮的亮粉色，色相大约 300 就是粉色，然后我们把饱和度调到 100 让它非常鲜艳，同时也把明度调到 60 左右。

```javascript
let red = hsl(0, 100, 50)
let green = hsl(120, 100, 50)
let darkGreen = hsl(120, 100, 25)
let dullGreen = hsl(120, 30, 50)
let hotPink = hsl(300, 100, 60)
```

这样我们就有了两种不同的表示颜色的方式，它们在不同的场合各有用途。当你想要调整一个特定的分量时，比如多少红色、多少绿色、多少蓝色，RGB 很棒。当你想要循环遍历各种颜色时，HSL 很棒。如果你想要一道彩虹，你只要不断增加色相就行了。
