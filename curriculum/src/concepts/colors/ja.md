コードでビジュアルなことを何かする場合（データサイエンティストを目指していて、描画の話はちょっと退屈だと思っている人でも、データを視覚的に伝えるのは重要なスキルです）、色を表現する方法は2つあります。これまでは、描画関数の最後の入力として、`red`や`yellow`のような色の名前を使ってきましたが、それは手軽に色を使うには便利な方法でした。しかし、名前付きの色は限られた数しか使えません。そこで、ここからは好きな色を表現するための2つの方法を見ていきましょう。その2つとは、RGBとHSLです。

RGBは色を赤、緑、青の混ぜ合わせとして考えます。RGBとは、赤（英: _red (R)_）、緑（英: _green (G)_）、青（英: _blue (B)_）の頭文字です。学校で絵の具を混ぜたことを覚えていますか？　それと似た考え方ですが、ここでは絵の具ではなく光を混ぜます。

多くの演習では、`rgb`という関数を使います。この関数は3つの数値を入力として受け取り、それぞれ赤、緑、青に対応し、色を返します。

入力に使える数値は0から`255`までです。0はその色をまったく使わないことを意味し、`255`はその色を可能な限り多く混ぜることを意味します。ですから、`rgb`関数に`255`、0、0を入力として渡すと、「赤を全部使う」という意味になります（`255`が最大値なので）。緑も青も使いたくないので、それらは0です。すると赤色が返ってきて、その赤を変数に保存し、これまで名前付き文字列で行ってきたように`circle`関数で使うことができます。では、`rgb`関数に0、`255`、0を渡すとどうなるでしょうか？　今度は、赤はなし、緑を全部、青はなし、ということになります。すると、緑色の円が得られます。黄色がほしい場合はどうでしょう？　黄色は赤と緑の混ぜ合わせです。ですから、赤を全部、緑を全部、青はなし、と指定すれば黄色になります。もっと小さな数値も使えます。赤を少し、緑はなし、青をたくさんにすると、紫色になります。赤をたっぷり、緑を少し、青を少し多めにすると、ピンク色になります。以上がRGBです。赤、緑、青を混ぜて、さまざまな組み合わせを作り出します。

```javascript
let red = rgb(255, 0, 0)
let green = rgb(0, 255, 0)
let yellow = rgb(255, 255, 0)
let pink = rgb(230, 50, 170)
```

では、HSLを見てみましょう。これは色をまったく別の視点からとらえる方法です。HSLは、色相（英: _hue (H)_）、彩度（英: _saturation (S)_）、明度（英: _lightness (L)_）の頭文字です。RGBと同様に、`hsl`という関数を使います。この関数は3つの数値（色相、彩度、明度）を入力として受け取り、色を返します。では、この3つの単語の意味を分解してみましょう。

色相は、欲しい色の色合いを指します。値は0から360までです。虹を想像してみてください。私の考え方では、左端が赤、続いてオレンジ、黄色、緑、青、紫と並び、実際にはぐるっと回って元の赤に戻ります。つまり、0を指定すると左端の赤から始まり、`120`を指定すると緑、`230`だと青になります。これは色相環（英: _color wheel_）とも考えられます。360というのは、実際には円の角度の度数です。私はいつも必要な数値を調べるだけなので、必死に覚えようとしなくても大丈夫ですが、仕組みを知っておくと便利です。これで色相、つまり色合いの説明は終わりです。次に彩度です。彩度は色の鮮やかさを表し、0から100までの値を取ります。0ではただの灰色になります。色味もトーンもまったくありません。100では、完全に鮮やかで生き生きとした色になります。そして明度です。明度は色の明るさで、これも0から100までの値を取ります。0では、どんな色相を選んでも黒になります。光がまったくないからです。100では白になります。他の要素に関係なく、光に満ちているので白になるのです。50がちょうど真ん中で、通常の色です。これは、色を明るくしたり暗くしたりするためのスライダーと考えることができます。

では、通常の赤い円を作りたい場合、RGBでは`255`、0、0（赤を全部、緑はなし、青はなし）と書きましたが、HSLでは`0`、`100`、`50`を使います。`0`は赤の色相、`100`の彩度で完全な色、`50`の明度で普通の明るさです。これを緑色の円にしたいなら、色相を`120`に変えるだけです。もっと暗い緑にしたい場合は、明度を`25`まで下げます。

彩度を`30`まで下げると、くすんだ緑になります。

明るく鮮やかなピンク（ホットピンク）がほしい場合、色相を約`300`（ピンク）にし、彩度を`100`にして非常に鮮やかに、明度も`60`くらいまで上げます。

```javascript
let red = hsl(0, 100, 50)
let green = hsl(120, 100, 50)
let darkGreen = hsl(120, 100, 25)
let dullGreen = hsl(120, 30, 50)
let hotPink = hsl(300, 100, 60)
```

このように、色を表現する方法は2つあり、それぞれ状況によって便利です。RGBは特定の要素（赤、緑、青の量）を調整したいときに最適です。HSLは、色を順に変化させたいときに便利です。虹を作りたければ、色相をどんどん増やしていけばいいのです。
