Όταν γράφεις κώδικα, αυτό που κάνεις στην πραγματικότητα είναι να λες τι θέλεις να συμβεί, σε μια γλώσσα που καταλαβαίνει ο υπολογιστής. Υπάρχουν πολλές διαφορετικές γλώσσες προγραμματισμού, και πολλοί διαφορετικοί διερμηνευτές που παίρνουν αυτό που γράφεις και το μετατρέπουν στα μηδενικά και τους άσσους που μπορεί να καταλάβει ένας υπολογιστής. Σε αυτό το μάθημα, ο διερμηνευτής σου είναι ο Jiki. Όλο το μάθημα πήρε το όνομά του από τον Jiki. Αυτός είναι ο Jiki. Ο Jiki θα είναι ο φίλος σου σε αυτό το ταξίδι στον προγραμματισμό. Δουλειά του είναι να διερμηνεύει τον κώδικα που γράφεις και να τον μετατρέπει σε μηδενικά και άσσους, με τους οποίους μπορεί πραγματικά να δουλέψει ο υπολογιστής.

Το νόημα του προγραμματισμού είναι να δίνεις στον διερμηνευτή, στον Jiki σε αυτή την περίπτωση, τις σωστές εντολές. Υπάρχουν πολλές διαφορετικές εντολές που μπορείς να δώσεις στον Jiki, πολλά πράγματα που καταλαβαίνει. Μπορεί να κολλάει πράγματα μεταξύ τους, μπορεί να κάνει κάτι πολλές φορές, μπορεί να πει: "Αν συμβεί αυτό, τότε πρέπει να κάνω εκείνο." Μπορεί να θυμάται πράγματα και να τα χρησιμοποιεί ξανά αργότερα. Μπορεί να σου πετάξει ένα σφάλμα αν κάτι δεν είναι σωστό. Θα καλύψουμε όλα αυτά τα πράγματα σε αυτό το μάθημα. Το βασικό, όμως, που πρέπει να καταλάβεις είναι ότι ό,τι κάνεις από εδώ και πέρα είναι να γράφεις εντολές σε έναν ασπροπίνακα, για να έρθει ο Jiki και να τις ακολουθήσει.

Όταν έμαθα να προγραμματίζω πριν από 34 χρόνια, αυτό ήταν το νοητικό μοντέλο που έφτιαξα, και είναι το ίδιο που έχω ακόμα σήμερα. Καταλαβαίνω πώς δουλεύουν οι υπολογιστές μέχρι το επίπεδο των μηδενικών και των άσσων, αλλά ειλικρινά δεν το σκέφτομαι ποτέ. Στο μυαλό μου, μέσα στον υπολογιστή ζει ένας μικρός άνθρωπος, και εγώ του λέω τι να κάνει. Έλα, λοιπόν, μαζί μου σε αυτό. Είναι ένα δυνατό νοητικό μοντέλο που μπορείς να φτιάξεις, και αν αρχίσεις να σκέφτεσαι τα πράγματα με αυτόν τον πολύ οπτικό τρόπο, δηλαδή τι κάνει ο άνθρωπος μέσα στον υπολογιστή, θα σε βοηθήσει πολύ καθώς μαθαίνεις να προγραμματίζεις.

Ας ξεκινήσουμε, λοιπόν, κοιτάζοντας μία από τις θεμελιώδεις έννοιες του προγραμματισμού, τις συναρτήσεις (_functions_ στα αγγλικά). Οι συναρτήσεις είναι σαν μικρές μηχανές που μπορείς να πεις στον Jiki να χρησιμοποιήσει, και αν κοιτάξουμε μέσα στην αποθήκη του Jiki, εκεί όπου περνάει την ώρα του, θα δεις ότι έχει ένα ράφι με τρεις διαφορετικές μηχανές: `move` (κίνηση), `turnLeft` (στρίψε αριστερά) και `turnRight` (στρίψε δεξιά).

Όταν έγραψες `move` και μετά αυτές τις δύο παρενθέσεις, αυτό που έκανες ήταν να πεις στον Jiki να πάει να πάρει τη μηχανή `move` από το ράφι, να γυρίσει τη μανιβέλα, να τη βάλει σε λειτουργία και να τη χρησιμοποιήσει.

Όταν έγραψες `turnLeft` και μετά τις παρενθέσεις, έλεγες στον Jiki να πάρει τη μηχανή `turnLeft` από το ράφι και να τη χρησιμοποιήσει. Και αυτό είναι το μοτίβο που θα χρησιμοποιείς ξανά και ξανά. Όποτε θέλεις να χρησιμοποιήσεις μια μηχανή, θα γράφεις το όνομά της και μετά αυτές τις παρενθέσεις, και αυτό λέει στον Jiki να πάει να φέρει τη μηχανή και να τη χρησιμοποιήσει:

```javascript
move()
turnLeft()
```

Πώς δουλεύει στην πραγματικότητα αυτή η μηχανή, τι συμβαίνει μέσα της, δεν χρειάζεται να μας απασχολεί για την ώρα. Θα το δούμε με πολύ περισσότερη λεπτομέρεια αργότερα. Μάλιστα, δεν θα περάσει πολύς καιρός μέχρι να μπορείς να φτιάχνεις και τις δικές σου μηχανές. Προς το παρόν, όμως, μην ανησυχείς για αυτό. Σε κάθε άσκηση θα σου λέμε ποιες μηχανές υπάρχουν στο ράφι του Jiki. Θα είναι διαφορετικές σε κάθε άσκηση, και θα μπορείς να χρησιμοποιείς αυτές τις μηχανές για να λύσεις τις ασκήσεις.
