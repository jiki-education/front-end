コードを書くということは、コンピューターが理解できる言葉で、自分がやりたいことを伝えるということです。プログラミング言語にはたくさんの種類があり、書かれたコードをコンピューターが理解できる 1 と 0 に変換してくれるインタプリター、つまり通訳の役割を担うプログラムも、いろいろなものがあります。このコースでは、Jiki が通訳をしてくれます。コースの名前も Jiki から来ています。これがその Jiki です。Jiki は、プログラミングの旅を案内してくれる友達です。Jiki の仕事は、皆さんの書いたコードを解釈して、コンピューターがわかる 1 と 0 に変換することです。

プログラミングの本質は、通訳者（ここでは Jiki）に正しい指示を出すことです。Jiki に出せる指示はたくさんあり、Jiki が理解できることもたくさんあります。たとえば、何かをつなげたり、何かを何度も繰り返したり、「もしこうなったら、こうする」と判断したりすることができます。また、一度覚えたことを後で使ったり、何かがおかしくなったときにエラーを出したりもできます。このコースでは、そういったさまざまなことをひとつずつ取り上げていきます。ただ、ここで大切なのは、皆さんがこれからやることはすべて、ホワイトボードに指示を書いて、Jiki にそれを実行してもらうことだ、という点です。

私が 34 年前にプログラミングを覚えたとき、こんなイメージにたどり着きました：「コンピューターの中に小さな人が住んでいて、その人に『これをやって』と伝えている」。そして、そのイメージは今でも変わりません。少しおかしく聞こえるかもしれませんが、意外と役に立つ考え方なので、ぜひ取り入れてみてください。コンピューターの仕組みは 1 と 0 のレベルまで理解しているつもりですが、正直なところ、そこまで考える必要はないと思っています。コンピューターの中の人が何をしているのかを想像すると、抽象的なプログラミングも具体的なイメージに落とし込めます。プログラミングを学んでいく中で、この力が助けになる場面はたくさんあります。

それでは、プログラミングの基本的な考え方のひとつである、関数（英: _function_）を見てみましょう。関数は、Jiki に使うように指示できる小さな機械のようなものです。Jiki がいつもいる倉庫を覗いてみると、棚の上に 3 つの機械が置いてあります。`move`（前に進む）、`turnLeft`（左に向く）、そして `turnRight`（右に向く）です。

`move` と書いて、その後に括弧を付けることは、Jiki に棚から `move` の機械を取り、クランクを回して電源を入れて、使うように指示していることになります。

  class="concept-image"

  width="439"

/>

`turnLeft` と括弧を書いたときは、Jiki に `turnLeft` の機械を棚から取って使うように指示していたのです。これはこれからも何度も使うパターンです。機械を使いたいときは、いつも名前を書いてその後に括弧を付ける。これで Jiki に、その機械を取りに行って使うように伝えているのです。

```javascript
move()
turnLeft()
```

しかし、その機械が実際にどのように動くのか、機械の中で何が起きているのか、今は気にする必要はありません。それについては、あとで詳しく見ていきます。実は、そう遠くないうちに、皆さん自身もこのような機械を作れるようになります。でも、今のところは気にしないでください。各演習では、Jiki の棚にどんな機械があるかが示されます。演習ごとに違う機械が用意されていて、それらを使って問題を解きます。
