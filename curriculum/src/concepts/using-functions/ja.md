コードを書くというのは、つまり「こうしてほしい」という内容を、コンピューターにわかる言葉で伝えることです。プログラミング言語にはいろいろな種類があり、書いたコードをコンピューターがわかる 1 と 0 に変換してくれる通訳（英: interpreter）も、いろいろなものがあります。このコースでの通訳は Jiki です。コースの名前も Jiki からとっています。これが Jiki です。Jiki は、これからのプログラミングの旅をいっしょに歩んでくれる友だちです。書かれたコードを解釈して、コンピューターが実際に動かせる 1 と 0 に変換するのが Jiki の仕事です。

プログラミングの本質は、通訳（ここでは Jiki）に正しい指示を出すことです。Jiki に出せる指示はたくさんあり、Jiki が理解できることもたくさんあります。ものをくっつけたり、同じことを何度も繰り返したり、「もしこうなったら、こうする」と判断したりできます。ものを覚えておいて、あとでまた使うこともできます。何かがおかしければ、エラー（英: error）を知らせてくれます。このコースでは、こうしたことをひとつずつ見ていきます。ただ、いちばん大事なのはここです。これから取り組むことはすべて、Jiki がやってきて順番に実行するための指示を、ホワイトボードに書き並べていく作業なのです。

私が 34 年前にプログラミングを覚えたとき、頭の中に作ったのがこのイメージで、今でも同じイメージのままです。コンピューターの仕組みは 1 と 0 のレベルまで理解していますが、正直なところ、そこまで考えることはありません。頭の中では、コンピューターの中に小さな人が住んでいて、その人に「これをやって」と伝えている感覚です。ぜひこのイメージにつきあってみてください。とても強力なイメージです。コンピューターの中の人が何をしているのかを、こうして目に見える形でとらえられるようになると、プログラミングを学ぶうえで大きな助けになります。

では、プログラミングのもっとも基本的な考え方のひとつ、関数（英: function）から見ていきましょう。関数は、Jiki に使ってもらえる小さな機械のようなものです。Jiki がいつも過ごしている倉庫をのぞいてみると、棚の上に 3 つの機械が並んでいます。`move`（動く）、`turnLeft`（左に曲がる）、`turnRight`（右に曲がる）です。

`move` と書いて、そのうしろに括弧（`()`）をつけたとき、Jiki に伝えていたのは「棚から `move` の機械を取ってきて、ハンドルを回して電源を入れ、使ってね」ということでした。

`turnLeft` と書いて括弧をつけたときも、Jiki に「棚から `turnLeft` の機械を取ってきて使ってね」と伝えていたわけです。そして、これがこれから何度も繰り返し使っていくパターンです。機械を使いたいときは、その名前を書いて、うしろに括弧をつけます。そうすると Jiki は棚から機械を取ってきて、使ってくれます。

```javascript
move()
turnLeft()
```

その機械が実際にどう動いているのか、中で何が起きているのかは、今はまだ気にしなくてだいじょうぶです。あとでもっとくわしく見ていきます。それどころか、そう遠くないうちに自分で機械を作れるようにもなります。でも今のところは、そこは気にしないでください。演習ごとに、Jiki の棚にどの機械があるかは示されます。演習によって並んでいる機械は変わり、その機械を使って演習を解いていきます。
