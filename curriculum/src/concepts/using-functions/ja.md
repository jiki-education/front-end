コードを書くということは、コンピューターが理解できる言葉で、自分がやりたいことを伝えるということです。プログラミング言語にはたくさんの種類があり、書かれたコードをコンピューターが理解できる 1 と 0 に変換してくれるインタプリター、つまり通訳の役割を担うプログラムも、いろいろなものがあります。このコースでは、Jiki が通訳をしてくれます。コースの名前も Jiki から来ています。これがその Jiki です。Jiki が、プログラミングの旅を案内してくれる友達です。Jiki の仕事は、皆さんの書いたコードを解釈して、コンピューターが実際に動かせる 1 と 0 に変換することです。

プログラミングの本質は、通訳者（ここでは Jiki）に正しい指示を出すことです。Jiki に出せる指示はたくさんあり、Jiki が理解できることもたくさんあります。たとえば、何かをつなげたり、何度も繰り返したり、「もしこうなったら、こうする」と判断したり、一度覚えたことを後で使ったり、何かが正しくないときにエラーを出したりできます。このコースでは、そういったさまざまなことをひとつずつ取り上げていきます。ただ、ここで大切なのは、皆さんがこれからやることはすべて、ホワイトボードに指示を書いて、Jiki にそれを実行してもらうことだ、という点です。

私が 34 年前にプログラミングを覚えたとき、これが私の頭の中に作ったイメージでした。そして、今でもそのイメージは変わりません。コンピューターの仕組みを 1 と 0 のレベルまで深く理解していますが、正直なところ、そんなことは考えたことがありません。私の頭の中には、コンピューターの中に住んでいる小さな人がいて、その人に何をするか指示を出しているのです。だから、この考え方に乗っかってみてください。これは、とても強力なイメージです。コンピューターの中の人が何をしているのか、という視覚的な捉え方をすると、プログラミングの学習がずっとやりやすくなります。

それでは、プログラミングの基本的な考え方のひとつである、関数（英: _function_）を見てみましょう。関数は、Jiki に使うように指示できる小さな機械のようなものです。Jiki がいつもいる倉庫を覗いてみると、棚の上に 3 つの機械が置いてあります。`move`（前に進む）、`turnLeft`（左に向く）、そして `turnRight`（右に向く）です。

`move` と書いて、その後に括弧を付けると、それは Jiki に、棚から `move` の機械を取りに行き、クランクを回して電源を入れ、使うように指示していることになります。

`turnLeft` と括弧を書いたときは、Jiki に `turnLeft` の機械を棚から取って使うように指示していたのです。これが、これから何度も使うパターンです。機械を使いたいときは、いつも名前を書いてその後に括弧を付ける。これで Jiki に、その機械を取りに行って使うように伝えているのです。

```javascript
move()
turnLeft()
```

さて、その機械が実際にどのように動くのか、機械の中で何が起きているのか、今は気にする必要はありません。それについては、あとで詳しく見ていきます。実は、そう遠くないうちに、皆さん自身も機械を作れるようになります。でも、今のところは心配しないでください。各演習では、Jiki の棚にどんな機械があるかが示されます。演習ごとに違う機械が用意されていて、それらを使って問題を解きます。
