Μέχρι τώρα, όταν συγκρίναμε πράγματα για να δούμε αν είναι ίσα, χρησιμοποιούσαμε τρία ίσον. Καμιά φορά, όμως, θέλουμε να ελέγξουμε αν τα πράγματα **δεν** είναι ίσα, και γι' αυτό χρησιμοποιούμε ένα θαυμαστικό ακολουθούμενο από δύο ίσον. Και γενικά, στον προγραμματισμό, ένα θαυμαστικό ή _bang_, όπως νομίζω το λένε οι Αμερικάνοι φίλοι μας, σημαίνει "όχι". Φαντάσου λοιπόν ότι δουλεύεις σε ένα κατάστημα και η διοίκηση έχει αποφασίσει ότι δεν επιτρέπονται ρούχα ντίσκο.

Μπορούμε να πούμε: «Αν το ρούχο δεν είναι ντίσκο, άνοιξε την πόρτα.» Η εντολή `if` λειτουργεί ακριβώς το ίδιο.

```javascript
if (outfit !== "disco") {
  openDoor()
}
```

Απλώς η συνθήκη επιστρέφει true αν τα πράγματα είναι διαφορετικά, και επιστρέφει false αν είναι ίδια. Έτσι, θα μπορούσαμε να γράψουμε το ίδιο πράγμα λέγοντας: «Αν το ρούχο είναι ντίσκο, μην κάνεις τίποτα. Αλλιώς, άνοιξε την πόρτα.» Αλλά γενικά, είναι πιο εύκολο και πιο καθαρό να χρησιμοποιείς τον τελεστή (_operator_ στα αγγλικά) `not` για να ξέρεις και να λες αυτό που εννοείς πραγματικά.

Και κάτι ακόμα σχετικό. Καμιά φορά θα έχεις μια μεταβλητή που είναι true και θέλεις να την αντιστρέψεις σε false, ή θα έχεις κάτι που είναι false και θέλεις να το αντιστρέψεις σε true, και μπορούμε να το χρησιμοποιήσουμε αυτό για να παρακολουθούμε κάτι. Φαντάσου λοιπόν ότι έχουμε κάτι που αναπηδά από αριστερά προς τα δεξιά, και έχουμε μια μεταβλητή που ονομάζεται `movingRight` (κίνηση προς τα δεξιά), η οποία είναι true όταν υποτίθεται ότι κινείσαι προς τα δεξιά. Αλλά όταν θέλεις να την εναλλάξεις (_toggle_ στα αγγλικά) ώστε να γίνει false, όταν φτάσεις στη δεξιά άκρη.

Θα μπορούσαμε λοιπόν να το κάνουμε λέγοντας: «Αν η `movingRight` ισούται με true, `movingRight` γίνεται false. Αλλιώς, `movingRight` γίνεται true.» Αυτός είναι ένας τρόπος εναλλαγής της μεταβλητής. Έτσι ο Jiki θα κοιτάξει τη `movingRight` για να δει αν είναι true ή false, και μετά θα βρει το αντίθετο και θα βάλει αυτή την τιμή πίσω στο κουτί.

```javascript
if (movingRight === true) {
  movingRight = false
} else {
  movingRight = true
}
```

Αλλά υπάρχει ένας πιο κομψός τρόπος να το κάνεις, και αυτός είναι να χρησιμοποιήσεις το ίδιο θαυμαστικό ή _bang_:

```javascript
movingRight = !movingRight
```

Και αυτό το αντιστρέφει. Το `!movingRight` σημαίνει το αντίθετο από ό,τι ήταν προηγουμένως.

Έτσι, αν η `movingRight` ήταν true, τώρα είναι false. Αν ήταν false, τώρα είναι true. Ο Jiki παίρνει αυτό που υπάρχει αυτή τη στιγμή στο κουτί, και αυτό το θαυμαστικό του λέει να βρει το αντίθετο. Έτσι, το αντίθετο του true είναι false. Το αντίθετο του false είναι true, και μετά το ξαναβάζει στο κουτί. Αυτό είναι ακριβώς το ίδιο με εκείνη τη μεγαλύτερη εντολή if/else, αλλά είναι απλά πολύ πιο κομψό και πιο σύντομο να το γράψεις.
