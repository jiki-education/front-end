تا اینجا، هر وقت چیزها را مقایسه می‌کردیم تا ببینیم برابرند یا نه، از سه علامت مساوی استفاده کردیم. اما گاهی می‌خواهیم بررسی کنیم که چیزها برابر نیستند، و برای این کار از یک علامت تعجب و به دنبال آن دو علامت مساوی استفاده می‌کنیم. و به طور کلی، در برنامه‌نویسی، علامت تعجب یا «بنگ»، که فکر می‌کنم دوستان آمریکایی‌مان اینطور می‌گویند، به معنی «نه» است. پس تصور کنید در یک فروشگاه کار می‌کنید و مدیریت تصمیم گرفته است که هیچ‌کس با لباس دیسکو وارد نشود.

می‌گوییم: «اگر لباس دیسکو نباشد، در را باز کن.» دستور if دقیقاً به همین شکل کار می‌کند.

```javascript
if (outfit !== "disco") {
  openDoor()
}
```

فقط شرط در اینجا اگر چیزها متفاوت باشند «درست» برمی‌گرداند و اگر مثل هم باشند «غلط» برمی‌گرداند. پس می‌توانیم همان کار را اینطور بنویسیم: «اگر لباس دیسکو باشد، هیچ کاری نکن. در غیر این صورت، در را باز کن.» اما معمولاً استفاده از «عملگر» `not` ساده‌تر و تمیزتر است تا دقیقاً منظورتان را بدانید و بگویید.

یک نکته‌ی دیگر هم در این رابطه هست. گاهی متغیری دارید که «درست» است و می‌خواهید آن را به «غلط» تغییر دهید، یا چیزی دارید که «غلط» است و می‌خواهید به «درست» تبدیلش کنید، و می‌توانیم از این برای پیگیری چیزی استفاده کنیم. تصور کنید یک توپ داریم که از چپ به راست حرکت می‌کند، و متغیری به نام `movingRight` (حرکت به راست) داریم که وقتی قرار است به راست حرکت کنید «درست» است. اما وقتی به لبه‌ی راست می‌رسید، می‌خواهید آن را «تغییر وضعیت» دهید تا «غلط» شود.

پس می‌توانیم این کار را اینطور انجام دهیم: «اگر `movingRight` برابر با «درست» باشد، `movingRight` برابر با «غلط» شود. در غیر این صورت، `movingRight` برابر با «درست» شود.» این روشی برای تغییر وضعیت متغیر است. جیکی به `movingRight` نگاه می‌کند تا ببیند «درست» است یا «غلط»، سپس مقدار مخالف را محاسبه می‌کند و آن را در جعبه می‌گذارد.

```javascript
if (movingRight === true) {
  movingRight = false
} else {
  movingRight = true
}
```

اما روش مرتب‌تری هم هست، و آن استفاده از همان علامت تعجب یا بنگ است:

```javascript
movingRight = !movingRight
```

و این کار آن را برعکس می‌کند. `!movingRight` یعنی مخالف هر چیزی که قبلاً بوده.

پس اگر `movingRight` «درست» بود، حالا «غلط» است. اگر «غلط» بود، حالا «درست» است. جیکی محتوای فعلی جعبه را برمی‌دارد، و آن بنگ به او می‌گوید که مخالف را پیدا کند. بنابراین مخالف «درست» یعنی «غلط» و مخالف «غلط» یعنی «درست»، و بعد او مقدار را دوباره داخل جعبه می‌گذارد. این دقیقاً همان دستور if/else بلندتر است، فقط نوشتنش خیلی مرتب‌تر و خلاصه‌تر است.
