Ο επόμενος βρόχος που πρέπει να γνωρίζεις είναι ο `while` βρόχος (όσο).

Αυτός λέει: "Όσο ισχύει κάποια συνθήκη, τρέξε τον βρόχο." Ας πούμε λοιπόν ότι έχουμε έναν κανόνα που λέει ότι στο Space Invaders μπορείς να πυροβολήσεις μόνο πέντε φορές. Θα βάζαμε λοιπόν εδώ έναν βρόχο που λέει: όσο ο αριθμός των βολών είναι μικρότερος από πέντε, τρέξε έναν βρόχο που επιτρέπει σε κάποιον να παίζει το παιχνίδι.

```javascript
while (numShots < 5) {
  // πυροβόλησε τον εξωγήινο
  numShots++
}
```

Κάθε φορά που κάποιος πυροβολεί, αυξάνουμε το `numShots` κατά ένα, και κάποια στιγμή θα φτάσουμε στο πέντε και ο βρόχος θα τερματιστεί.

Τώρα, ένα πρόβλημα με τους `while` βρόχους είναι ότι είναι αρκετά εύκολο να προκύψουν bugs (λογικά σφάλματα) που κάνουν τον βρόχο να μην τελειώνει ποτέ. Αυτοί λέγονται ατέρμονες βρόχοι (_infinite loops_ στα αγγλικά) και είναι ένα από τα πιο συνηθισμένα bugs στα προγράμματα.

Όταν ο υπολογιστής σου αρχίζει να σέρνεται, οι ανεμιστήρες παίρνουν μπρος και όλα γίνονται θορυβώδη, αυτό συμβαίνει συχνά επειδή κάποιος έχει αφήσει στον κώδικά του έναν ατέρμονα βρόχο που δεν τελειώνει ποτέ.
