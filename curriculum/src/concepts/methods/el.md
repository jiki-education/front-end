Μέχρι τώρα, όταν σκεφτόμασταν τις συμβολοσειρές ή τους αριθμούς, τις θεωρούσαμε αρκετά στατικά πράγματα.

Και παρόλο που είναι, έχουν επίσης πολλή λειτουργικότητα ενσωματωμένη σε αυτές που ο Jiki μπορεί να χρησιμοποιήσει.

Και καθώς προχωράμε, θα μάθουμε για αυτήν τη λειτουργικότητα, για αυτές τις δυνατότητες που έχουν και κάνουν τη ζωή σου πολύ πιο εύκολη.

Υπάρχουν δύο ειδών δυνατότητες που θα εξετάσουμε: ιδιότητες (_properties_ στα αγγλικά) και μέθοδοι (_methods_ στα αγγλικά).

Μέθοδοι είναι συναρτήσεις που ανήκουν στη συμβολοσειρά.

Έτσι, αντί να γράφουμε εμείς μια συνάρτηση στην οποία βάζουμε μια συμβολοσειρά ως είσοδο, μπορούμε να χρησιμοποιήσουμε μια μέθοδο απευθείας πάνω στη συμβολοσειρά.

Για παράδειγμα, θυμάσαι μια συνάρτηση όπου ελέγχεις αν μια συμβολοσειρά περιέχει ένα συγκεκριμένο γράμμα μέσα της; Λοιπόν, οι συμβολοσειρές έχουν στην πραγματικότητα μια μέθοδο που ονομάζεται `includes` (περιέχει) η οποία το κάνει αυτό, και μπορούμε να τη χρησιμοποιήσουμε με την ίδια σύνταξη τελείας που είδες για τις ιδιότητες.

Η διαφορά από τις ιδιότητες είναι ότι όταν γράφουμε αυτές, τις γράφουμε σαν συναρτήσεις με παρενθέσεις και εισόδους.

Μπορούμε λοιπόν να γράψουμε:

```javascript
"Jeremy".includes("e") // true
```

και θα πάρουμε πίσω `true`, αφού το `"Jeremy"` περιέχει ένα `"e"`.

Οι μέθοδοι διαφέρουν από τις ιδιότητες επειδή δεν είναι στατικά δεδομένα. Είναι στην πραγματικότητα συναρτήσεις. Μπορείς να τις φανταστείς σαν συναρτήσεις που έχουν ένα ενσωματωμένο κουτί με τη συμβολοσειρά μέσα του.

Το πώς λειτουργούν δεν έχει σημασία για την ώρα. Δεν θα τις κατασκευάζεις εσύ για λίγο καιρό ακόμα. Αυτό που χρειάζεται να ξέρεις είναι ότι χρησιμοποιείς μια μέθοδο βάζοντας μια τελεία και μετά την κανονική σύνταξη συναρτήσεων.

Ένα πράγμα που πρέπει να ξέρεις για τις συμβολοσειρές είναι ότι οι μέθοδοι δεν αλλάζουν τίποτα μέσα στη συμβολοσειρά. Για παράδειγμα, υπάρχει μια μέθοδος `toUpperCase` (μετατροπή σε κεφαλαία), η οποία επιστρέφει τη συμβολοσειρά με όλα τα γράμματα κεφαλαία. Αλλά αυτό δεν αλλάζει την αρχική συμβολοσειρά. Αυτή εξακολουθεί να περιέχει το `"Jeremy"` γραμμένο μόνο με κεφαλαίο J. Αντίθετα, ο Jiki δημιουργεί μια νέα συμβολοσειρά που είναι εξ ολοκλήρου κεφαλαία.

```javascript
const name = "Jeremy"
const bigName = name.toUpperCase()

log(bigName) // "JEREMY"
log(name) // "Jeremy"
```
