Κάθε τιμή στα προγράμματά μας έχει έναν τύπο. Το `"7"` είναι μια συμβολοσειρά και το `7` είναι ένας αριθμός. Μπορεί να μοιάζουν σχεδόν ίδια, αλλά ο Jiki τα αντιμετωπίζει πολύ διαφορετικά. Δεν μπορείς να προσθέσεις τη συμβολοσειρά `"7"` στον αριθμό `3` και να περιμένεις να πάρεις `10`, επειδή το ένα είναι ένα κομμάτι κειμένου και το άλλο είναι μια ποσότητα.

Αρκετά συχνά χρειάζεται να μεταφέρουμε μια τιμή από έναν τύπο σε έναν άλλο. Αυτό ονομάζεται μετατροπή τύπου (_type conversion_ στα αγγλικά), και υπάρχουν δύο μετατροπές που θα χρειαστείς συνέχεια.

### Μετατροπή μιας συμβολοσειράς σε αριθμό

Όταν διαβάζεις χαρακτήρες από μια συμβολοσειρά, κάθε χαρακτήρας είναι και ο ίδιος μια συμβολοσειρά, ακόμα κι όταν μοιάζει με ψηφίο. Για να μπορέσεις να κάνεις αριθμητικές πράξεις μαζί του, πρέπει πρώτα να τον μετατρέψεις σε πραγματικό αριθμό. Αυτό το κάνουμε με τη `Number()`.

```javascript
Number("7")
// 7

Number("42")
// 42
```

Μόλις έχεις έναν πραγματικό αριθμό, μπορείς να τον προσθέσεις, να τον πολλαπλασιάσεις και όλα τα υπόλοιπα.

```javascript
let digit = Number("7")
let doubled = digit * 2
// 14
```

Αν δώσεις στη `Number()` κάτι που δεν είναι έγκυρος αριθμός, όπως `Number("cat")`, δεν θα πάρεις πίσω αριθμό καθόλου, οπότε καλό είναι να φροντίσεις να της δίνεις μόνο συμβολοσειρές που είναι πραγματικά ψηφία.

### Μετατροπή ενός αριθμού σε συμβολοσειρά

Η αντίθετη κατεύθυνση είναι εξίσου χρήσιμη. Μερικές φορές έχεις έναν αριθμό και θέλεις να τον χειριστείς ως κείμενο, ίσως για να τον ενώσεις με μια άλλη συμβολοσειρά ή για να κοιτάξεις τα επιμέρους ψηφία του. Αυτό το κάνουμε με τη `String()`, το αντίστοιχο της `Number()`.

```javascript
String(42)
// "42"

let count = 7
String(count)
// "7"
```

Τώρα που είναι συμβολοσειρά, μπορείς να χρησιμοποιήσεις όλα τα συνηθισμένα εργαλεία συμβολοσειρών πάνω της, όπως να τη διαβάσεις χαρακτήρα προς χαρακτήρα ή να ελέγξεις το μήκος της.
