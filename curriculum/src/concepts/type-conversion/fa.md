هر مقداری در برنامه‌های ما یک نوع دارد. `"7"` یک رشته است و `7` یک عدد است. شاید این دو تقریباً یکسان به نظر برسند، اما جیکی با آن‌ها بسیار متفاوت برخورد می‌کند. نمی‌توانید رشته‌ی `"7"` را به عدد `3` اضافه کنید و انتظار داشته باشید `10` بگیرید، چون یکی از آن‌ها یک قطعه متن است و دیگری یک کمیت.

اغلب نیاز داریم یک مقدار را از یک نوع به نوع دیگری منتقل کنیم. به این کار «تبدیل نوع» می‌گویند و دو تبدیل هست که همیشه به کارتان می‌آید.

### تبدیل یک رشته به عدد

وقتی کاراکترهایی را از یک رشته می‌خوانید، هر کاراکتر خودش یک رشته است، حتی وقتی شبیه یک رقم باشد. پیش از آنکه بتوانید با آن عملیات ریاضی انجام دهید، باید آن را به یک عدد واقعی تبدیل کنید. این کار را با `Number()` انجام می‌دهیم.

```javascript
Number("7")
// 7

Number("42")
// 42
```

وقتی یک عدد واقعی داشته باشید، می‌توانید آن را جمع کنید، ضرب کنید و هر کار دیگری.

```javascript
let digit = Number("7")
let doubled = digit * 2
// 14
```

اگر چیزی که به `Number()` می‌دهید یک عدد معتبر نباشد، مثل `Number("cat")`، اصلاً عددی پس نمی‌گیرید، بنابراین بهتر است مطمئن شوید فقط رشته‌هایی را به آن بدهید که واقعاً ارقام هستند.

### تبدیل یک عدد به رشته

جهت برعکس هم به همان اندازه کاربرد دارد. گاهی عددی دارید و می‌خواهید با آن مثل یک متن برخورد کنید، مثلاً برای اینکه به یک رشته‌ی دیگر بچسبانیدش یا ارقام مجزایش را ببینید. این کار را با `String()`، که تصویر آینه‌ای `Number()` است، انجام می‌دهیم.

```javascript
String(42)
// "42"

let count = 7
String(count)
// "7"
```

حالا که یک رشته است، می‌توانید از همه‌ی ابزارهای معمول رشته‌ها روی آن استفاده کنید، مثل خواندن کاراکتر به کاراکتر یا بررسی طول آن.
