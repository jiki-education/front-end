プログラムの中の値すべてに型があります。`"7"`は文字列で、`7`は数値です。見た目はほとんど同じですが、Jikiはこれらをまったく異なるものとして扱います。文字列`"7"`を数値`3`に足しても`10`にはなりません。片方はテキストで、もう片方は数量だからです。

よくあることですが、値をある型から別の型に移したいことがあります。これを型変換（英: _type conversion_）といい、特によく使う変換が2つあります。

### 文字列を数値に変換する

文字列から文字を取り出すと、それぞれの文字は、それが数字のように見えても、それ自体は文字列です。算術演算を行う前に、それを実際の数値に変換する必要があります。それには`Number()`を使います。

```javascript
Number("7")
// 7

Number("42")
// 42
```

実際の数値にできれば、足し算や掛け算、その他あらゆることができるようになります。

```javascript
let digit = Number("7")
let doubled = digit * 2
// 14
```

`Number()`に有効な数値でないもの（たとえば`Number("cat")`）を渡すと、数値はまったく返ってきません。ですから、本当に数字だけの文字列だけを渡すように気をつけましょう。

### 数値を文字列に変換する

逆方向の変換も同じくらい便利です。数値があって、それをテキストとして扱いたいことがあります。たとえば他の文字列とつなげたり、各桁を見たりするためです。それには`String()`を使います。これは`Number()`の鏡像のようなものです。

```javascript
String(42)
// "42"

let count = 7
String(count)
// "7"
```

それが文字列になったので、通常の文字列の操作をすべて行えます。たとえば、1文字ずつ読み取ったり、長さを調べたりすることができます。
