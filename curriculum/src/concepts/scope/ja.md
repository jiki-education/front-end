実行するたびに違う場所に円を描くコードがあるとします。そして、10個の円を、それぞれ違う場所に描きたいです。これをループと組み合わせることができます。でも、注意深く見ている方は、ここで何か変なことに気づいたかもしれません。

```javascript
repeat(10) {
  let left = Math.randomInt(0, 100)
  let top = Math.randomInt(0, 100)
  circle(left, top, 5, "blue")
}
```

最初の方で、Jikiの棚にある箱にはそれぞれ固有の名前が必要だというルールがあると私が言いました。そして、`let`というキーワードは、使うたびに新しい箱を作るということも。

しかし、このコードでは`let`がループの中にあるので、Jikiはループが実行されるたびに新しい箱を作ることになります。

では、このコードは間違っているのでしょうか？　それとも、何か別のおかしなことが起きているのでしょうか？

実は、このコードは大丈夫なんです。これは完全に正しいJavaScriptで、スコープ（英: _scope_）と呼ばれる概念によって動いています。スコーピングとも言います。

スコープは、最初はとても単純に感じられるでしょう。でも、これからのキャリアでずっと悩ませ続けることになると、私は保証します。最も経験豊富なエンジニアでさえ、スコープの問題にぶつかりますし、JavaScriptはその点で特に複雑な言語のひとつです。私がこれを言うのは、スコープの問題にぶつかったときに、自分を責めなくて済むようにです。そして、この部分は本当に重要なので、しっかり注意を払ってください。

コードの中で波括弧を見かけたら、それは新しいスコープを作ります。これはどういう意味でしょうか？　Jikiは波括弧を見るたびに、自分の作業場に新しく小さな棚を作るとイメージしてください。そして、Jikiがその波括弧の中のコードを実行している間に作る箱は、その新しい小さな棚の上に置かれ、メインの棚には置かれません。

ですから、このようなループでは、ループの1回の間だけ存在する箱を作ることができます。ここで見えている`left`（左の位置）と`top`（上の位置）の箱は、閉じ波括弧に当たるまでだけ存在し、その後は捨てられます。そして、Jikiはループが実行されるたびにその閉じ波括弧に当たります。このプログラムではそれが10回です。つまり、10回`left`という箱を作っては、また捨てるのです。

ですから、変数を作るときは、どれくらいの間存在させたいかを決めなければなりません。長く生きさせたいなら、波括弧の外に置く必要があります。もし、1回の繰り返し（英: _iteration_）の間だけ、つまりループの1回分だけ存在させたいなら、波括弧の中に入れます。お分かりかと思いますが、これで少し混乱しそうですね。初心者のうちは、これをシンプルに保つための良いルールとして、すべての変数をコードの先頭近く、波括弧の外に置き、波括弧の中ではそれらを更新するだけにすることです。例えば、上のコードを、最初に`left`と`top`の箱をゼロに設定し、ループの中で毎回それらを更新するように書き直すこともできます。それもまったく問題ありません。どちらが正しいとか間違いというわけではありません。ベストプラクティスというものはありますが、それについてはあとで学びます。今は、いろいろ試して、楽しんで、自分に一番しっくりくるやり方を見つけてみてください。あまり気にしすぎないでくださいね。
