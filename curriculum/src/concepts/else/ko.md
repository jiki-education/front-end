`if`문을 사용하면 조건을 검사해서 어떤 것이 참일 때만 코드를 실행할 수 있어요. 이제 if의 공범인 `else`를 소개할게요.

`if`문(영어: _if statement_)을 사용하면, 조건이 참일 때 Jiki가 코드 블록을 실행하고, 거짓일 때는 그 코드 블록을 건너뛰어요. 하지만 조건이 참일 때와 거짓일 때 서로 다른 작업을 실행하고 싶다면 어떻게 해야 할까요? 바로 `else`가 필요한 순간이에요. if의 닫는 중괄호 뒤에 `else` 절(영어: _else clause_)을 넣을 수 있어요. 그러면 if의 조건이 거짓일 때 Jiki가 그 절을 실행해요. 클럽 입구의 경비원 예시로 돌아가 보면, 이제는 문을 열어주거나 손님을 돌려보내는 선택지가 생겼어요. 아까처럼 완전히 무시하는 것보다는 낫죠. 이건 마치 갈림길과 같아요. Jiki가 이 갈림길에 도착하면 조건을 확인하고, 참이면 한쪽 길로, 거짓이면 다른 길로 갈 수 있어요. 하지만 동시에 두 길로 갈 수는 없어요.

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

그런데 가능성이 세 가지 이상이라면 어떨까요? 이제 경비원이 티켓을 판다고 상상해 봐요. 13세 미만이면 어린이 티켓, 13세 이상 20세 미만이면 10대 티켓, 20세 이상이면 성인 티켓을 줘요. 이렇게 세 가지 결과가 생겼어요. 이럴 때는 `else` 뒤에 또 다른 `if`문을 추가할 수 있어요. 그러니까 "만약 이 조건이면 이걸 하고, 그렇지 않고 이 조건이면 저걸 하고, 둘 다 아니면 다른 걸 해."라고 말하는 셈이죠. 이 예제에서 Jiki는 `if`를 보고 첫 번째 조건을 확인할 거예요. 16이 13보다 작은가요? 아니에요. 그러면 `else if`로 넘어가요. 16이 20보다 작은가요? 네, 참이에요. 그래서 그 블록을 실행해서 10대 티켓을 줘요. 거기서 끝이에요. Jiki는 더 이상 아무것도 확인하지 않아요. 마지막 `else`는 쳐다보지도 않아요. Jiki는 한 번 참인 조건을 찾으면 그 블록을 실행하고, 그 아래는 전부 건너뛰어요.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

이게 꼭 이해해야 할 핵심이에요. 오직 하나의 블록만 실행돼요. Jiki는 이 구조를 위에서 아래로 훑으면서, 처음으로 참인 조건을 찾으면 그 블록을 실행하고 넘어가요.

이제 진짜 이해해야 할 게 하나 있어요. 이 부분에서 많은 사람이 헷갈려 해요. 두 개의 별도 `if`문을 쓰는 것과 `else if`를 쓰는 것 사이에는 미묘하지만 아주 중요한 차이가 있어요. 점수에 따라 기본 상품이나 보너스 상품을 주는 프로그램을 만든다고 상상해 보세요. 아래 두 가지 가능성을 봐요. 하나는 `else if`를 사용하고, 다른 하나는 별개의 `if`문을 두 번 사용해요. 어떤 차이가 생길까요?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

그래서 첫 번째 경우, `else if`를 사용하면 높은 점수를 확인해서 상을 주고, 그다음 `else if`는 실행하지 않아요. 따라서 점수가 100을 넘은 사람은 보너스 상품만 받게 돼요.

하지만 두 번째 예제에서는 두 `if`문이 완전히 독립적이에요. 둘 다 실행되고, 두 조건 모두 참이기 때문에 이 사람은 상품을 두 개 받게 돼요. 첫 번째는 한 개, 두 번째는 두 개예요. 잠시 멈춰서 이 차이를 확실히 이해했는지 확인해 보세요.

또 하나 재미있는 점은, 게임 설계에 따라 둘 다 맞을 수 있다는 거예요. 참가자가 일반 상품과 보너스 상품을 둘 다 받을 수도 있고, 그냥 보너스 상품으로 업그레이드될 수도 있어요. 어느 코드가 맞고 틀렸다고 할 수 없고, 상황에 따라 유용하게 쓰이는 거예요. 하지만 어떤 걸 의도하고 사용하는지 분명히 알아야 해요.
