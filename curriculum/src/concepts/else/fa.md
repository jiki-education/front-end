دستور شرطی به شما اجازه می‌دهد شرط‌ها را بررسی کنید و فقط وقتی چیزی «درست» است کد را اجرا کنید. حالا بیایید شریک جرم `if` یعنی `else` را معرفی کنیم.

با یک دستور شرطی، جیکی وقتی شرط «درست» باشد قطعه کد را اجرا می‌کند، و وقتی «غلط» باشد آن قطعه کد را رد می‌کند. اما اگر بخواهید جیکی وقتی شرط «درست» است یک کار را انجام دهد و وقتی «غلط» است کار دیگری را انجام دهد چه؟ `else` برای همین است. می‌توانیم یک بند `else` را بعد از آکولاد بسته‌ی `if` قرار دهیم، و اگر شرط `if` «غلط» باشد جیکی آن را اجرا خواهد کرد. پس برگردیم به مثال نگهبان باشگاه، حالا این گزینه را داریم که یا در را باز کنیم یا کسی را برگردانیم، که احتمالاً بهتر از نادیده گرفتن کامل آن‌هاست، همان‌طور که قبلاً انجام می‌دادیم. آن را مثل یک دو‌راهی در جاده تصور کنید. جیکی به این دو‌راهی می‌رسد، شرط را بررسی می‌کند، و بعد اگر «درست» بود از یک راه می‌رود، و اگر «غلط» بود از راه دیگر می‌رود. اما هر دو کار را انجام نمی‌دهد، همان‌طور که هر دو راه را نمی‌توان همزمان رفت.

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

اما اگر بیش از دو حالت ممکن داشته باشید چه؟ تصور کنید نگهبان ما بلیت می‌فروشد. زیر ۱۳ سال، بلیت کودک می‌گیرید. بین ۱۳ تا ۲۰ سال، بلیت نوجوان. ۲۰ سال و بالاتر، بلیت بزرگسال. پس حالا سه نتیجه مختلف دارید. برای این کار، می‌توانیم یک دستور شرطی دیگر بعد از `else` اضافه کنیم. پس می‌توانیم بگوییم: «اگر این، آن‌گاه فلان. `else if` این، آن‌گاه آن کار را بکن. `else`، کار دیگری بکن.» پس در این مثال، جیکی `if` را می‌بیند و شرط اول را بررسی می‌کند. آیا ۱۶ از ۱۳ کمتر است؟ نه. پس به سراغ `else if` می‌رود. آیا ۱۶ از ۲۰ کمتر است؟ بله، «درست» است. پس آن قطعه را اجرا می‌کند و یک بلیت نوجوان می‌دهد. اما بعد کارش تمام می‌شود. چیز دیگری را بررسی نمی‌کند. اصلاً به آن `else` نهایی نگاه نمی‌کند. به محض اینکه جیکی شرطی را «درست» پیدا کند، آن قطعه را اجرا می‌کند، و همه چیزهای بعدی زیر آن را رد می‌کند.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

این نکته کلیدی است که باید درک کنید. فقط یک قطعه اجرا می‌شود. جیکی در طول این زنجیر پیش می‌رود، اولین شرط «درست» را پیدا می‌کند، آن قطعه را اجرا می‌کند، و ادامه می‌دهد.

حالا، یک چیز هست که باید خوب بفهمید چون خیلی‌ها را گول می‌زند. یک تفاوت ظریف اما بسیار مهم بین نوشتن دو دستور شرطی جداگانه و استفاده از `else if` وجود دارد. تصور کنید برنامه‌ای می‌سازیم که بر اساس امتیاز یک نفر یا یک جایزه معمولی می‌دهد یا یک جایزه ویژه. به این دو حالت نگاه کنید. یکی از `else if` استفاده می‌کند و دیگری از دو دستور `if` جداگانه. چه اتفاق متفاوتی می‌افتد؟

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

پس در حالت اول، با `else if`، ما امتیاز بالا را بررسی می‌کنیم و جایزه را می‌دهیم، و بعد `else if` را اجرا نمی‌کنیم. بنابراین اگر امتیاز شخص بیش‌تر از ۱۰۰ باشد، فقط جایزه ویژه را می‌گیرد.

اما در مثال دوم، دو `if` کاملاً مستقل هستند. هر دو اجرا می‌شوند و هر دو «درست» خواهند بود. بنابراین این شخص دو جایزه می‌گیرد. در اولین `if` جایزه می‌گیرد و در `if` دوم هم دومین جایزه‌اش را می‌گیرد! لحظه‌ای درنگ کنید و مطمئن شوید درست و حسابی این مثال را فهمیدید.

همچنین جالب است بدانید که بسته به طراحی بازی، هر دو ممکن است درست باشند. شاید شرکت‌کننده هم یک جایزه معمولی بگیرد و هم یک جایزه ویژه، یا شاید فقط به جایزه ویژه ارتقا پیدا کند. هیچ‌کدام از این کد‌ها درست یا غلط نیستند. هر کدام در موقعیت خاص خودشان کاربرد دارند. اما باید بدانید کدام‌شان را قصد دارید استفاده کنید.
