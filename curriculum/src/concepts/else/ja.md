`if`文を使うと、条件をチェックして、真のときだけコードを実行できます。では、ifの相棒、`else`を紹介しましょう。

`if`文（英: _if statement_）を使うと、Jikiは条件が真のときはコードブロックを実行し、偽のときはそのブロックをスキップします。でも、真のときにあることをして、偽のときには別のことをさせたい場合はどうでしょう？　そのために`else`があります。`if`の閉じ波括弧の後に`else`節（英: _else clause_）を追加すると、Jikiは`if`の条件が偽の場合にそのブロックを実行します。クラブのバウンサーの例に戻ると、今度はドアを開けるか、追い返すかの選択肢ができました。前のように完全に無視するよりはずっと良いでしょう。これを道の分かれ道のように考えてみてください。Jikiはこの分岐に差し掛かり、条件をチェックして、真なら一方の道へ、偽ならもう一方の道へ進みます。でも、両方進むことは決してありません。

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

では、選択肢が2つ以上ある場合はどうでしょう？　想像してみてください。バウンサーがチケットを売っています。13歳未満なら子供用チケット、13歳以上20歳未満ならティーン用チケット、20歳以上なら大人用チケットです。これで結果が3つになりました。この場合、`else`の後にもう一つ`if`文を追加できます。「もしこれなら、こうする。そうでなくもしこれなら、こうする。そうでもなければ、こうする」という流れです。この例では、Jikiは`if`を見て最初の条件をチェックします。16は13未満ですか？　いいえ。では、次の`else if`に進みます。16は20未満ですか？　はい、真です。なので、そのブロックを実行してティーン用チケットを渡します。そして、それで終わりです。他のことは一切チェックしません。最後の`else`も全く見ません。Jikiは、真になる条件を最初に見つけたら、そのブロックを実行し、それ以下のものはすべてスキップします。

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

これが理解すべき重要なポイントです。実行されるブロックは常に1つだけです。Jikiはこの一連の条件を上から順に見ていき、最初に真になる条件を見つけて、そのブロックを実行し、次に進みます。

さて、本当に理解しておくべきことが一つあります。というのは、これでよくつまずくからです。2つの別々の`if`文を書くのと、`else if`を使うのとでは、微妙ですが非常に重要な違いがあります。では、スコアに応じて基本の賞品かボーナス賞品のどちらかをあげるプログラムを作っているとします。次の2つの可能性を見てください。一方は`else if`を使い、もう一方は2つの別々の`if`文を使っています。何が違ってくるでしょうか？

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

最初のケース、`else if`を使った方は、高いスコアをチェックして賞品をあげたら、`else if`は実行しません。ですから、スコアが100を超えている人は、ボーナス賞品だけを受け取ります。

でも2番目の例では、2つの`if`は完全に独立しています。両方とも実行され、両方とも真になります。なので、この人は賞品を2つもらいます。最初のケースでは1つ、2番目のケースでは2つです。本当に理解できているか、ちょっと立ち止まって確認してみましょう。

それから、これも面白い点ですが、ゲームの設計によってはどちらも正しい場合があります。参加者が普通の賞品とボーナスの両方をもらうかもしれませんし、ボーナス賞品にグレードアップするだけかもしれません。どちらのコードも正解・不正解ではありません。異なる状況で役立つだけです。でも、自分がどちらを使おうとしているのかは分かっている必要があります。
