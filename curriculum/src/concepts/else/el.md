Οι εντολές `if` σου επιτρέπουν να ελέγχεις συνθήκες και να τρέχεις κώδικα μόνο όταν κάτι είναι αληθές. Τώρα ας γνωρίσουμε τον συνεργό του `if`, το `else`.

Με μια εντολή `if` (_if statement_ στα αγγλικά), ο Jiki τρέχει το μπλοκ κώδικα όταν η συνθήκη είναι αληθής, και το προσπερνάει όταν είναι ψευδής. Τι γίνεται όμως αν θέλεις ο Jiki να κάνει ένα πράγμα όταν η συνθήκη είναι αληθής και κάτι διαφορετικό όταν είναι ψευδής; Ακριβώς γι' αυτό υπάρχει το else. Μπορούμε να βάλουμε μια ρήτρα `else` (_else clause_ στα αγγλικά) μετά το άγκιστρο που κλείνει το if, και ο Jiki θα την τρέξει αν η συνθήκη του if είναι ψευδής. Οπότε, για να γυρίσουμε στο παράδειγμα με τον πορτιέρη του κλαμπ, τώρα έχουμε την επιλογή είτε να ανοίξουμε την πόρτα είτε να διώξουμε κάποιον, που μάλλον είναι καλύτερο από το να τον αγνοούμε εντελώς όπως πριν. Σκέψου το σαν μια διακλάδωση στον δρόμο. Ο Jiki φτάνει στη διακλάδωση, ελέγχει τη συνθήκη, και μετά μπορεί να πάει από τον έναν δρόμο αν είναι αληθής ή από τον άλλον αν είναι ψευδής. Ποτέ όμως δεν πηγαίνει και από τους δύο.

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

Τι γίνεται όμως αν έχεις περισσότερες από δύο πιθανότητες; Φαντάσου ότι ο πορτιέρης μας πουλάει εισιτήρια. Κάτω από δεκατρία, παίρνεις παιδικό εισιτήριο. Από δεκατρία μέχρι είκοσι, εφηβικό εισιτήριο. Από είκοσι και πάνω, εισιτήριο ενηλίκου. Έχεις λοιπόν τρία διαφορετικά αποτελέσματα. Γι' αυτό, μπορούμε να προσθέσουμε άλλη μια εντολή `if` μετά το else. Μπορούμε δηλαδή να πούμε: "Αν ισχύει αυτό, κάνε αυτό. Αλλιώς, αν ισχύει εκείνο, κάνε εκείνο. Αλλιώς, κάνε αυτό το τρίτο." Σε αυτό το παράδειγμα, λοιπόν, ο Jiki θα δει το if και θα ελέγξει την πρώτη συνθήκη. Είναι το δεκαέξι μικρότερο από το δεκατρία; Όχι. Οπότε προχωράει στο else if. Είναι το δεκαέξι μικρότερο από το είκοσι; Ναι, αυτό είναι αληθές. Οπότε τρέχει εκείνο το μπλοκ και δίνει ένα εφηβικό εισιτήριο. Και εκεί τελειώνει. Δεν ελέγχει τίποτα άλλο. Δεν κοιτάζει καθόλου το τελικό else. Μόλις ο Jiki βρει μια συνθήκη που είναι αληθής, τρέχει εκείνο το μπλοκ και προσπερνάει όλα τα υπόλοιπα από κάτω.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

Αυτό είναι το βασικό που πρέπει να καταλάβεις. Μόνο ένα μπλοκ τρέχει κάθε φορά. Ο Jiki κατεβαίνει τις συνθήκες μία μία, βρίσκει την πρώτη που είναι αληθής, τρέχει το μπλοκ της και προχωράει.

Τώρα, υπάρχει κάτι που πρέπει πραγματικά να καταλάβεις, γιατί μπερδεύει πολύ κόσμο. Υπάρχει μια λεπτή αλλά πολύ σημαντική διαφορά ανάμεσα στο να γράψεις δύο ξεχωριστές εντολές `if` και στο να χρησιμοποιήσεις else if. Φαντάσου λοιπόν ότι φτιάχνουμε ένα πρόγραμμα που δίνει είτε ένα βασικό έπαθλο είτε ένα έπαθλο μπόνους, ανάλογα με το σκορ κάποιου. Δες αυτές τις δύο εκδοχές. Η μία χρησιμοποιεί else if και η άλλη δύο ξεχωριστές εντολές `if`. Τι θα γίνει διαφορετικά;

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

Στην πρώτη περίπτωση, λοιπόν, με το else if, ελέγχουμε για υψηλό σκορ και δίνουμε το έπαθλο, και μετά δεν τρέχουμε το else if. Οπότε, αν κάποιος έχει σκορ πάνω από εκατό, παίρνει απλώς το έπαθλο μπόνους.

Στο δεύτερο παράδειγμα όμως, οι δύο if είναι εντελώς ανεξάρτητες. Θα τρέξουν και οι δύο, και οι δύο συνθήκες θα είναι αληθείς. Οπότε εδώ το άτομο παίρνει δύο έπαθλα. Στην πρώτη εκδοχή, ένα έπαθλο. Στη δεύτερη, δύο έπαθλα. Αφιέρωσε ένα λεπτό για να βεβαιωθείς ότι το κατάλαβες πραγματικά.

Αξίζει επίσης να σημειώσουμε κάτι ενδιαφέρον: και οι δύο εκδοχές μπορεί να είναι σωστές, ανάλογα με το πώς είναι σχεδιασμένο το παιχνίδι. Ίσως ο παίκτης να παίρνει και το κανονικό έπαθλο και το μπόνους, ή ίσως απλώς να αναβαθμίζεται στο έπαθλο μπόνους. Κανένα από τα δύο κομμάτια κώδικα δεν είναι σωστό ή λάθος. Απλώς είναι χρήσιμα σε διαφορετικές περιστάσεις. Πρέπει όμως να ξέρεις ποιο από τα δύο σκοπεύεις να χρησιμοποιήσεις.
