`if` स्टेटमेंट आपको शर्तों की जाँच करने और तभी कोड चलाने देते हैं जब कोई चीज़ सही हो। अब `if` के साथी, `else` से मिलिए।

`if` स्टेटमेंट (_if statement_) के साथ, Jiki तब कोड ब्लॉक चलाता है जब शर्त सही हो, और शर्त गलत होने पर वह उस कोड ब्लॉक को छोड़ देता है। लेकिन तब क्या जब आप चाहते हैं कि Jiki शर्त सही होने पर एक काम करे और शर्त गलत होने पर दूसरा काम करे? `else` इसी के लिए है। हम `if` के बंद करने वाले ब्रेस के बाद एक `else` क्लॉज़ (_else clause_) लगा सकते हैं, और Jiki उसे तब चलाएगा जब `if` की शर्त गलत हो। तो क्लब के बाउंसर वाले उदाहरण पर लौटते हुए, अब हमारे पास दरवाज़ा खोलने या किसी को वापस भेजने का विकल्प है, जो शायद उन्हें पूरी तरह अनदेखा करने से बेहतर है जैसा हम पहले करते थे। इसे सड़क पर एक काँटे की तरह सोचिए। Jiki इस काँटे पर पहुँचता है, वह शर्त जाँचता है, और फिर वह एक रास्ते पर जा सकता है अगर शर्त सही है, या दूसरे रास्ते पर जा सकता है अगर शर्त गलत है। लेकिन वह कभी भी दोनों रास्तों पर नहीं जाता।

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

लेकिन तब क्या जब दो से अधिक संभावनाएँ हों? कल्पना कीजिए कि हमारा बाउंसर टिकट बेच रहा है। तेरह से कम उम्र में, आपको बच्चे का टिकट मिलता है। तेरह से बीस के बीच, आपको किशोर का टिकट मिलता है। बीस या उससे अधिक, तो यह वयस्क का टिकट है। तो अब आपके पास तीन अलग-अलग परिणाम हैं। इसके लिए हम `else` के बाद एक और `if` स्टेटमेंट जोड़ सकते हैं। इसलिए हम कह सकते हैं, "अगर यह, तो यह करो। वरना अगर यह, तो वह करो। वरना, यह दूसरा काम करो।" तो इस उदाहरण में, Jiki `if` देखेगा और पहली शर्त जाँचेगा। क्या सोलह तेरह से कम है? नहीं। इसलिए वह `else if` की तरफ बढ़ता है। क्या सोलह बीस से कम है? हाँ, यह सही है। इसलिए वह उस ब्लॉक को चलाता है और एक किशोर टिकट देता है। लेकिन फिर उसका काम खत्म हो जाता है। वह और कुछ नहीं जाँचता। वह उस अंतिम `else` को बिल्कुल नहीं देखता। जैसे ही Jiki को कोई सही शर्त मिलती है, वह उस ब्लॉक को चलाता है, और उसके नीचे की बाकी सब चीज़ें छोड़ देता है।

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

यह समझने की अहम बात है। हमेशा केवल एक ही ब्लॉक चलता है। Jiki इस क्रम में नीचे की ओर काम करता है, पहली सही शर्त ढूँढता है, उस ब्लॉक को चलाता है, और आगे बढ़ जाता है।

अब, एक बात है जो सचमुच समझनी चाहिए क्योंकि यह लोगों को उलझा देती है। दो अलग-अलग `if` स्टेटमेंट लिखने और `else if` का उपयोग करने में एक सूक्ष्म लेकिन बहुत महत्वपूर्ण अंतर है। तो कल्पना कीजिए कि हम एक ऐसा प्रोग्राम बना रहे हैं जो किसी के स्कोर के अनुसार या तो सामान्य इनाम देता है या बोनस इनाम। इन दो संभावनाओं को देखिए। एक में `else if` का उपयोग किया गया है और दूसरे में दो अलग-अलग `if` स्टेटमेंट हैं। क्या अलग होगा?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

तो पहले मामले में, `else if` के साथ, हम उच्च स्कोर की जाँच करके इनाम देते हैं, और फिर हम `else if` को नहीं चलाते। इसलिए जिस व्यक्ति का स्कोर सौ से ऊपर है, उसे सिर्फ़ बोनस इनाम मिलता है।

लेकिन दूसरे उदाहरण में, दोनों `if` पूरी तरह स्वतंत्र हैं। दोनों चलेंगे और दोनों सही होंगे। इसलिए यहाँ व्यक्ति को दो इनाम मिलते हैं। पहले वाले में, एक इनाम। दूसरे वाले में, दो इनाम। एक पल रुककर सुनिश्चित कीजिए कि आप यह सचमुच समझ गए हैं।

यह भी दिलचस्प है कि खेल के डिज़ाइन के आधार पर दोनों में से कोई भी सही हो सकता है। शायद प्रतियोगी को एक सामान्य इनाम और एक बोनस इनाम मिलता है, या शायद उन्हें सिर्फ़ बोनस इनाम में अपग्रेड किया जाता है। कोड का कोई भी टुकड़ा सही या गलत नहीं है। वे बस अलग-अलग स्थितियों में उपयोगी हैं। लेकिन आपको पता होना चाहिए कि आप कौन-सा इस्तेमाल करना चाह रहे हैं।
