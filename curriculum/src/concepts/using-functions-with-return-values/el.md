Μέχρι στιγμής είδαμε συναρτήσεις που κάνουν κάτι στον κόσμο. Έτσι, η συνάρτηση `circle` (κύκλος) σχεδιάζει έναν κύκλο. Η συνάρτηση `move` (κίνηση) μετακινεί τον χαρακτήρα σου. Όμως, κάποιες συναρτήσεις λειτουργούν διαφορετικά. Αντί να κάνουν κάτι εξωτερικό, σου δίνουν κάτι πίσω που μπορείς να χρησιμοποιήσεις μέσα στον κώδικά σου. Όταν μια συνάρτηση δίνει κάτι πίσω στον Jiki για να το χρησιμοποιήσει στον κώδικα, λέμε ότι αυτή η συνάρτηση επιστρέφει (_returning_ στα αγγλικά) κάτι. Επιστρέφει κάτι πίσω στον Jiki.

Μπορείς να σκεφτείς αυτές τις μηχανές σαν να έχουν μια τσουλήθρα. Έχουμε ήδη τις θυρίδες στις οποίες βάζουμε πράγματα, αλλά μπορούμε επίσης να έχουμε μια μοναδική υποδοχή εξόδου ή μια τσουλήθρα από την οποία μπορεί να βγει κάτι. Όταν ο Jiki πατάει το κουμπί της μηχανής, η μηχανή δουλεύει και στο τέλος κάτι θα πεταχτεί από την τσουλήθρα. Μπορεί να είναι ένας αριθμός. Μπορεί να είναι μια συμβολοσειρά. Είναι κάτι που ο Jiki μπορεί να πιάσει και να χρησιμοποιήσει.

Οι περισσότερες συναρτήσεις, πιθανώς το 95% αυτών, επιστρέφουν κάτι. Μπορεί να σου κάνουν κάποια μαθηματικά και να επιστρέψουν την τιμή, ή μπορεί να κολλήσουν μερικές συμβολοσειρές μαζί και μετά να σου δώσουν την συμβολοσειρά που προκύπτει. Ή μπορεί να σου δίνουν την τρέχουσα ώρα κάθε φορά που τρέχεις αυτήν τη μηχανή. Ας δούμε αυτήν την τελευταία. Ας πούμε ότι έχουμε μια συνάρτηση που ονομάζεται `getCurrentTime` (τρέχουσα ώρα). Κάθε φορά που ο Jiki τρέχει τη μηχανή, ένα κομμάτι χαρτί με την ώρα γραμμένη πάνω του βγαίνει από την τσουλήθρα, ας πούμε 14:35.

Και μετά μπορούμε να βάλουμε αυτήν την τιμή επιστροφής σε ένα κουτί χρησιμοποιώντας `let`:

```javascript
let time = getCurrentTime()
```

Ο Jiki θα τρέξει τη μηχανή, θα πάρει την τρέχουσα ώρα από την τσουλήθρα και θα την αποθηκεύσει σε ένα κουτί με το όνομα `time`.

Τώρα, είναι σημαντικό να καταλάβεις ότι το κομμάτι χαρτί που ο Jiki βάζει στο κουτί είναι σταθερό εκείνη τη στιγμή. Ακόμα κι αν η πραγματική ώρα αλλάξει ενώ το πρόγραμμά σου τρέχει, το κουτί εξακολουθεί να έχει εκείνο το κομμάτι χαρτί με το 14:35 γραμμένο πάνω του. Μόλις κάτι μπει στο κουτί, είναι ένα σταθερό πράγμα εκεί μέσα. Δεν αλλάζει μαγικά. Αν θέλουμε να βάλουμε την τρέχουσα ώρα στο κουτί ξανά στο μέλλον, πρέπει να χρησιμοποιήσουμε ξανά τη συνάρτηση `getCurrentTime` για να την πάρουμε.

Οι περισσότερες συναρτήσεις που επιστρέφουν πράγματα έχουν και εισόδους. Για παράδειγμα, μπορεί να έχουμε μια συνάρτηση `join` (συνένωση) που παίρνει δύο συμβολοσειρές ως εισόδους και τις επιστρέφει ενωμένες με ένα κενό. Έτσι, αν χρησιμοποιήσουμε μια μηχανή `join` με `"Hello"` και `"World"` ως εισόδους μας, από την τσουλήθρα θα βγει μια συμβολοσειρά με `"Hello World"` γραμμένο πάνω της.

```javascript
join("Hello", "World"); // "Hello World"
```
