文字列の一文字には、角括弧`[]`でアクセスできます。では、文字列をループで処理し、一文字ずつ取り出す方法を見てみましょう。

そのために、新しいループが必要です。これまでは`repeat`ループを使ってきましたが、今度は`for-of`（コレクションの各要素をひとつずつ取り出して繰り返し処理する）ループを使います。このループは、`for`と`of`という2つの新しいキーワードで構成されています。

`for`キーワードは、これから先の学習でもよく登場します。単独で使うこともあれば、`in`や`of`と組み合わせて使うこともあります。今は、最後の`of`に注目しましょう。

では、実際のコードを見てみましょう。

まず、`name`（名前）という変数を作り、そこに文字列 `"Jeremy"`（Jeremyという名前）を代入します。ここまでは新しいことはありませんね。

次にループの行です。ここにはたくさんの要素が詰まっているので、ゆっくり説明していきます。

```javascript
let name = "Jeremy"
for (let letter of name) {
  // ...
}
```

まず、`for`キーワードがあります。これは、Jikiに「これからループ処理をしますよ」と伝える合図です。Jikiは先を読んで`of`を見つけると、「ああ、`for-of`のループをするんだな」と理解します。

つまり、`repeat`ループのように「10回繰り返す」と指示するのではなく、「文字列のすべての文字を順に取り出して繰り返す」と指示しているわけです。これが`for-of`の意味するところです。

次に、`let letter`（文字）という部分があります。これは、先ほどの`let name`と同じです。単に`letter`（文字）という変数を作っているだけです。

違うのは、中身を自分で明示するのではなく、文字列の各文字をひとつずつ、この変数に入れるようにJikiに指示している点です。

Jikiは`for`を見て、`of`があるか確認し、それから処理を始めます。まずは文字列の最初の文字、この例では`"J"`を見つけて、それを`letter`という名前の新しい箱に入れます。ちなみに、この変数名は何でもかまいません。必ずしも`letter`である必要はなく、ここではたまたま`letter`という名前にしただけです。

次に、波括弧`{}`の中のコードを実行します。ここには、コードの他の場所と同様に、どんな処理でも書けます。唯一の違いは、このコードブロックが文字列の各文字に対して一度ずつ実行され、そのたびに`letter`という変数が利用できることです。

Jikiは閉じ波括弧に到達するたびに、`letter`の箱を破棄し、次の文字が入った新しい箱を作ります。したがって、最初は`"J"`を捨てて、代わりに`"e"`を箱に入れます。その次は`"r"`、`"e"`、`"m"`、`"y"`と同じことを繰り返します。6文字あるので、ループは6回まわります。構文に慣れるまでは少し時間がかかるかもしれませんが、概念としてはそれほど難しくありません。
