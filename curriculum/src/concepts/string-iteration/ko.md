문자열의 한 글자에 접근할 때는 대괄호(`[]`)를 사용할 수 있어요. 이제 문자열을 반복해서 돌며 글자를 하나씩 꺼내는 방법을 살펴볼 거예요.

그러기 위해서는 새로운 종류의 루프가 필요해요. 지금까지는 `repeat` 루프를 사용했고, 이제는 `for...of`문(영어: _for...of_)이라는 루프를 사용할 거예요. 이 루프는 `for`와 `of`라는 두 개의 새로운 키워드로 이루어져 있어요.

`for` 키워드는 앞으로 꽤 많은 곳에서 보게 될 거예요. `for`만 단독으로 쓰일 수도 있고, `in`이나 `of`와 함께 쓰일 수도 있어요. 지금은 그중 `of`에 집중할 거예요.

그럼 코드를 한번 살펴볼까요. 먼저 `name`(이름)이라는 변수를 만들고, 여기에 문자열 `"Jeremy"`(제레미라는 이름)를 담아요. 여기까지는 새로운 게 없어요.

그다음 줄에는 루프가 나오는데, 여기에는 많은 내용이 담겨 있어서 하나씩 천천히 살펴볼게요.

```javascript
let name = "Jeremy"
for (let letter of name) {
  // ...
}
```

먼저 `for` 키워드가 있어요. 이 키워드는 Jiki에게 ‘이제 루프를 시작할 거야’라고 알려 줘요. Jiki는 그 뒤를 살펴보다가 `of`를 보고는 우리가 ‘for of’ 방식의 루프를 돌리려 한다는 걸 알아차려요.

그 말은 곧 `repeat` 루프처럼 ‘10번 루프를 돌아요’라고 말하는 대신, ‘문자열의 모든 글자를 차례로 돌아요’라고 말하는 거예요. 바로 그게 ‘for of’의 의미예요.

그다음에는 이 `let letter`(‘letter’라는 변수를 선언하는 부분)이 있어요. 이건 위에서 `let name`이라고 쓴 것과 똑같아요. 그냥 `letter`라는 변수를 만드는 거예요.

차이점은 여기에 무엇을 넣을지 우리가 직접 정하지 않고, 문자열에 있는 글자들을 하나씩 차례대로 넣어 달라고 Jiki에게 부탁한다는 거예요.

그래서 Jiki는 `for`를 보고, `of`도 확인한 다음에 실행을 시작해요. 먼저 문자열의 첫 번째 글자인 `"J"`를 살펴보고, 그걸 `letter`라는 새 상자에 담아요. 참고로, 이 변수 이름은 아무렇게나 지어도 돼요. 꼭 `letter`일 필요는 없어요. 여기서는 그냥 `letter`라고 부르기로 한 거예요.

그런 다음 중괄호(`{}`) 안의 코드를 실행해요. 이 안에서는 다른 곳에서 하는 것과 똑같이 무엇이든 할 수 있어요. 유일한 차이는 이 코드 블록이 문자열의 글자 수만큼, 각 글자마다 한 번씩 실행된다는 거예요. 그리고 그때마다 이 변수를 사용할 수 있어요.

Jiki는 닫는 중괄호(`}`)에 도착할 때마다 `letter` 상자를 버리고, 다음 글자를 담은 새 상자를 만들어요. 그래서 처음에는 `"J"`를 버리고 `"e"`를 담아요. 그다음 `"r"`, `"e"`, `"m"`, `"y"`도 똑같이 반복해요. 글자가 여섯 개니까 루프는 총 여섯 번 돌아요. 문법에 익숙해지는 데 조금 시간이 걸릴 수 있지만, 개념 자체는 그렇게 어렵지 않아요.
