HSL은 RGB와는 전혀 다른 방식으로 색을 생각하게 해 줘요. HSL은 색상(영어: _hue (H)_), 채도(영어: _saturation (S)_), 명도(영어: _lightness (L)_)의 약자예요. `hsl`이라는 함수가 있어요. 색상, 채도, 명도에 해당하는 세 개의 숫자를 받아서 색을 반환해 줘요. 그럼 이 세 단어가 각각 무엇을 뜻하는지 하나씩 살펴볼까요?

```javascript
hsl(hue, saturation, lightness)
```

색상은 원하는 색의 색조를 말해요. 값은 0부터 360까지예요. 무지개를 상상해 보세요. 저는 이렇게 생각해요. 왼쪽에는 빨간색이 있고, 그다음에는 주황색, 노란색, 초록색, 파란색, 보라색이 있어요. 그리고 사실상 다시 빨간색으로 돌아와요. 그래서 0을 쓰면 왼쪽 맨 처음인 빨간색이 되고, `120`을 쓰면 초록색, `230`은 파란색이에요. 이걸 색상환으로 생각할 수도 있어요. 360이라는 숫자는 원의 각도를 뜻해요. 저는 원하는 숫자를 항상 찾아보기 때문에 굳이 외울 필요는 없어요. 그래도 원리를 알아두면 좋아요.

다음은 채도예요. 채도는 색이 얼마나 선명한지를 나타내요. 값은 0부터 100까지예요. 0이면 회색이 나와요. 색도, 색조도 전혀 없는 상태예요. 100이면 완전히 선명하고 생생한 색이 나와요.

그리고 명도가 있어요. 명도는 색이 얼마나 밝은지를 나타내요. 이것도 0부터 100까지예요. 0이면 검은색이 나와요. 어떤 색상을 선택했든 상관없이 검은색이 나와요. 빛이 전혀 없는 거예요. 100이면 흰색이 나와요. 다른 건 아무 상관 없이 빛이 가득 차서 흰색이 돼요. 50은 중간으로, 보통의 색이에요. 이걸 색을 더 밝게 또는 더 어둡게 만드는 슬라이더라고 생각해도 좋아요.

그래서 RGB에서는 (255, 0, 0)으로 적어서 빨간색만 가득하고 초록과 파랑은 전혀 없던 평범한 빨간색 원을 HSL에서는 0, 100, 50으로 표현해요. 0은 빨간색 색상, 100은 채도로 완전한 색, 50은 명도로 보통 밝기 수준이에요. 초록색 원을 만들고 싶다면 색상을 `120`으로 바꾸면 돼요. 더 어두운 초록색으로 만들고 싶다면 명도를 `25`까지 낮추면 돼요.

```javascript
hsl(0, 100, 50) // red
hsl(120, 100, 50) // green
hsl(120, 100, 25) // dark green
```

좀 더 탁한 초록색으로 만들고 싶다면 채도를 낮춰서 색을 빼면 돼요. 예를 들어 `30`으로 줄여 보세요.

선명하고 강렬한 핑크색을 원한다면 색상을 300 정도로 하면 분홍색이 나와요. 그다음 채도를 100까지 올려서 아주 선명하게 만들고, 명도도 60 정도로 높여 줘요.

HSL은 색을 순환할 때 아주 좋아요. 무지개를 만들고 싶다면 색상을 계속 증가시키기만 하면 돼요.
