HSLは、RGBとはまったく異なる色の考え方を提供してくれます。HSLは、色相（英: _hue (H)_）、彩度（英: _saturation (S)_）、明度（英: _lightness (L)_）の頭文字です。`hsl`という関数があり、色相、彩度、明度の3つの数値を渡すと、色を返してくれます。では、この3つの言葉が何を意味するのか見てみましょう。

```javascript
hsl(hue, saturation, lightness)
```

色相は、望む色の色合いで、0から360までの値で表します。虹を想像してみてください。私はこんなふうにイメージしています。左端が赤で、そこからオレンジ、黄色、緑、青、紫と続き、最後は元の赤に戻ります。つまり、0を指定すると左端の赤になります。`120`を指定すると緑、`230`で青です。これはカラーホイールとしても捉えられ、360というのは円の角度の度数です。私はいつも必要な数値を調べて使っているので、覚えようとあまり気にしなくて大丈夫ですが、仕組みを知っておくと便利です。これが色相、つまり色合いです。次に、彩度です。彩度は色の鮮やかさを示し、0から100までの値です。0にするとただの灰色になり、まったく色味がありません。100にすると、完全に鮮やかで生き生きとした色になります。そして明度です。明度は色の明るさを表し、こちらも0から100までの値です。0では黒、100では白になります。選択した色相に関係なく、光がまったくないので黒、光があふれるので白です。50はちょうど中間で、通常の色です。つまり、明度は色を明るくしたり暗くしたりするスライダーと思えます。

では、ふつうの赤い円を作りたいとしましょう。RGBでは`255, 0, 0`（赤だけを最大にし、緑と青は0）と書きましたが、HSLでは`0, 100, 50`を使います。0で赤の色相、100で彩度を最大にし、50でふつうの明るさになります。これを緑の円にしたければ、色相を`120`に変えるだけです。暗い緑にしたければ、明度を`25`まで下げます。

```javascript
hsl(0, 100, 50) // 赤
hsl(120, 100, 50) // 緑
hsl(120, 100, 25) // 暗い緑
```

くすんだ緑にしたければ、彩度を少し落として、たとえば`30`まで下げます。

明るいホットピンクがほしいなら、色相は300あたりでピンクになり、彩度を100まで上げて鮮やかにし、明度も60くらいに上げます。

HSLは、色を順に移り変えたいときに便利です。虹色を作りたければ、色相をどんどん増やしていけばいいのです。
