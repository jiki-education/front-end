Οι συναρτήσεις που έχεις φτιάξει μέχρι τώρα κάνουν πάντα ακριβώς το ίδιο πράγμα κάθε φορά. Η `turnAround` (γύρνα πίσω) στρίβει πάντα αριστερά δύο φορές. Η `shootIfAlienAbove` (πυροβόλησε αν υπάρχει εξωγήινος από πάνω) ελέγχει πάντα και πυροβολεί.

Αλλά σκέψου τις συναρτήσεις που χρησιμοποιείς σε όλο το μάθημα, πώς κάνουν διαφορετικά πράγματα ανάλογα με τις εισόδους. Η Rectangle παίρνει ως εισόδους ένα αριστερά, ένα πάνω, ένα πλάτος και ένα ύψος, και μετά σχεδιάζει ένα διαφορετικό ορθογώνιο με βάση αυτά που της λες.

Τώρα θα προσθέσουμε θυρίδες εισόδου και στις δικές σου συναρτήσεις.

Για να το κάνεις αυτό, χρειάζεται να ξέρεις δύο πράγματα. Το πρώτο είναι πώς φαίνεται στην πράξη, τι πρέπει να γράψεις, και το δεύτερο είναι τι συμβαίνει πραγματικά.

Το πρώτο είναι αρκετά απλό. Απλώς προσθέτεις μερικές κανονικές παρενθέσεις και μετά τα ονόματα των εισόδων που θέλεις.

Φαντάσου λοιπόν ότι δημιουργούμε μια συνάρτηση που πυροβολεί πολλές φορές. Ας την ονομάσουμε `shootMany` (πυροβόλησε πολλές φορές).

Θα τη γράφαμε έτσι:

```javascript
function shootMany(numShots) {
  // ...
}
```

Όταν θέλεις να χρησιμοποιήσεις αυτή τη συνάρτηση, θα την καλούσες με τον αριθμό των βολών που θέλεις:

```javascript
shootMany(5)
shootMany(2)
```

Αυτό είναι το σημαντικό κομμάτι. Όταν εκτελείται ο κώδικας, ό,τι βάλεις σε αυτή την είσοδο, `5` ή `2`, ο μίνι-Τζίκι, με το καπέλο μέσα στη συνάρτηση, παίρνει αυτή την είσοδο και τη βάζει σε ένα κουτί που ονομάζεται `numShots` (αριθμός βολών), και μετά τοποθετεί αυτό το κουτί στα ράφια μέσα στη συνάρτηση για να το χρησιμοποιήσεις στον κώδικα της συνάρτησης.

Θα το πω ξανά.

Όταν γράφουμε `shootMany(5)` για να χρησιμοποιήσουμε τη συνάρτηση, ο Τζίκι από έξω πηγαίνει και παίρνει ένα `5` και το βάζει στη θυρίδα εισόδου της `shootMany`. Μέσα στη μηχανή, ο μίνι-Τζίκι βγάζει αυτό το `5` και το βάζει σε ένα κουτί που ονομάζεται `numShots`, επειδή αυτό είναι το όνομα που έδωσες σε αυτή τη θυρίδα εισόδου, και μετά τοποθετεί αυτό το κουτί στα ράφια μέσα στη συνάρτηση, μέσα στη μηχανή.

Και μετά μέσα στη συνάρτηση, μπορείς απλώς να χρησιμοποιήσεις το κουτί `numShots` όπως θα χρησιμοποιούσες οποιοδήποτε άλλο κουτί. Δεν υπάρχει τίποτα μαγικό με το όνομα `numShots`. Θα μπορούσαμε να το ονομάσουμε ό,τι θέλαμε. Το μόνο που είναι είναι μια εντολή για τον μίνι-Τζίκι να δημιουργεί πάντα ένα κουτί με αυτή την ετικέτα μέσα στη συνάρτηση και να βάζει ό,τι περάσει σε αυτή τη θυρίδα σε αυτό το κουτί.

Και μόλις έχεις μια τιμή σε αυτό το κουτί, μπορείς να κάνεις ό,τι θα έκανες κανονικά με τα κουτιά. Θα μπορούσες να χρησιμοποιήσεις το κουτί `numShots` ως μέρος ενός βρόχου επανάληψης για να πυροβολήσεις τον σωστό αριθμό φορών. Και μπορείς να έχεις και περισσότερες από μία εισόδους. Απλώς τις χωρίζεις με κόμματα. Έτσι, αν έχουμε μια συνάρτηση που ονομάζεται `drawStar` (σχεδίασε αστέρι) που σχεδιάζει ένα αστέρι με βάση την πάνω-αριστερά θέση του, θα την έγραφες έτσι:

```javascript
function drawStar(left, top) {
  // ...
}
```
