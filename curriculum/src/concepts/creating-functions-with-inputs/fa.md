تابع‌هایی که تا الان ساخته‌اید همیشه دقیقاً یک کار را انجام می‌دهند. `turnAround` (دور زدن) همیشه دو بار به چپ می‌چرخد. `shootIfAlienAbove` (اگر بیگانه بالا باشد شلیک کن) همیشه بررسی می‌کند و شلیک می‌کند.

اما به تابع‌هایی که در طول دوره از آن‌ها استفاده کرده‌اید فکر کنید، که بسته به ورودی کارهای متفاوتی انجام می‌دهند. `Rectangle` یک چپ، یک بالا، یک عرض و یک ارتفاع را به عنوان ورودی می‌گیرد، و بعد بر اساس چیزی که به آن می‌گویید یک مستطیل متفاوت رسم می‌کند.

حالا می‌خواهیم به تابع‌های خودتان هم دهانه‌های ورودی اضافه کنیم.

برای این کار باید دو چیز را بدانید. اول اینکه این کار چه شکلی است و چه چیزی باید بنویسید، و دوم اینکه واقعاً چه اتفاقی می‌افتد.

بخش اول خیلی ساده است. فقط کافی است چند پرانتز معمولی و بعد اسم ورودی‌هایی که می‌خواهید را اضافه کنید.

پس تصور کنید می‌خواهیم تابعی بسازیم که چندین بار شلیک کند. اسمش را بگذاریم `shootMany` (بسیار شلیک کن).

این‌طور می‌نویسیم:

```javascript
function shootMany(numShots) {
  // ...
}
```

وقتی می‌خواهید از این تابع استفاده کنید، آن را با تعداد شلیک‌هایی که می‌خواهید فراخوانی می‌کنید:

```javascript
shootMany(5)
shootMany(2)
```

حالا بخش اصلی این است. وقتی کد اجرا می‌شود، هر چیزی که در آن ورودی قرار می‌دهید، `5` یا `2`، جیکی کوچولو (با کلاهش) درون تابع، آن ورودی را می‌گیرد و در جعبه‌ای به اسم `numShots` (تعداد شلیک) می‌گذارد، و بعد آن جعبه را در قفسه‌های داخل تابع می‌گذارد تا شما بتوانید در کد تابع از آن استفاده کنید.

بگذارید دوباره بگویم.

وقتی برای استفاده از تابع می‌نویسیم `shootMany(5)`، جیکیِ بیرون می‌رود و یک `5` می‌گیرد و آن را در دهانه‌ی ورودی `shootMany` می‌گذارد. درون دستگاه، جیکی کوچولو آن `5` را برمی‌دارد و در جعبه‌ای به اسم `numShots` می‌گذارد، چون این همان اسمی است که شما به آن دهانه‌ی ورودی داده‌اید، و بعد آن جعبه را در قفسه‌های داخل تابع، درون دستگاه می‌گذارد.

و سپس درون تابع، می‌توانید از جعبه‌ی `numShots` درست مثل هر جعبه‌ی دیگری استفاده کنید. اسم `numShots` هیچ چیز جادویی‌ای ندارد. می‌توانستیم هر اسمی که می‌خواستیم برایش بگذاریم. تمام آن فقط یک دستورالعمل برای جیکی کوچولو است که همیشه یک جعبه با آن برچسب درون تابع بسازد و هر چیزی را که به آن دهانه فرستاده می‌شود در آن جعبه بگذارد.

و وقتی یک مقدار در آن جعبه داشته باشید، می‌توانید همان کارهایی را که معمولاً با جعبه‌ها انجام می‌دهید، انجام دهید. می‌توانید از جعبه‌ی `numShots` به عنوان بخشی از یک حلقه‌ی `repeat` برای شلیک به تعداد درست استفاده کنید. و می‌توانید بیش از یک ورودی هم داشته باشید. فقط آن‌ها را با کاما از هم جدا کنید.

پس اگر تابعی به اسم `drawStar` (رسم ستاره) داشته باشیم که یک ستاره را بر اساس موقعیت بالای چپ آن رسم می‌کند، آن را این‌طوری می‌نویسید:

```javascript
function drawStar(left, top) {
  // ...
}
```
