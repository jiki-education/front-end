Μέχρι τώρα, χρησιμοποιούσες συναρτήσεις που έχουν φτιαχτεί για σένα, συναρτήσεις όπως `circle`, `rectangle`, `moveRight`, `shoot`. Όλες αυτές είναι συναρτήσεις που φτιάχτηκαν και μπήκαν στα ράφια του Jiki.

Αλλά τώρα είναι η ώρα να αρχίσεις να φτιάχνεις τις δικές σου συναρτήσεις.

Για να σου δείξουμε πώς να το κάνεις αυτό, θα δούμε πώς να φτιάξουμε μια νέα συνάρτηση για τον λαβύρινθο που ονομάζεται `walk5` (πέντε βήματα).

Αυτή η συνάρτηση θα μετακινεί πάντα τον χαρακτήρα πέντε βήματα μπροστά. Αυτή ομολογουμένως δεν είναι η πιο χρήσιμη συνάρτηση στον κόσμο, αλλά είναι μια ωραία εύκολη για να ξεκινήσουμε.

Άρα αν σου ζητούσα να γράψεις κώδικα για να μετακινήσεις τον χαρακτήρα πέντε βήματα μπροστά, θα μπορούσες είτε να γράψεις `move` (κίνηση) πέντε φορές, είτε να χρησιμοποιήσεις έναν βρόχο `repeat`. Σε αυτό το παράδειγμα, για να κρατήσουμε τα πράγματα απλά, θα χρησιμοποιήσουμε την προσέγγιση του `move` πέντε φορές στη σειρά.

```javascript
move()
move()
move()
move()
move()
```

Οπότε αυτό είναι που θέλουμε να υπάρχει μέσα στη συνάρτησή μας.

Τώρα, πρόσθεσε μια γραμμή από κάτω που λέει στον Jiki να χρησιμοποιήσει αυτήν τη συνάρτηση. Το έχεις δει πολλές φορές αυτό.

Και μετά η δουλειά μας θα είναι να τυλίξουμε όλες αυτές τις πρώτες πέντε γραμμές σε μια συνάρτηση, ώστε όταν ο Jiki χρησιμοποιεί την `walk5`, να εκτελούνται αυτές οι πρώτες πέντε γραμμές κώδικα.

Για να μετατρέψουμε αυτές τις πέντε γραμμές σε συνάρτηση, αυτά τα πέντε `move` σε συνάρτηση, χρειάζεται να χρησιμοποιήσουμε μια νέα λέξη-κλειδί, που είναι η λέξη-κλειδί `function`.

Όταν χρησιμοποιούμε τη λέξη-κλειδί `function`, πρέπει να κάνουμε δύο πράγματα. Πρώτον, να καθορίσουμε το όνομα της συνάρτησης. Σε αυτή την περίπτωση, είναι `walk5`. Και δεύτερον, να χρησιμοποιήσουμε άγκιστρα για να τυλίξουμε κώδικα που λέει: 'Αυτό είναι που πρέπει να κάνεις μέσα στη συνάρτηση.' Οπότε μπορούμε να το προσθέσουμε αυτό στον κώδικά μας, και τώρα λέμε στον Jiki να δημιουργήσει μια συνάρτηση με το όνομα `walk5`, και μετά όταν χρησιμοποιείται η `walk5`, να εκτελεί αυτές τις πέντε γραμμές κώδικα.

```javascript
function walk5() {
  move()
  move()
  move()
  move()
  move()
}
```

Όταν ο Jiki βλέπει αυτήν τη λέξη-κλειδί `function`, θα πάει να φτιάξει μια νέα συνάρτηση, θα βάλει αυτές τις εντολές σε έναν ασπροπίνακα μέσα της, και θα βάλει μια ετικέτα στη μηχανή για την `walk5`. Και μετά θα βάλει αυτήν τη συνάρτηση στα ράφια δίπλα σε όλες τις υπόλοιπες που είναι εκεί.

Τώρα, δεν υπάρχει τίποτα το ιδιαίτερο σε αυτήν τη συνάρτηση που έφτιαξες σε σύγκριση με τις ενσωματωμένες (built-in στα αγγλικά). Απλώς κάθονται όλες η μία δίπλα στην άλλη στα ράφια του.

Και όταν χρησιμοποιείς τη συνάρτηση, όταν γράφεις `walk5()`, ο Jiki απλώς θα πάει και θα πάρει τη μηχανή από τα ράφια και θα τη χρησιμοποιήσει ακριβώς το ίδιο όπως έκανε με οποιαδήποτε άλλη συνάρτηση.

Μπορείς να φανταστείς ότι κάθε μηχανή έχει έναν μίνι Jiki που ζει μέσα της. Ο μίνι Jiki φοράει πάντα αυτό το ωραίο καπέλο. Και αυτός ο μίνι Jiki λειτουργεί ακριβώς με τον ίδιο τρόπο όπως ο κανονικός Jiki απ'έξω, ακολουθώντας τις εντολές με τον ίδιο τρόπο.

Ένα βασικό πράγμα που πρέπει να καταλάβεις εδώ είναι ότι όταν ο Jiki δημιουργεί τη συνάρτηση, δεν εκτελεί πραγματικά τον κώδικα. Απλώς γράφει αυτόν τον κώδικα για να τον χρησιμοποιήσει αργότερα.

Ο χαρακτήρας στον λαβύρινθο δεν κινείται σε αυτό το σημείο όταν γράφεις τη λέξη-κλειδί `function`.

Ο Jiki έχει φτιάξει τη μηχανή και την έχει βάλει στα ράφια. Μόνο όταν του πεις να χρησιμοποιήσει τη μηχανή γράφοντας `walk5()` συμβαίνει αυτό πραγματικά.
