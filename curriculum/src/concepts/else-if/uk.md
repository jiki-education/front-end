Ми вже бачили, як `if` та `else` дають нам два шляхи: зробити одне, коли умова правдива, або інше, коли вона неправдива. Але що, як можливостей більше, ніж дві?

Уявімо, що наш охоронець продає квитки. Кому менше тринадцяти, той отримує дитячий квиток. Кому від тринадцяти до двадцяти, тому дістається підлітковий. А кому двадцять чи більше, той отримує дорослий. Отже, тепер маємо три різні результати. Для цього можемо додати ще одну умовну конструкцію після `else`. Тобто можемо сказати: «Якщо це, зроби це. Інакше, якщо ось це, зроби те. Інакше зроби щось третє». У цьому прикладі Jiki побачить `if` і перевірить першу умову. Чи шістнадцять менше за тринадцять? Ні. Тож він переходить до `else if`. Чи шістнадцять менше за двадцять? Так, це правда. Тож він виконує цей блок і видає підлітковий квиток. Але на цьому все: далі він нічого не перевіряє. На той останній `else` він навіть не дивиться. Щойно Jiki знаходить правдиву умову, він виконує її блок і пропускає все, що нижче.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

Це найважливіше, що треба зрозуміти: завжди виконується лише один блок. Jiki рухається вниз цим ланцюжком, знаходить першу правдиву умову, виконує її блок і йде далі.

А тепер одна річ, яку варто зрозуміти по-справжньому, бо на ній багато хто спотикається. Між двома окремими умовними конструкціями і використанням `else if` є тонка, але дуже важлива різниця. Уявімо, що ми створюємо програму, яка видає або звичайний приз, або бонусний, залежно від кількості набраних балів. Погляньмо на два варіанти. Один використовує `else if`, а інший використовує дві окремі конструкції `if`. Що відбуватиметься по-різному?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

Отже, у першому випадку, з `else if`, ми перевіряємо, чи набрано достатню кількість очок, видаємо бонусний приз, і до `else if` уже не доходимо. Тож людина, якщо в неї понад сто балів, отримує лише бонусний приз.

А в другому прикладі дві конструкції `if` цілком незалежні одна від одної. Виконаються обидві, і обидві умови будуть правдивими. Тож тут людина отримує два призи. У першому варіанті один приз. У другому два. Зупинімося на мить, щоб точно це зрозуміти.

Цікаво також, що правильним може бути будь-який із варіантів, залежно від того, як задумана гра. Можливо, учасник отримує і звичайний приз, і бонусний, а можливо, його просто підвищують до бонусного. Жоден із цих фрагментів коду не є правильним чи неправильним: вони просто корисні в різних ситуаціях. Але треба розуміти, який саме ми маємо намір використати.
