تا اینجا دیدید که `if` و `else` دو مسیر به شما می‌دهند: وقتی شرط درست باشد یک کار را انجام بده، وقتی نادرست باشد کار دیگری. اما اگر بیش از دو حالت داشته باشیم چه کار کنیم؟

تصور کنید نگهبان ما دارد بلیط می‌فروشد. زیر ۱۳ سال، بلیط بچه. بین ۱۳ تا ۲۰، بلیط نوجوان. ۲۰ سال یا بیشتر، بلیط بزرگسال. بنابراین الان سه نتیجهٔ متفاوت دارید. برای این کار، می‌توانیم یک دستور `if` دیگر بعد از `else` اضافه کنیم. بنابراین می‌گوییم: «اگر این، آن‌گاه آن کار را انجام بده. وگرنه اگر این، آن کار را انجام بده. وگرنه این کار دیگر را انجام بده.» پس در این مثال، جیکی اول `if` را می‌بیند و شرط اول را بررسی می‌کند. آیا ۱۶ کمتر از ۱۳ است؟ نه. بنابراین به سراغ `else if` می‌رود. آیا ۱۶ کمتر از ۲۰ است؟ بله، این درست است. پس آن بلوک را اجرا می‌کند و بلیط نوجوان صادر می‌کند. اما بعد از آن کارش تمام می‌شود. دیگر هیچ چیز دیگری را بررسی نمی‌کند. اصلاً به آن `else` آخر نگاه هم نمی‌کند. وقتی جیکی شرطی را پیدا می‌کند که درست باشد، همان بلوک را اجرا می‌کند و از همهٔ چیزهای بعدی رد می‌شود.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

این نکتهٔ اصلی است که باید درک کنید. فقط یک بلوک اجرا می‌شود. جیکی این زنجیره را از بالا به پایین طی می‌کند، اولین شرط درست را پیدا می‌کند، آن بلوک را اجرا می‌کند و رد می‌شود.

حالا یک نکته هست که واقعاً باید بفهمید، چون خیلی‌ها را به اشتباه می‌اندازد. یک تفاوت ظریف اما بسیار مهم بین نوشتن دو دستور `if` جداگانه و استفاده از `else if` وجود دارد. تصور کنید می‌خواهیم برنامه‌ای بنویسیم که بسته به امتیاز یک نفر، یک جایزهٔ معمولی یا یک جایزهٔ ویژه بدهد. به این دو حالت نگاه کنید. یکی از `else if` استفاده می‌کند و دیگری از دو دستور `if` جداگانه. چه اتفاق متفاوتی می‌افتد؟

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

پس در حالت اول، با `else if`، اول امتیاز بالا را بررسی می‌کنیم و جایزهٔ ویژه را می‌دهیم، و بعد دیگر `else if` اجرا نمی‌شود. بنابراین فردی که امتیازش بالای ۱۰۰ باشد، فقط جایزهٔ ویژه را دریافت می‌کند.

اما در مثال دوم، دو `if` کاملاً مستقل از هم هستند. هر دو اجرا می‌شوند و هر دو شرطشان درست است. بنابراین اینجا فرد دو جایزه می‌گیرد. در اولی، یک جایزه. در دومی، دو جایزه. یک لحظه وقت بگذارید و مطمئن شوید که این را واقعاً درک کرده‌اید.

همچنین جالب است بدانید که بسته به طراحی بازی، هر دو می‌تواند درست باشد. شاید شرکت‌کننده یک جایزهٔ معمولی و یک جایزهٔ ویژه بگیرد، یا شاید فقط به جایزهٔ ویژه ارتقا پیدا کند. هیچ‌کدام از این دو تکه کد درست یا غلط نیست. بسته به موقعیت، هر کدام کاربرد جداگانه‌ای دارند. اما باید بدانید که قصد استفاده از کدام یک را دارید.
