आपने देख लिया है कि `if` और `else` आपको दो रास्ते देते हैं: जब कोई शर्त सही हो तो एक काम करो, और जब गलत हो तो दूसरा। लेकिन तब क्या जब आपके पास दो से ज़्यादा संभावनाएँ हों?

कल्पना कीजिए कि हमारा बाउंसर टिकट बेच रहा है। तेरह साल से कम उम्र में, आपको बच्चों का टिकट मिलता है। तेरह से बीस के बीच, किशोर टिकट। बीस या उससे ज़्यादा पर, बड़ों का टिकट। तो अब आपके पास तीन अलग-अलग परिणाम हैं। इसके लिए, हम `else` के बाद एक और `if` स्टेटमेंट जोड़ सकते हैं। तो हम कह सकते हैं, "if यह, तो यह करो। else if यह, तो वह करो। else, तो यह दूसरी चीज़ करो।" तो इस उदाहरण में, Jiki `if` देखेगा और पहली शर्त की जाँच करेगा। क्या सोलह, तेरह से छोटा है? नहीं। तो वह `else if` पर जाता है। क्या सोलह, बीस से छोटा है? हाँ, यह सही है। तो वह वह ब्लॉक चलाता है और किशोर टिकट देता है। लेकिन उसके बाद उसका काम खत्म हो जाता है। वह और कुछ जाँचता नहीं है। वह उस आखिरी `else` को बिल्कुल नहीं देखता। एक बार जब Jiki कोई सही शर्त पा लेता है, तो वह उस ब्लॉक को चलाता है और नीचे की बाकी सब चीज़ों को छोड़ देता है।

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

यह समझने की सबसे ज़रूरी बात है। हमेशा सिर्फ एक ही ब्लॉक चलता है। Jiki इस चेन में नीचे जाता है, पहली सही शर्त ढूँढता है, वह ब्लॉक चलाता है, और आगे बढ़ जाता है।

अब, एक चीज़ है जिसे वाकई समझना ज़रूरी है क्योंकि यह लोगों को उलझा देती है। दो अलग-अलग `if` स्टेटमेंट लिखने और `else if` इस्तेमाल करने में एक छोटा लेकिन बहुत महत्वपूर्ण अंतर है। तो कल्पना कीजिए कि हम एक प्रोग्राम बना रहे हैं जो किसी के स्कोर के अनुसार या तो एक सामान्य पुरस्कार या एक बोनस पुरस्कार देता है। इन दो संभावनाओं को देखिए। एक में `else if` इस्तेमाल हुआ है, और दूसरे में दो अलग-अलग `if` स्टेटमेंट। अलग-अलग क्या होगा?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

तो पहले मामले में, `else if` के साथ, हम उच्च स्कोर की जाँच करते हैं और बोनस पुरस्कार देते हैं, और फिर `else if` नहीं चलता। तो उस व्यक्ति को, अगर उसका स्कोर सौ से ज़्यादा है, सिर्फ बोनस पुरस्कार मिलता है।

लेकिन दूसरे उदाहरण में, दोनों `if` पूरी तरह स्वतंत्र हैं। दोनों चलेंगे और दोनों सही होंगे। तो यहाँ व्यक्ति को दो पुरस्कार मिलते हैं। पहले में, एक पुरस्कार। दूसरे में, दो पुरस्कार। एक पल रुककर यह सुनिश्चित कीजिए कि आपने यह वाकई समझ लिया है।

यह भी ध्यान देने लायक है कि खेल के डिज़ाइन के अनुसार दोनों में से कोई भी सही हो सकता है। हो सकता है कि प्रतियोगी को सामान्य पुरस्कार के साथ बोनस भी मिले, या फिर उसका पुरस्कार सिर्फ बोनस में अपग्रेड हो जाए। कोड का कोई भी टुकड़ा सही या गलत नहीं है। वे बस अलग-अलग स्थितियों में उपयोगी हैं। लेकिन आपको यह जानना ज़रूरी है कि आप कौन-सा इस्तेमाल करना चाहते हैं।
