Έχεις δει πώς το `if` και το `else` σου δίνουν δύο δρόμους: κάνεις ένα πράγμα όταν μια συνθήκη είναι αληθής, και κάτι άλλο όταν είναι ψευδής. Τι γίνεται όμως αν έχεις περισσότερες από δύο πιθανότητες;

Φαντάσου ότι ο πορτιέρης μας πουλάει εισιτήρια. Κάτω από τα δεκατρία, παίρνεις παιδικό εισιτήριο. Από δεκατρία μέχρι είκοσι, παίρνεις εφηβικό εισιτήριο. Από είκοσι και πάνω, εισιτήριο ενηλίκου. Έχεις λοιπόν τρία διαφορετικά αποτελέσματα τώρα. Γι' αυτό, μπορούμε να προσθέσουμε άλλη μία εντολή `if` μετά το else. Μπορούμε δηλαδή να πούμε: "Αν ισχύει αυτό, κάνε αυτό. Αλλιώς, αν ισχύει εκείνο, κάνε εκείνο. Αλλιώς, κάνε αυτό το τρίτο." Σε αυτό το παράδειγμα λοιπόν, ο Jiki θα δει το if και θα ελέγξει την πρώτη συνθήκη. Είναι το δεκαέξι μικρότερο από το δεκατρία; Όχι. Οπότε προχωράει στο else if. Είναι το δεκαέξι μικρότερο από το είκοσι; Ναι, αυτή είναι αληθής. Οπότε εκτελεί εκείνο το μπλοκ και δίνει εφηβικό εισιτήριο. Αλλά εκεί τελειώνει. Δεν ελέγχει τίποτα άλλο. Δεν κοιτάζει καθόλου εκείνο το τελικό else. Μόλις ο Jiki βρει μια συνθήκη που είναι αληθής, εκτελεί εκείνο το μπλοκ και προσπερνάει όλα τα υπόλοιπα από κάτω.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

Αυτό είναι το βασικό που πρέπει να καταλάβεις. Μόνο ένα μπλοκ εκτελείται κάθε φορά. Ο Jiki κατεβαίνει αυτή την αλυσίδα, βρίσκει την πρώτη αληθή συνθήκη, εκτελεί εκείνο το μπλοκ και προχωράει.

Τώρα, υπάρχει κάτι που πρέπει πραγματικά να καταλάβεις, γιατί εδώ μπερδεύονται πολλοί. Υπάρχει μια λεπτή αλλά πολύ σημαντική διαφορά ανάμεσα στο να γράψεις δύο ξεχωριστές εντολές `if` και στο να χρησιμοποιήσεις else if. Φαντάσου λοιπόν ότι φτιάχνουμε ένα πρόγραμμα που δίνει είτε ένα βασικό βραβείο είτε ένα μπόνους βραβείο, ανάλογα με το σκορ κάποιου. Δες αυτές τις δύο πιθανότητες. Η μία χρησιμοποιεί else if και η άλλη δύο ξεχωριστές εντολές `if`. Τι θα γίνει διαφορετικά;

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

Στην πρώτη περίπτωση λοιπόν, με το else if, ελέγχουμε για υψηλό σκορ και δίνουμε το μπόνους βραβείο, και μετά δεν εκτελούμε το else if. Οπότε αν κάποιος έχει σκορ πάνω από εκατό, παίρνει μόνο το μπόνους βραβείο.

Στο δεύτερο παράδειγμα όμως, τα δύο if είναι εντελώς ανεξάρτητα. Θα εκτελεστούν και τα δύο, και θα ισχύουν και τα δύο. Οπότε εδώ το άτομο παίρνει δύο βραβεία. Στο πρώτο, ένα βραβείο. Στο δεύτερο, δύο βραβεία. Αφιέρωσε λίγο χρόνο για να βεβαιωθείς ότι το κατάλαβες πραγματικά.

Αξίζει επίσης να σημειώσουμε ότι, ανάλογα με το πώς είναι σχεδιασμένο το παιχνίδι, μπορεί να είναι σωστό είτε το ένα είτε το άλλο. Ίσως ο διαγωνιζόμενος να παίρνει ένα κανονικό βραβείο και ένα μπόνους, ή ίσως απλώς να αναβαθμίζεται στο μπόνους βραβείο. Κανένα από τα δύο κομμάτια κώδικα δεν είναι σωστό ή λάθος. Απλώς είναι χρήσιμα σε διαφορετικές περιστάσεις. Πρέπει όμως να ξέρεις ποιο από τα δύο σκοπεύεις να χρησιμοποιήσεις.
