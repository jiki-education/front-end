`if`と`else`を使うと、条件が真のときと偽のときで別々の処理ができることはもう学びましたね。では、選択肢が3つ以上あるときはどうすればいいのでしょうか？

バウンサーがチケットを売っている場面を想像してみましょう。13歳未満なら子ども用のチケット、13歳以上20歳未満なら10代用のチケット、20歳以上なら大人用のチケットです。これで3つの異なる結果が生まれます。そこで、`else`の後ろにもう1つ`if`文を付け加えます。つまり、「もしこれなら、これをします。そうでなくて、もしこれなら、あれをします。そうでなければ、別のことをします」というわけです。この例では、Jikiは`if`を見て最初の条件を確かめます。16は13より小さいですか？　いいえ。そこでJikiは`else if`に移ります。16は20より小さいですか？　はい、その通りです。そこで、そのブロックを実行して10代用のチケットを渡します。そして、それで終わりです。それ以上は何も調べません。最後の`else`はまったく見ません。Jikiは真になる条件を見つけたら、そのブロックを実行し、それ以降の部分はすべてスキップします。

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

これが理解すべき重要なポイントです。実行されるブロックは常に1つだけです。Jikiはこの鎖を上から順にたどり、最初に真になった条件を見つけ、そのブロックを実行して、先に進みます。

さて、よくつまずくポイントなので、しっかり理解しておきたいことがあります。2つの別々の`if`文を書くことと、`else if`を使うことの間には、微妙ではありますが非常に重要な違いがあります。得点に応じて、基本賞品かボーナス賞品を渡すプログラムを作るとしましょう。この2つの可能性を見てみましょう。一方は`else if`を使い、もう一方は2つの別々の`if`文を使っています。何が違うでしょうか？

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

最初のケース、つまり`else if`を使った場合では、高得点をチェックしてボーナス賞品を渡し、そして`else if`の部分は実行しません。したがって、スコアが100を超えている人は、ボーナス賞品だけを受け取ります。

しかし2つ目の例では、2つの`if`文は完全に独立しています。どちらも実行され、どちらの条件も真になります。そのため、この人は賞品を2つ受け取ります。最初の例では賞品は1つ、2つ目の例では2つです。この点をしっかり理解できるよう、少し時間をとって考えてみてください。

また、どちらが正しいかは、ゲームの設計次第で決まるという点も興味深いですね。参加者が通常の賞品とボーナス賞品の両方を手にする場合もあれば、単にボーナス賞品にアップグレードされるだけの場合もあります。どちらのコードも、間違いというわけではありません。それぞれ異なる状況で役立ちます。ただし、自分がどちらを使おうとしているのかを理解しておく必要があります。
