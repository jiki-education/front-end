Ένα από τα πιο δυνατά πράγματα στις μηχανές, στις συναρτήσεις, είναι ότι πολλές από αυτές σου επιτρέπουν να βάζεις πληροφορίες μέσα τους, οι οποίες, όταν τις εκτελείς, αλλάζουν αυτό που κάνουν.

Μέχρι τώρα, έχουμε δει μηχανές που μοιάζουν λίγο με κουτιά, όπως η μηχανή `move` (μετακίνηση).

Αλλά κάποιες μηχανές έχουν θυρίδες, όπως αυτή η μηχανή `walk` (περπάτημα). Η μηχανή `walk` είναι ακριβώς όπως η `move`. Μετακινεί τον χαρακτήρα (_character_ στα αγγλικά) προς τα εμπρός, με τη διαφορά ότι ο Jiki μπορεί να χρησιμοποιήσει τη θυρίδα για να καθορίσει πόσα βήματα θα προχωρήσει ο χαρακτήρας σου προς τα εμπρός. Έτσι, αντί να χρειάζεται να χρησιμοποιείς τη συνάρτηση `move` τρεις φορές στη σειρά, `move`, `move`, `move`, μπορείς τώρα απλώς να χρησιμοποιήσεις τη συνάρτηση `walk` και να πεις στον Jiki να βάλει τον αριθμό τρία μέσα στη μηχανή.

Για να το κάνουμε αυτό στον κώδικα, γράφουμε πάλι το όνομα της συνάρτησης, στην περίπτωσή μας `walk`, και πάλι βάζουμε την αριστερή παρένθεση. Αλλά μετά, πριν από τη δεξιά παρένθεση, λέμε ποια θέλουμε να είναι η είσοδος (_input_ στα αγγλικά). Επομένως, σε αυτή την περίπτωση, θέλουμε η είσοδος να είναι τρία, για να πούμε `walk` τρία βήματα προς τα εμπρός:

```javascript
walk(3)
```

Όταν ο Jiki το δει αυτό, θα πάρει τον αριθμό τρία, και μπορείς να σκεφτείς αυτόν τον αριθμό σαν ένα μικρό κέρμα, και θα το βάλει στη θυρίδα εισόδου της μηχανής πριν γυρίσει τη μανιβέλα για να την ενεργοποιήσει.

Για συναρτήσεις που σχεδιάζουν ορθογώνια και κύκλους, πρέπει να πεις στον Jiki να εισάγει πολλούς διαφορετικούς αριθμούς, προσδιορίζοντας πράγματα όπως πόσο μακριά από αριστερά πρέπει να είναι, πόσο μακριά από την κορυφή, το πλάτος ενός ορθογωνίου, το ύψος ενός ορθογωνίου.

Στον κόσμο του Jiki, αυτές είναι απλώς διαφορετικές θυρίδες, μία για κάθε έναν από αυτούς τους αριθμούς.

Έτσι στον κώδικα, απλώς γράφουμε κάθε αριθμό και μετά βάζουμε ένα κόμμα ανάμεσα. Το όνομα της συνάρτησης, μια παρένθεση, έναν αριθμό για κάθε είσοδο, όλα χωρισμένα με κόμματα, και μετά κλείνουμε την παρένθεση:

```javascript
rectangle(10, 20, 30, 40)
```

Αν προσπαθήσεις να χρησιμοποιήσεις μια συνάρτηση με λάθος αριθμό εισόδων, θα πάρεις ένα σφάλμα. Για παράδειγμα, αν προσπαθήσεις να βάλεις μία είσοδο σε μια μηχανή που δεν έχει θυρίδα, ο Jiki θα σου πει ότι δεν μπορείς. Και αν προσπαθήσεις να χρησιμοποιήσεις μια μηχανή που έχει θυρίδα εισόδου, αλλά δεν πεις στον Jiki τι να βάλει μέσα, θα σταματήσει επίσης και θα παραπονεθεί. Δοκίμασέ το αν νιώθεις λίγο επαναστατημένος και δες τι θα συμβεί. Θα κάνεις πολλά τέτοια λάθη καθώς τα πράγματα γίνονται πιο περίπλοκα. Προσπάθησε να μην αγχωθείς ή στεναχωρηθείς γι' αυτό. Όλοι μαθαίνουμε από τα λάθη. Είναι στην κυριολεξία ο πιο γρήγορος τρόπος για να εσωτερικεύσει πραγματικά ο εγκέφαλός μας τα πράγματα. Και όλοι κάνουν αυτά τα λάθη. Όλοι ξεκινήσαμε από το μηδέν, οπότε μην αγχώνεσαι.

Κάτι άλλο που αξίζει να αναφέρουμε: μερικές φορές στις ασκήσεις, θα δεις γραμμές που ξεκινούν με δύο κάθετες, `//`. Αυτές ονομάζονται σχόλια (_comments_ στα αγγλικά). Είναι προσωπικές σημειώσεις μόνο για σένα που ο Jiki θα αγνοήσει εντελώς. Έτσι, αν ο Jiki δει μια γραμμή που ξεκινά με αυτές τις δύο κάθετες, απλώς θα την προσπεράσει και θα προχωρήσει στην επόμενη γραμμή. Αυτά τα σχόλια σου δίνουν έναν τρόπο να γράφεις τις δικές σου σημειώσεις για τον εαυτό σου. Είναι πολύ χρήσιμα για να σου θυμίζουν πώς λειτουργούν τα πράγματα. Συχνά, σχόλια γράφονται και για σένα, έτσι ώστε όταν ξεκινάς μια άσκηση, να σου προτείνουν πού πρέπει να γράψεις κώδικα ή πώς να λύσεις κάτι. Αλλά μη διστάσεις να προσθέσεις και δικά σου σχόλια.

Στο κάτω μέρος των οδηγιών μιας άσκησης, θα δεις πληροφορίες για τις συναρτήσεις που μπορείς να χρησιμοποιήσεις, ποιες ακριβώς είναι οι είσοδοι που πρέπει να βάλεις.
