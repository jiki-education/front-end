機械、つまり関数のとても強力な特徴のひとつは、ほとんどのものに情報を渡すことができ、それを実行するたびに違う動きをさせられることです。

これまでに見てきた機械は、`move`（移動する）のように、少し箱に似たものでした。

しかし、中には差し込み口がついている機械もあります。たとえば、この`walk`（歩く）機械です。`walk`機械は`move`機械とよく似ています。`move`機械は前方にキャラクターを動かしますが、`walk`機械はJikiがその差し込み口を使って、キャラクターを何歩進めるかを指定できます。つまり、`move`、`move`、`move`と3回続けて`move`関数を使わなくても、`walk`関数で「3」という数字をJikiに機械へ入れるように伝えればよいのです。

<img
  class="concept-image"
  src="/static/images/concept-assets/using-functions-with-inputs/walk-machine-slot.webp"
  alt="walk機械。上部に歩数を入れるための入力差し込み口がある"
  width="481"
  height="400"
/>

コードでこれを実現するには、関数の名前（ここでは`walk`）を書き、その後に開き括弧（`(`）を書きます。そして、閉じ括弧（`)`）を書く前に、その関数の入力を何にするかを指定します。つまり、この場合は入力を「3」にして、前方へ3歩進むようにします。

```javascript
walk(3)
```

Jikiがこれを見ると、彼は「3」という数字を受け取ります。その数字はまるで小さなコインのようなもので、彼はクランクを回して機械の電源を入れる前に、そのコインを機械の入力差し込み口に入れます。

長方形や円を描く関数では、Jikiに複数の異なる数値を渡す必要があります。たとえば、左端からの距離、上端からの距離、長方形の幅や高さといったものですね。

Jikiの世界では、それぞれの数値用の別々の差し込み口が用意されています。

コードでは、それぞれの数値を書き、その間をカンマで区切ります。関数の名前を書き、括弧を開け、各入力に対応する数値をカンマで区切って並べ、最後に閉じ括弧を書きます。

```javascript
rectangle(10, 20, 30, 40)
```

間違った数の入力で関数を使おうとすると、エラーが発生します。たとえば、差し込み口のない機械に値をひとつ入れようとすると、Jikiは「それはできません」と教えてくれます。また、入力差し込み口がある機械を使おうとしたけれど、中になにを入れるべきかJikiに伝えなかった場合も、Jikiは処理を止めて不満を伝えます。少し反抗的な気分なら、試してみてください。なにが起こるか見てみましょう。コードが複雑になるにつれて、このような間違いはたくさん起こるものです。それでストレスを感じたり、落ち込んだりしないでください。誰もが間違いから学びます。それは、脳が物事をしっかりと身につけるための、実はいちばんの近道なのです。そして、このような間違いはみんな経験します。誰もがゼロからスタートしているのですから、ストレスを感じる必要はありません。

あともうひとつ、お伝えしておきたいことがあります。演習では時々、`//`という二つのスラッシュで始まる行が出てきます。これらは「コメント」と呼ばれるもので、あなただけが見られるプライベートなメモです。Jikiはコメントを完全に無視します。Jikiがこの二つのスラッシュで始まる行を見つけると、その行を飛ばして、次の行に移ります。コメントを使うと、自分自身へのメモを残すことができ、ものの仕組みを思い出すのに本当に便利です。また、演習を始めたときに、どこにコードを書けばよいか、あるいはどうやって解けばよいかを示唆してくれる、あらかじめ書かれたコメントもよくあります。もちろん、自分でコメントを追加してもかまいません。

演習の指示の一番下には、使える関数と、それぞれに渡すべき入力の情報が表示されます。
