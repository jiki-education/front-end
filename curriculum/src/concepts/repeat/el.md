Μέχρι τώρα, όλος ο κώδικάς μας ήταν γραμμένος με γραμμικό τρόπο, όπου ο Jiki ακολουθεί κάθε εντολή με τη σειρά, από πάνω προς τα κάτω.

Τώρα θα δούμε πώς μπορεί ο Jiki να ξεφύγει από αυτή την αυστηρή ροή από πάνω προς τα κάτω, και συγκεκριμένα πώς μπορούμε να του πούμε να εκτελέσει το ίδιο κομμάτι κώδικα πολλές φορές στη σειρά.

Για παράδειγμα, φαντάσου ότι βρίσκεσαι στον λαβύρινθο και θέλεις να προχωρήσεις 10 βήματα μπροστά. Υπάρχει μια συνάρτηση `walk` που βοηθάει σε αυτό, αλλά τι θα γινόταν αν δεν υπήρχε; Τι θα γινόταν αν είχες μόνο τη συνάρτηση `move` (κίνηση);

Αντί να γράφουμε `move` δέκα φορές στη σειρά, κάτι που γίνεται πολύ κουραστικό, αυτό που χρειαζόμαστε είναι να μπορούμε να πούμε: "Γεια σου, Jiki, κάνε αυτό που θα σου πω δέκα φορές.

`Move`."

Για να το κάνουμε αυτό σε κώδικα, χρειάζεται να χρησιμοποιήσουμε την πρώτη μας λέξη-κλειδί (_keyword_ στα αγγλικά), όπου λέξεις-κλειδιά είναι εντολές που ο Jiki καταλαβαίνει μόνος του. Μοιάζουν λίγο με μηχανές, αλλά δεν είναι. Όταν ο Jiki βλέπει μια λέξη-κλειδί, δεν ψάχνει για μηχανή στο ράφι, απλώς ξέρει τι πρέπει να κάνει. Είναι κομμάτι του μυαλού του. Θα μάθουμε περίπου 20 διαφορετικές λέξεις-κλειδιά κατά τη διάρκεια του μαθήματος, και η πρώτη από αυτές είναι η λέξη-κλειδί `repeat`.

Η λέξη-κλειδί `repeat` κάνει ακριβώς αυτό που περιέγραψα παραπάνω. Λέει στον Jiki: "Ό,τι θα σου πω μετά, επανάλαβέ το τόσες φορές." Ρίξε μια ματιά σε αυτόν τον κώδικα. Αρχικά, χρησιμοποιούμε τη λέξη-κλειδί `repeat` για να πούμε στον Jiki ότι θα κάνει κάτι πολλές φορές. Μετά βάζουμε μέσα σε κανονικές παρενθέσεις πόσες φορές θέλουμε να το επαναλάβει ο Jiki, και έπειτα έχουμε αυτά τα άγκιστρα, και μέσα σε αυτά τα άγκιστρα βρίσκονται τα πράγματα που θέλουμε να επαναλάβει ο Jiki. Αυτό το μοτίβο, μάλιστα, είναι εξαιρετικά συνηθισμένο στον προγραμματισμό. Ορίζουμε μια λέξη-κλειδί, συνήθως με κάποια πληροφορία, όπως εδώ πόσες φορές να γίνει κάτι, και μετά ένα μπλοκ κώδικα (_code block_ στα αγγλικά) μέσα σε άγκιστρα. Γυρνώντας πίσω στον λαβύρινθο, αντί να γράφουμε `move`, `move`, `move`, `move`, μπορούμε να γράψουμε να επαναλάβει τέσσερις φορές το `move`.

```javascript
repeat(4) {
  move()
}
```

Ο Jiki θα δει αυτόν τον κώδικα και θα χρησιμοποιήσει τη μηχανή `move` τέσσερις φορές στη σειρά.

Επίσης, δεν περιοριζόμαστε στο να έχουμε μόνο ένα πράγμα μέσα σε αυτά τα άγκιστρα. Ο Jiki μπορεί να κάνει πολλά πράγματα επαναληπτικά. Μπορούμε να του πούμε να κάνει `move`, μετά `turnLeft`, και να επαναλάβει όλο αυτό τέσσερις φορές. Αν ο Jiki το δει αυτό, θα χρησιμοποιήσει τη μηχανή `move`, μετά τη μηχανή `turnLeft`, μετά τη μηχανή `move`, μετά τη μηχανή `turnLeft`, μετά τη μηχανή `move`, και ούτω καθεξής, μέχρι να έχει κάνει και τα δύο τέσσερις φορές.

```javascript
repeat(4) {
  move()
  turnLeft()
}
```

Ονομάζουμε αυτές τις εντολές επανάληψης βρόχους (_loops_ στα αγγλικά), και υπάρχουν πολλοί διαφορετικοί βρόχοι που μπορούμε να χρησιμοποιήσουμε, ο καθένας από τους οποίους λειτουργεί λίγο διαφορετικά.

Υπάρχει ακόμα ένα πράγμα που αξίζει να ξέρεις: όταν δουλεύεις με βρόχους, το να κρατάς τον κώδικά σου καθαρό και τακτοποιημένο γίνεται απαραίτητο. Όταν ο κώδικάς σου έχει καλή οπτική δομή, είναι πολύ εύκολο να δεις τι συμβαίνει. Αν όμως δεν την έχει, αν ξεχάσεις να κάνεις σωστή εσοχή ή μπερδέψεις τις εσοχές σου, τα πράγματα μπερδεύονται πολύ γρήγορα. Γι' αυτό σε αυτό το μάθημα ακολουθούμε πάντα έναν κανόνα. Βάζεις πάντα το ανοιχτό άγκιστρο στην ίδια γραμμή με την εντολή (_statement_ στα αγγλικά) `repeat`. Βάζεις πάντα το κλειστό άγκιστρο σε δική του γραμμή μετά την εντολή, και κάνεις πάντα εσοχή στον κώδικα ανάμεσά τους κατά δύο κενά. Έτσι όλα θα μένουν πολύ τακτοποιημένα, και αν το ξεχάσεις ή προσπαθήσεις να ακολουθήσεις διαφορετικό μοτίβο, θα πάρεις σφάλμα.
