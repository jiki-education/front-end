辞書の作り方と値の取り出し方はもうご存知ですね。でも、データが変わったらどうなるのでしょうか？　私もいずれ年をとります。いつまでも`42`のままではありません。`43`になります。

では、辞書を更新するにはどうすればいいのでしょうか？　値を取り出す方法とよく似ています。角括弧を使って値を取り出すことは知っていますよね。同じように、角括弧の後にイコールを続けることで辞書を更新できます。Jikiはpersonの箱のところへ行き、ノートの紙を取り出して、`"age"`キーを見つけます。そこに書いてあった`42`を消し、代わりに`43`と書き込みます。それからノートの紙を箱に戻します。これが辞書そのものを変更するということです。

```javascript
person["age"] = 43
```

Jikiは新しい辞書を作っているのではなく、箱の中にすでにあるノートを書き換えているのです。

では、これまでになかった情報を追加したい場合はどうでしょうか？　実はまったく同じ方法で追加できます。

存在しないキーを指定すると、Jikiはその値を持つ新しいキーをノートの末尾に追加してくれます。

この場合、Jikiはノートを開き、`"country"`を探しますが、見つからないので、末尾に新しい行を追加します。左側に`"country"`、右側に`"England"`と書くわけです。

```javascript
person["country"] = "England"
```

値の変更とまったく同じ構文です。Jikiが自動的に両方に対応してくれます。キーが存在すれば更新し、存在しなければ追加してくれます。特別なことをする必要はありません。

空の配列から始めて要素を追加できるのと同じように、空の辞書から始めてキーを1つずつ追加することもできます。これも非常によく使われるパターンです。これから何度も目にすることでしょう。

辞書は、ものの数を数えるのによく使われます。カウントしたいものをキーとし、その値をカウント数にします。たとえば、バードウォッチングで見た鳥の数を種類ごとに記録したいとします。ある鳥を見かけたら、その鳥のカウントを1に設定します。そして、再びその鳥を見かけたときは、現在の値を取得して1増やします。このパターンを機能させるには、辞書にそのキーがすでに存在するかどうかをチェックする方法が必要です。存在すれば1を足し、存在しなければカウントを1から始める必要があるからです。

そのために、辞書には`has`メソッド（キーの存在を調べるメソッド）があります。

調べたいキーを指定すると、Jikiがそのキーが辞書に存在するかどうかをチェックし、その結果に応じてtrueかfalseを返します。

```javascript
person.has("age") // true
```

これらを組み合わせると、カウントのパターンは次のようになります。

```javascript
if (counts.has(letter)) {
  counts[letter] = counts[letter] + 1
} else {
  counts[letter] = 1
}
```
