딕셔너리를 만들고 값을 가져오는 방법은 이미 알고 계시죠? 그런데 데이터가 바뀌면 어떻게 될까요? 어느 순간 저도 나이가 더 들 거예요. `42`가 아니라 `43`이 될 거예요.

딕셔너리를 어떻게 업데이트할까요? 값을 찾을 때와 아주 비슷한 방법을 써요. 값을 꺼낼 때 대괄호를 쓴다는 건 알고 계시죠? 대괄호 뒤에 등호를 붙여서 딕셔너리를 업데이트할 수도 있어요. Jiki는 `person` 상자로 가서, 공책을 꺼내요. `"age"` 키를 찾아서 거기에 적힌 `42`를 지우고 `43`을 대신 써 넣은 다음, 공책을 다시 상자에 넣어요. 이게 바로 딕셔너리 자체를 바꾸는 거예요.

```javascript
person["age"] = 43
```

Jiki는 새 딕셔너리를 만드는 게 아니라, 원래 상자에 들어 있던 공책을 고치고 있는 거예요.

그럼 전에 없던 정보를 추가하고 싶으면 어떨까요? 똑같은 방법으로 할 수 있어요.

존재하지 않는 키를 지정하면, Jiki는 그냥 맨 아래에 새 키와 값을 추가해요.

그럼 이 경우, 공책을 펼쳐서 `"country"`를 찾아보고, 없으면 맨 아래에 새 줄을 추가해서 왼쪽에는 `"country"`, 오른쪽에는 `"England"`를 적어요.

```javascript
person["country"] = "England"
```

값을 바꾸는 문법과 완전히 똑같아요. Jiki는 두 경우를 자동으로 처리해요. 키가 있으면 업데이트하고, 없으면 추가해요. 따로 신경 쓸 필요 없어요.

빈 배열에 항목을 하나씩 추가하듯이, 빈 딕셔너리에서 시작해서 키를 하나씩 추가할 수도 있어요. 이것도 아주 흔한 패턴이에요. 앞으로 자주 보게 될 거예요.

딕셔너리의 흔한 용도 중 하나는 개수를 세는 거예요. 키를 세고 싶은 대상으로, 값을 그 개수로 지정할 수 있어요. 예를 들어, 새 관찰을 하면서 각 새를 몇 번 봤는지 기록하고 싶다고 상상해 보세요. 새를 볼 때마다 그 새의 개수를 1로 설정하고, 그다음에 또 볼 때마다 현재 값을 가져와서 1을 더하는 식이에요. 이렇게 하려면 딕셔너리에 이미 그 키가 있는지 확인하는 방법이 필요해요. 키가 있으면 1을 더하고, 없으면 1부터 시작해야 하니까요.

이를 위해 딕셔너리에는 `has`(키가 있는지 확인하는) 메서드가 있어요.

관심 있는 키를 지정하면, Jiki가 딕셔너리에 그 키가 있는지 확인해서 `true`나 `false`를 돌려줘요.

```javascript
person.has("age") // true
```

이것을 합치면, 개수 세기 패턴은 이렇게 생겼어요:

```javascript
if (counts.has(letter)) {
  counts[letter] = counts[letter] + 1
} else {
  counts[letter] = 1
}
```
