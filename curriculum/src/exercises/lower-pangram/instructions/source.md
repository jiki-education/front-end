---
title: "Simple Pangram"
description: "Check if a sentence uses every letter of the alphabet."
---

A <define>pangram</define> is a sentence that uses **every letter of the alphabet at least once**.

In this exercise, you only need to handle lowercase letters. The input will only contain lowercase letters and other characters like spaces, numbers, or punctuation, but no uppercase letters.

Your task is to write <define>`isPangram(sentence)`</define>, which takes a sentence as an input and returns `true` if it contains every letter from a to z at least once, or `false` if it doesn't.

The best known English pangram is: "the quick brown fox jumps over the lazy dog"!

### Helper functions

You cannot use nested loops in this exercise. Instead, as in the last exercise, the key to is to create one or more **helper functions** which `isPangram(...)` uses.

Have fun!
