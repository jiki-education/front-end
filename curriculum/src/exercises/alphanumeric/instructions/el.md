Σε αυτή την άσκηση, στόχος σου είναι να δημιουργήσεις συναρτήσεις που ελέγχουν αν μια συμβολοσειρά περιέχει γράμματα ή/και αριθμούς.

Θα χρειαστεί να γράψεις τρεις βοηθητικές συναρτήσεις:

- `isAlpha(string)` (αλφαβητική) — ελέγχει αν μια συμβολοσειρά αποτελείται μόνο από γράμματα ASCII (π.χ. "A", "a", "Hello")
- `isNumeric(string)` (αριθμητική) — ελέγχει αν μια συμβολοσειρά αποτελείται μόνο από αριθμητικούς χαρακτήρες (π.χ. "0", "1", "456")
- `isAlphanumeric(string)` (αλφαριθμητική) — ελέγχει αν μια συμβολοσειρά αποτελείται μόνο από γράμματα ASCII ή αριθμούς (π.χ. "Hello", "42", "Hello42")

Για οποιαδήποτε άλλα σύμβολα (π.χ. "!", "?") ή χαρακτήρες εκτός ASCII (π.χ. "じき", "正直"), και οι τρεις συναρτήσεις θα πρέπει να επιστρέφουν ψευδής.

Στη συνέχεια, γράψε μια συνάρτηση `whatAmI(string)` (τι είμαι) που χρησιμοποιεί αυτές τις βοηθητικές για να ταξινομήσει μια συμβολοσειρά:

- Συμβολοσειρές με μόνο γράμματα πρέπει να επιστρέφουν `"Alpha"`
- Συμβολοσειρές με μόνο αριθμούς πρέπει να επιστρέφουν `"Numeric"`
- Συμβολοσειρές με γράμματα και αριθμούς πρέπει να επιστρέφουν `"Alphanumeric"`
- Οτιδήποτε άλλο πρέπει να επιστρέφει `"Unknown"`

### Χρησιμοποιώντας αυτά που μόλις έμαθες

Αν και υπάρχουν πολλοί έγκυροι τρόποι για να λύσεις αυτή την άσκηση, η λύση που θέλουμε να καταλήξεις χρησιμοποιεί μια εντολή `continue` και τις τρεις παραπάνω συναρτήσεις.

Αυτή η άσκηση σε προκαλεί επίσης να λύσεις όλο το πρόβλημα σε 42 γραμμές κώδικα ή λιγότερες. Αυτός ο στόχος δεν είναι απαραίτητα η πιο «επαγγελματική» λύση. Μερικές επιπλέον γραμμές πιθανότατα δίνουν μια κομψότερη λύση, ενώ υπάρχουν και πιο σύντομες εκδοχές. Είναι όμως ένας καλός στόχος για να ωθήσεις τις ικανότητές σου.
