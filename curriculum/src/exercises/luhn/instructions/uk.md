Ми щойно розглянули перевірку номерів ISBN для книжок. Існує ще одна поширена формула, якою перевіряють номери в багатьох контекстах: формула Луна (англ. _Luhn formula_). Найвідоміше її застосування: виявлення помилок при введенні номерів кредитних карток.

### Перевірка Луна

Перевірка Луна складається з кількох кроків:

- Починаючи з **крайньої правої** цифри й рухаючись ліворуч, **подвоюємо кожну другу цифру**.
- Якщо після подвоєння цифри виходить число, більше за 9, віднімаємо від нього 9.
- Потім додаємо всі цифри разом.
- Якщо сума ділиться на 10 без остачі, номер дійсний.

Наприклад, для `"067"` виконуємо ці кроки:

```
0   6   7     // початкові цифри
0  12   7     // кожна друга цифра (з правого краю) подвоєна
0   3   7     // 12 більше за 9, тому віднімаємо 9 → 3
       10     // Додаємо цифри разом
     true     // 10 ділиться на 10, тому 067 дійсний
```

### Завдання

Створіть функцію з назвою `valid` (дійсний), яка приймає рядок тексту (англ. _string_) і повертає `true`, якщо він проходить перевірку Луна, і `false`, якщо ні.

Номери подаються як рядки тексту й можуть містити пробіли для зручності читання (наприклад, `"4539 1488 0343 6467"`). Пробіли слід ігнорувати.

Кілька важливих зауважень:

- Вхідний рядок тексту може містити пробіли: їх слід ігнорувати.
- Якщо вхідний рядок тексту містить будь-які інші символи, слід повернути false.
- Рядки тексту довжиною 1 або менше (після видалення пробілів) **не** є дійсними.
