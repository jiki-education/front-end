Καλώς ήρθες στην τρίτη άσκηση Pangram, όπου θα πάρουμε όλες αυτές τις βοηθητικές συναρτήσεις που έφτιαξες και θα απλοποιήσουμε πολύ τα πράγματα!

Κάθε μία από τις συναρτήσεις που σε ενθάρρυνα να γράψεις (`includes`, `indexOf` και `toLowerCase`) είναι στην πραγματικότητα ενσωματωμένη στις συμβολοσειρές ως μέθοδος.

Έτσι, αντί να γράφεις `includes("Jeremy", "r")`, μπορείς να γράφεις `"Jeremy".includes("r")` και κάνει ακριβώς το ίδιο πράγμα. Αλλά επειδή αυτή η μέθοδος είναι ενσωματωμένη στη συμβολοσειρά, δεν χρειάζεται να τη γράφεις.

Για αυτή την άσκηση, χρειάζεσαι μόνο δύο από αυτές:

- `"Jeremy".toLowerCase()`
- `"Jeremy".includes("r")`

Δεν θα χρειαστείς καθόλου την `indexOf` πλέον, γιατί την έγραψες μόνο για να βοηθήσεις στη δημιουργία της `toLowerCase`, και τώρα η ενσωματωμένη `toLowerCase` κάνει αυτή τη δουλειά για εσένα.

Έτσι, μπορείς να διαγράψεις όλες αυτές τις συναρτήσεις που έγραψες (τουλάχιστον τώρα ξέρεις πώς λειτουργούν αυτές οι μέθοδοι κάτω από το καπό, οπότε μη μου φωνάζεις πολύ δυνατά!) και να χρησιμοποιήσεις αυτές αντ' αυτών.

Καλά να περάσεις!
