在第一个你完成的绘画练习中，你使用了`rectangle`（矩形）函数来填补墙壁上的一些空隙。在这个练习中，我们在那个基础上，使用循环来给墙壁加上顶层。

除了顶层之外的所有层都已经完成了。你需要添加最后一层 5 个砖块。完成的墙壁应该像这样：

<img src="/static/images/exercise-assets/finish-wall/completed-wall.webp" alt="完成的墙壁" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

你需要知道的事情：

- 每个砖块高 10，宽 20。
- `rectangle` 函数在你的代码中只能出现一次！
- 正确的颜色是 `"brick"`。

复用你最近一直在使用的思路，你就能顺利完成。祝你好运！
