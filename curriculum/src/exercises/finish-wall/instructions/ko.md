첫 번째 그리기 연습 문제에서는 `rectangle`(직사각형) 함수를 사용하여 벽의 빈 곳을 채웠어요. 이번 연습 문제에서는 그에 이어 루프를 사용하여 벽의 맨 위층을 추가할 거예요.

맨 위층을 제외한 모든 층은 이미 완성되어 있어요. 마지막으로 벽돌 5개로 이루어진 층을 추가해야 해요. 최종 벽의 모습은 다음과 같아요.

<img src="/static/images/exercise-assets/finish-wall/completed-wall.webp" alt="완성된 벽" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

알아두어야 할 점:

- 각 벽돌은 높이 10, 너비 20이에요.
- `rectangle` 함수는 코드에 한 번만 나타날 수 있어요!
- 올바른 색은 `"brick"`이에요.

최근에 사용하던 아이디어를 다시 활용하면 잘 해낼 거예요. 행운을 빌어요!
