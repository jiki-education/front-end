最初の描画演習では、`rectangle`（長方形を描く）関数を使って壁の隙間を埋めました。この演習では、それを踏まえて、ループを使って壁に最上段を追加します。

最上段以外のすべての段は、すでに完成しています。最後に、レンガを5つ積んで最上段を仕上げましょう。完成後の壁は、次のようになります。

<img src="/static/images/exercise-assets/finish-wall/completed-wall.webp" alt="完成した壁" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

知っておくべきこと

- 各レンガの高さは10、幅は20です。
- `rectangle`関数は、コード内に1回だけしか使えません！
- 正しい色は`"brick"`です。

これまでに使ってきた考え方を応用すれば、きっとうまくいきますよ。頑張ってください！
