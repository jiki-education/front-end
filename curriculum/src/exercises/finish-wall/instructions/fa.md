در اولین تمرین رسم که کامل کردید، از تابع `rectangle` (مستطیل) برای پر کردن شکاف‌های یک دیوار استفاده کردید. در این تمرین، با استفاده از یک حلقه برای اضافه کردن لایه‌ی بالایی یک دیوار، روی آن کار می‌کنیم.

تمام لایه‌ها به جز لایه‌ی بالایی قبلاً کامل شده‌اند. شما باید لایه‌ی نهایی متشکل از ۵ آجر را اضافه کنید. دیوار نهایی باید شبیه این باشد:

<img src="/static/images/exercise-assets/finish-wall/completed-wall.webp" alt="دیوار کامل‌شده" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

نکاتی که باید بدانید:

- هر آجر ۱۰ ارتفاع و ۲۰ عرض دارد.
- تابع `rectangle` فقط یک بار می‌تواند در کد شما ظاهر شود!
- رنگ صحیح `"brick"` است.

از ایده‌هایی که اخیراً استفاده می‌کردید دوباره استفاده کنید و کارتان راه می‌افتد. موفق باشید!
