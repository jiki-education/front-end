Σε αυτή την άσκηση σχεδιάζουμε ελλείψεις για πρώτη φορά και σκεφτόμαστε λίγο περισσότερο τη συμμετρία που αναφέραμε στο Foxy Face.

Αυτή η άσκηση χρησιμοποιεί ελλείψεις. Οι ελλείψεις είναι σαν τεντωμένοι κύκλοι. Ορίζουμε και πάλι το κέντρο, αλλά αντί για μία ακτίνα χρησιμοποιούμε δύο, την οριζόντια ακτίνα και την κατακόρυφη ακτίνα. Αν η κατακόρυφη ακτίνα είναι μεγαλύτερη από την οριζόντια, η έλλειψη θα φαίνεται ψηλή. Και αν η οριζόντια ακτίνα είναι μεγαλύτερη από την κατακόρυφη, η έλλειψη θα φαίνεται πλατιά. Αν ορίσεις και τις δύο ακτίνες ίσες, έχεις πάλι έναν κύκλο!

Η συνάρτηση `ellipse` (έλλειψη) δέχεται 5 εισόδους: τη θέση του κέντρου (`centerX` (κέντρο Χ), `centerY` (κέντρο Y)), την οριζόντια ακτίνα (`radiusX` (ακτίνα Χ)), την κατακόρυφη ακτίνα (`radiusY` (ακτίνα Y)), και το χρώμα:

### Ο Πιγκουίνος

Η δουλειά σου είναι να σχεδιάσεις τη δεξιά πλευρά του πιγκουίνου και να προσπαθήσεις να το κάνεις **ΧΩΡΙΣ** να περάσεις τον κέρσορα πάνω από τις συντεταγμένες ή να μαντέψεις τις τιμές τους. Το τελικό σχέδιο θα πρέπει να μοιάζει με αυτό:

<img src="/static/images/exercise-assets/penguin/penguin-finished.webp" alt="Πιγκουίνος" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Έχουμε σχεδιάσει τη μισή εικόνα για σένα. Διαβάζοντας τον κώδικα που υπάρχει εκεί, θα μπορέσεις να βρεις τις υπόλοιπες λεπτομέρειες για να την κάνεις συμμετρική. Θυμήσου: η επάνω αριστερή γωνία του καμβά σχεδίασης είναι `0,0`, και η κάτω δεξιά είναι `100,100`. Ο πιγκουίνος βρίσκεται στο κέντρο. Για τη μύτη, θα πρέπει να **αλλάξεις** τις κεντρικές συντεταγμένες του τριγώνου. Μην προσθέσεις νέο τρίγωνο.

**Ξεκίνα πατώντας το _"Εκτέλεση Κώδικα"_** για να δεις πώς είναι η αρχική εικόνα. Καλή διασκέδαση!
