Te han dado una solución que funciona para un laberinto, pero es muy larga y repetitiva. Tu trabajo es cambiar el código para que tenga la menor cantidad posible de líneas.

El secreto para lograrlo es usar bucles `repeat` (loops en inglés) para acortar el código. Por ejemplo, recuerda que un bucle `repeat` tiene esta sintaxis:

```javascript
repeat(3) {
  // Lo que quieras repetir aquí.
}
```

Tu trabajo aquí es hacer que el código sea lo más corto posible: **22 líneas de código**. Eso implica pensar cuándo conviene usar un bucle `repeat` y cuándo no. Ten en cuenta que las líneas en blanco y las que solo tienen comentarios no cuentan para el objetivo, así que siéntete libre de espaciar tu código para que sea más legible.

¡Buena suerte!
