On t'a donné une solution qui fonctionne pour ce labyrinthe, mais elle est très longue et pleine de répétitions. Ta mission : modifier le code pour qu'il tienne en **aussi peu de lignes que possible**.

Le secret, c'est d'utiliser des boucles (_loops_ en anglais) avec le mot-clé `repeat` pour rendre le code plus court. Rappelle-toi qu'une boucle repeat s'écrit avec cette syntaxe :

```javascript
repeat(3) {
  // Ce que tu veux répéter ici.
}
```

Ton objectif ici : rendre le code aussi court que possible, c'est-à-dire **22 lignes de code**. Il faut donc réfléchir aux moments où une boucle repeat est utile, et à ceux où elle ne l'est pas. Note que les lignes vides et les lignes qui ne contiennent qu'un commentaire ne comptent pas dans le total, alors n'hésite pas à aérer ton code pour le rendre plus lisible !

Bonne chance !
