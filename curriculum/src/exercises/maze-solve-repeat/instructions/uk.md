У нас уже є робоче рішення лабіринту, але воно дуже довге й повторюване. Наше завдання: змінити код так, щоб він мав **якомога менше рядків**.

Секрет у тому, щоб скоротити код за допомогою циклів (англ. _loops_) `repeat`. Ось приклад. Нагадаємо, що цикл repeat має такий синтаксис:

```javascript
repeat(3) {
  // Те, що ми хочемо повторити.
}
```

Отже, завдання: зробити код якомога коротшим, а саме вкластися в **22 рядки коду**. Для цього варто подумати, коли цикл repeat справді допомагає, а коли ні. Порожні рядки та рядки лише з коментарями не враховуються, тож можна сміливо розріджувати код, щоб він читався легше!

Успіхів!
