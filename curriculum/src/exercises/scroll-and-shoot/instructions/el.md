Επιστρέφουμε στο Space Invaders. Την προηγούμενη φορά χρειαζόσουν μόνο να μετακινηθείς αριστερά και δεξιά για να πυροβολήσεις όλους τους εξωγήινους. Αυτή τη φορά όμως θα πρέπει επίσης να κάνεις το λέιζερ να αναπηδά από αριστερά προς τα δεξιά, πραγματοποιώντας πολλαπλά περάσματα για να τους εξολοθρεύσεις.

Μπορείς να μετακινήσεις το λέιζερ αριστερά και δεξιά χρησιμοποιώντας τις συναρτήσεις `moveLeft()` (μετακίνηση προς τα αριστερά) και `moveRight()` (μετακίνηση προς τα δεξιά). Μπορείς να πειραματιστείς για να δεις πόσο μακριά αριστερά και δεξιά μπορείς να φτάσεις. Αν βγεις έξω από την άκρη της οθόνης, χάνεις.

Όπως και πριν, όταν μετακινείσαι, πρέπει να ελέγξεις αν υπάρχει εξωγήινος από πάνω σου χρησιμοποιώντας τη συνάρτηση `isAlienAbove()` (ελέγχει αν υπάρχει εξωγήινος από πάνω) και, αν ναι, να τον πυροβολήσεις με τη `shoot()` (πυροβολεί). Αν πυροβολήσεις χωρίς να υπάρχει εξωγήινος, χάνεις το παιχνίδι, η σπατάλη πυρομαχικών δεν επιτρέπεται!

Το κανόνι λέιζερ υπερθερμαίνεται εύκολα. Πρέπει να μετακινηθείς ανάμεσα στις βολές για να το κρατήσεις δροσερό.

Τα κύματα γίνονται όλο και πιο έντονα όσο προχωράς. Στο τελευταίο κύμα, οι εξωγήινοι αναγεννιούνται, οπότε δεν μπορείς να ξέρεις εκ των προτέρων πόσες βολές θα χρειαστείς – ο βρόχος σου πρέπει να συνεχίσει να τρέχει μέχρι να εξολοθρευτούν όλοι οι εξωγήινοι.

Ένας κανόνας σε αυτή την άσκηση: για να περάσεις το τελικό σενάριο, δεν μπορείς να χρησιμοποιήσεις βρόχο `repeat` με είσοδο (δηλαδή **μπορείς** να χρησιμοποιήσεις `repeat() { ... }`, αλλά **δεν μπορείς** να χρησιμοποιήσεις `repeat(10) { ... }`).

Μόλις εξολοθρευτούν όλοι οι εξωγήινοι, κερδίζεις! Καλή τύχη!
