Dans cet exercice, ta mission est de dessiner une icône météo pour un jour de pluie, avec le soleil qui pointe derrière les nuages. Une fois l'exercice terminé, le résultat doit ressembler à ceci :

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="Scène terminée avec nuage, pluie et soleil" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

On a dessiné un modèle pour toi. Tes formes doivent se placer juste à l'intérieur des lignes. On a aussi ajouté la base du nuage dans le code pour te faciliter un peu les choses. **Tu ne peux pas modifier cette ligne** (tu verras qu'elle est grisée et qu'un symbole de cadenas se trouve à côté).

Tu auras besoin des fonctions `circle` (cercle) et `ellipse`. N'utilise les ellipses que pour les gouttes de pluie. Si tu t'en sers pour le soleil ou les nuages, ça ne fonctionnera pas.

Presque tous les nombres dont tu as besoin sont divisibles par 5 (par exemple 5, 10, 15, etc.). La seule exception est le rayon horizontal des gouttes de pluie, qui est `3`.

Amuse-toi bien !
