У цій вправі потрібно намалювати картинку погоди для дощовитого дня, коли сонце визирає з-за хмар. У готовому вигляді вона має виглядати так:

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="Готова картинка з хмарою, дощем і сонцем" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Ми вже намалювали шаблон. Фігури мають розташовуватися всередині напрямних ліній. Крім того, ми додали в код основу хмари, щоб трохи полегшити завдання. **Цей рядок змінювати не можна** (він виділений сірим, а поруч стоїть символ замочка).

Знадобляться функції `circle` (коло) та `ellipse` (еліпс). Еліпси використовуйте лише для крапель дощу: якщо намалювати ними сонце чи хмари, нічого не вийде.

Майже всі потрібні для цього числа діляться на 5 (наприклад, 5, 10, 15 і так далі). Єдиний виняток: горизонтальний радіус крапель дощу, який дорівнює `3`.

Приємного малювання!
