Έχεις ήδη λύσει απλά ακρωνύμια τριών γραμμάτων, όπως το να μετατρέπεις το `Portable Network Graphics` σε `PNG`.

Ωστόσο, σε αυτή την άσκηση, το πάμε ένα βήμα παραπέρα και θα ασχοληθείς με όλα τα ακρωνύμια — όχι μόνο με αυτά των τριών γραμμάτων. Και αυτό είναι πολύ πιο δύσκολο...

Η δουλειά σου είναι να γράψεις μια συνάρτηση με το όνομα `acronym(phrase)` η οποία δέχεται μια φράση και επιστρέφει το ακρωνύμιό της.

## Οι κανόνες

Μια νέα λέξη ξεκινά μετά από ένα **κενό** ή μια **παύλα** (`-`). Κάθε άλλος χαρακτήρας, όπως κόμματα, απόστροφοι, κάτω παύλες, θαυμαστικά, και ούτω καθεξής, **δεν** είναι διαχωριστικό και ποτέ δεν γίνεται μέρος του ακρωνυμίου. Μετράνε μόνο τα γράμματα.

| Phrase                    | Acronym |
| ------------------------- | ------- |
| As Soon As Possible       | ASAP    |
| Liquid-crystal display    | LCD     |
| Thank George It's Friday! | TGIF    |

## Προσοχή

Δεν σου έχουμε δώσει καμία από τις πιο προχωρημένες μεθόδους JavaScript που βλέπεις αργότερα στο μάθημα (τίποτα που να κάνει μαγικά κεφαλαίο ένα γράμμα ή να σου λέει αν ένας χαρακτήρας είναι γράμμα εξαρχής). Θα χρειαστεί να φτιάξεις μόνος σου όλες αυτές τις βοηθητικές συναρτήσεις πριν μπορέσεις να συνθέσεις το όλο πράγμα.

Αυτή είναι πιο δύσκολη απ' ό,τι ακούγεται. Καλή διασκέδαση!
