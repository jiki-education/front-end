Αυτή η άσκηση σου συστήνει τη συνάρτηση `triangle` (τρίγωνο). Τη χρησιμοποιείς με 7 εισόδους. Οι πρώτες 6 είσοδοι είναι ζεύγη συντεταγμένων για τις τρεις γωνίες. Η τελευταία είσοδος είναι το `color`:

- `x1` (πρώτη συντεταγμένη x), `y1` (πρώτη συντεταγμένη y): Η πρώτη γωνία
- `x2` (δεύτερη συντεταγμένη x), `y2` (δεύτερη συντεταγμένη y): Η δεύτερη γωνία
- `x3` (τρίτη συντεταγμένη x), `y3` (τρίτη συντεταγμένη y): Η τρίτη γωνία
- `color` (χρώμα): Το χρώμα του τριγώνου (π.χ. `"orange"`)

### Σχεδιάζοντας ένα πρόσωπο αλεπούς

Η δουλειά σου είναι να χρησιμοποιήσεις τρίγωνα για να φτιάξεις ένα γεωμετρικό πρόσωπο αλεπούς:

<img src="/static/images/exercise-assets/foxy-face/example.svg" alt="Πρόσωπο Αλεπούς" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Το πρόσωπο είναι οριζόντια συμμετρικό (η αριστερή πλευρά είναι πανομοιότυπη με τη δεξιά). Και έχει συνολικά 8 τρίγωνα:

- Δύο μάγουλα `"white"`
- Δύο αυτιά `"brown"`
- Δύο μισά του προσώπου `"orange"`
- Μια μύτη `"charcoal"` (δύο τρίγωνα)

(Φρόντισε να χρησιμοποιήσεις αυτά τα χρώματα όταν σχεδιάζεις τα τρίγωνα, και θυμήσου να ελέγξεις ότι τα γράφεις ως συμβολοσειρές (_strings_ στα αγγλικά)!)

Έχουμε σχεδιάσει τα περιγράμματα κάποιων μερών για να σε βοηθήσουμε να ξεκινήσεις. Αν ακολουθήσεις τη σειρά που δίνεται στα σχόλια, θα διαπιστώσεις ότι γίνεται λίγο πιο εύκολο.

Επίσης, για να γίνει ακόμα πιο εύκολο, όλοι οι αριθμοί που χρησιμοποιούνται διαιρούνται ακριβώς με το 5 (π.χ. `5`, `10`, `15` κ.λπ. είναι έγκυροι, αλλά `1`, `2`, `3`, `4`, `6`, `7`, `8`, `9`, `11` κ.λπ. δεν είναι). Θα δεις αυτό το μοτίβο συχνά στις επόμενες ασκήσεις.

Κάτι τελευταίο. Μπορείς να περάσεις τον κέρσορα πάνω από τον χώρο για να βρεις συντεταγμένες. Αυτό είναι εξαιρετικό για την αριστερή πλευρά, αλλά εφόσον η δεξιά πλευρά είναι συμμετρική, μπορείς να το λύσεις χωρίς να χρειαστεί να περάσεις τον κέρσορα;

Καλή επιτυχία!
