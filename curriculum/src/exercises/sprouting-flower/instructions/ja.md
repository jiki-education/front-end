この演習では、60回の繰り返しで成長する花を作成することが課題です。

アニメーションは次のような感じになります。

<img src="/static/images/exercise-assets/sprouting-flower/frames.webp" alt="60回の繰り返しで地面から花が成長する様子を示すコマ" style="width: 100%; max-width: 600px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

この演習のポイントは、異なる要素どうしの関係性を組み立てることです。これはプログラミングにおける重要なスキルです。

**これより先の指示を読む前に**、どのようにしてこれを作ればいいか、数分かけて考えてみましょう。自分で取るべき手順を、紙に書き出してみてください。

**自分なりの解決策が固まった**（あるいは諦めた）ら、**下にスクロール**して指示を確認してください。

---

## 解き方

ここでのキーとなる要素は、花の中心です。それ以外のものはすべて、その中心点から計算できます。ループの各繰り返しで、中心点は `1` ずつ上に動かします（描画する前に）。

その他、知っておくべきことは以下のとおりです。

- 描画領域（キャンバス）の左上が `0,0`、右下が `100,100` です。
- 花の半径は `0` から始まり、各繰り返しで `0.4` ずつ増えます（描画前）。
- 花の中央の黄色い部分（めしべ）の半径は `0` から始まり、各繰り返しで `0.1` ずつ増えます（描画前）。
- 茎は花の中心から始まり、地面まで届きます。
- 茎の幅は、茎の高さの10%です（つまり `stemHeight / 10`（茎の高さの10分の1））。
- すべての要素は、水平方向の中心に配置されます。
- 葉は茎の両側にぴったりくっついて配置されます。
- 葉は茎のちょうど真ん中の高さに位置します。
- 葉の `radiusX`（横方向の半径）は、花の半径の50%です。
- 葉の `radiusY`（縦方向の半径）は、花の半径の20%です。
- 花の色は好みに合わせて `"red"` か `"pink"` にできます。花の中央部分（めしべ）の色は `"yellow"`、草は `"green"`、背景は `"skyblue"` にしてください。

一つひとつ順番に取り組むことが**とても重要**です。

- まずピンクの花を描き、それを上に動かすことから始めましょう。
- 次に、それを成長させます。
- 小さい黄色い中心を追加します。
- 茎を追加します。
- 左の葉を追加します。
- 右の葉を追加します。

スクラバー（再生バー）を使ってコードをなぞり、どこがうまくいっていないのかを探りましょう。

### これは難しい演習です

これは挑戦的な演習です。時間をかけてじっくり取り組んでください。どうしても行き詰まったら助けを求め、何がうまくいっていないのか、なぜそう思うのかを詳しく伝えてください。

何が起きているのかわからないときは、スクラバー（左下の再生バー）を使って変数の値を確認しましょう。各行の情報を見るには、小さなトグルボタンをクリックしてください。

学びは、苦労のなかにあります。何かに間違い、それを解決するたびに、プログラマーとして一歩前進しています。やがて、それが簡単に感じられるようになります。そのまま続けましょう。
