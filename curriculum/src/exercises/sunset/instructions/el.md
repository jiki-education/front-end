Η αποστολή σου είναι να κάνεις ένα animation μιας σκηνής ηλιοβασιλέματος που διαρκεί 100 επαναλήψεις. Θα πρέπει να μοιάζει με αυτό (το τρεμόπαιγμα είναι ακριβώς αυτό που βλέπεις και στα flip-books!):

<img src="/static/images/exercise-assets/sunset/example.webp" alt="Ηλιοβασίλεμα" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 16px;" />

Έχουμε σχεδιάσει την αρχική σκηνή για σένα. Πρέπει να ζωντανέψεις μερικά πράγματα, χρησιμοποιώντας το στυλ flip-book που έμαθες στο προηγούμενο βίντεο:

- **Το μέγεθος του ήλιου**: Θα πρέπει να ξεκινά με ακτίνα 5 και να μεγαλώνει κατά 0.2 σε κάθε επανάληψη.
- **Η θέση του ήλιου**: Έχει αρχικό κέντρο (50, 10) και θα πρέπει να χαμηλώνει στον ουρανό κατά 1 σε κάθε επανάληψη.
- **Το χρώμα του ήλιου**: Κάνε animation από κίτρινο σε πορτοκαλί χρησιμοποιώντας RGB. Μπορείς να επιλέξεις όποιες τιμές θέλεις, αλλά συνιστούμε να ξεκινήσεις με `255, 237, 0` και να μειώσεις το πράσινο για ένα ωραίο αποτέλεσμα.
- **Το χρώμα του ουρανού**: Χρησιμοποίησε το HSL για να κάνεις animation στο χρώμα του ουρανού. Θα θέλεις να αυξήσεις την απόχρωση (_hue_ στα αγγλικά) σε όλη τη διάρκεια του animation. Διάλεξε τιμές που θεωρείς όμορφες. Εμείς επιλέξαμε ένα ροζ ηλιοβασίλεμα στο παραπάνω animation, αλλά μπορείς να διαλέξεις πολλές διαφορετικές ατμόσφαιρες!

Θυμήσου: για να κάνεις animation σε στυλ flip-book, απλώς σχεδιάζουμε ολόκληρη τη σκηνή ξανά πάνω από την προηγούμενη έκδοση.

Καλή τύχη!
