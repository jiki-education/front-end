你的任务是制作一个持续 100 次迭代的日落动画。它应该看起来像这样（闪烁效果正是你在手翻书中看到的！）：

<img src="/static/images/exercise-assets/sunset/example.webp" alt="日落" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 16px;" />

我们已经为你画好了初始场景。你需要利用在上一个视频中学到的手翻书风格，对下面几项进行动画处理：

- **太阳的大小**：它的半径应从 5 开始，每次迭代增加 0.2。
- **太阳的位置**：它的初始中心点为 (50, 10)，并应在每次迭代中向下移动 1。
- **太阳的颜色**：使用 RGB 将颜色从黄色渐变到橙色。你可以选择你喜欢的所有值，但我们建议从 255, 237, 0 开始，并减少绿色分量以获得漂亮的效果。
- **天空的颜色**：使用 HSL 来制作天空颜色的动画。你将需要在动画过程中逐渐增加色相（英语：_hue_）。选择你觉得看起来不错的值。我们在上面的动画中制作了粉色日落，但你可以选择各种不同的氛围！

记住：要用手翻书风格制作动画，我们只需将整个场景重新绘制在上一版本的上面。
