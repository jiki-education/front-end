課題は、100回の繰り返しにわたる夕日のシーンをアニメーションさせることです。こんな感じになるはずです（ちらつきは実際のパラパラ漫画でも見られるものです！）：

<img src="/static/images/exercise-assets/sunset/example.webp" alt="夕日" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 16px;" />

最初のシーンはあらかじめ描いてあります。前のビデオで学んだパラパラ漫画スタイルを使って、いくつかの要素をアニメーションさせる必要があります。

- **太陽の大きさ**：半径5から始まり、繰り返しごとに0.2ずつ大きくなります。
- **太陽の位置**：初期の中心は (50, 10) で、繰り返しごとに空における位置が1ずつ下がります。
- **太陽の色**：RGBを使って、黄色からオレンジ色にアニメーションさせます。好きな値を選んで構いませんが、最初に `255, 237, 0` から始め、緑の値を減らしていくと良い効果が得られるとお勧めします。
- **空の色**：HSLを使って空の色をアニメーションさせます。アニメーション全体を通して色相（英: _hue_）を増やしていきたいところです。見た目が良いと思う値を選んでください。上のアニメーションではピンク色の夕日にしていますが、いろんな雰囲気も楽しめますよ！

覚えておいてください：パラパラ漫画スタイルでアニメーションするには、シーン全体を前に描いた上に、もう一度描くだけです。

頑張ってください！
