과제는 100번 반복되는 석양 장면을 애니메이션으로 만드는 거예요. 결과는 이렇게 보여야 해요 (이 반짝거림은 플립북에서도 똑같이 나타나요!):

<img src="/static/images/exercise-assets/sunset/example.webp" alt="석양" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 16px;" />

초기 장면은 미리 그려 두었어요. 이제 지난 영상에서 배운 플립북 방식으로 몇 가지를 애니메이션으로 만들어야 해요.

- **태양의 크기**: 반지름이 5에서 시작해서 반복할 때마다 0.2씩 커져야 해요.
- **태양의 위치**: 처음 중심 좌표는 (50, 10)이고, 하늘에서 반복할 때마다 1씩 낮아져야 해요.
- **태양의 색상**: RGB를 사용해 노란색에서 주황색으로 변하게 해요. 원하는 값으로 설정해도 되지만, `255, 237, 0`으로 시작해서 녹색을 줄이면 멋진 효과를 낼 수 있어요.
- **하늘의 색상**: HSL을 사용해 하늘 색을 바꿔요. 애니메이션이 진행되는 동안 색상(영어: _hue_)을 점점 높여야 해요. 마음에 드는 값을 골라 보세요. 위 애니메이션에서는 분홍빛 석양을 표현했지만, 다양한 분위기를 선택할 수 있어요!

기억하세요: 플립북 방식의 애니메이션은 단순히 이전 장면 위에 전체 장면을 다시 그리는 거예요.

행운을 빌어요!
