Η δουλειά σου είναι να φτιάξεις ένα όμορφο σχέδιο ουράνιου τόξου, φτιαγμένο από 100 κάθετες ράβδους. Πρέπει να μοιάζει κάπως έτσι:

<img src="/static/images/exercise-assets/rainbow/example.webp" alt="Ουράνιο τόξο" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Το ουράνιο τόξο αποτελείται από `100` ράβδους, η καθεμία εκτεινόμενη από πάνω μέχρι κάτω με πλάτος `1`. Η πρώτη ράβδος πρέπει να έχει `x` (οριζόντια θέση) ίση με `0`, και η τελευταία ράβδος πρέπει να έχει `x` ίση με `99`.

Για να ορίσεις το χρώμα, χρησιμοποίησε τη συνάρτηση `hsl(...)` (μετατροπή σε χρώμα). Αυτή επιστρέφει (_return_ στα αγγλικά) μια συμβολοσειρά χρώματος, την οποία μπορείς μετά να χρησιμοποιήσεις ως τελευταία είσοδο στην `rectangle(...)` (ορθογώνιο). Καλύτερα να ορίσεις τις τιμές του κορεσμού (_saturation_ στα αγγλικά) και της φωτεινότητας (_lightness_ στα αγγλικά) γύρω στο `50`. Η πρώτη ράβδος πρέπει να έχει **απόχρωση** (_hue_ στα αγγλικά) ίση με `0`. Η απόχρωση πρέπει να αυξάνεται για κάθε ράβδο και να καταλήγει κάπου κοντά στο 300.
