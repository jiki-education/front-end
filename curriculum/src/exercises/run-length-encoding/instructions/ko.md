_Run-length encoding_(런 길이 부호화)는 데이터를 압축하는 간단한 방법이에요. 같은 문자가 연속해서 나오는 부분을, 그 개수와 해당 문자 하나로 대체해요. 한 번만 나타나는 문자는 그대로 두고, 앞에 개수를 붙이지 않아요.

예를 들어, `"AABBBCCCC"`를 부호화하면 `"2A3B4C"`가 되고, `"XYZ"`(반복 없음)는 그냥 `"XYZ"`예요.

공백도 다른 문자와 마찬가지로 하나의 문자로 취급해요. 따라서 `"  hsqq qww  "`를 부호화하면 `"2 hs2q q2w2 "`가 돼요.

### 두 개의 함수

두 개의 함수를 만들어 봐요:

- `encode`(부호화하다) 함수는 문자열을 받아 런 길이 부호화된 형태를 반환해요.
- `decode`(복호화하다) 함수는 부호화된 문자열을 받아 원래 텍스트로 복원해요.

복호화는 그 과정을 반대로 수행해요. 숫자는 바로 뒤에 오는 문자를 몇 번 반복할지 알려줘요. 연속된 문자의 길이가 9를 넘을 수 있으므로, 개수가 여러 자릿수일 수 있다는 점을 기억하세요 (예를 들어, `"12W"`는 `W`가 열두 개라는 뜻이에요).
